# ORION

ORION is the clean-generation repository for the evidence-governed recursive research system developed from the RAKL project.

The repository is intentionally being bootstrapped from a minimal root so that the new architecture can be organized by recursive conceptual responsibility rather than by the historical order in which RAKL accumulated artifacts.

Active bootstrap work should land through reviewed branches/PRs. The legacy RAKL repository remains the provenance source for migrated ideas, mechanics, experiments, and negative results.
