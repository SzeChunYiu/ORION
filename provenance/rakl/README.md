# RAKL provenance

ORION is a clean-generation reconstruction of the RAKL project, not an attempt to erase its history.

The RAKL repository remains the immutable provenance location for papers, experiments, failed approaches, review artifacts and implementation history unless a specific artifact is deliberately migrated.

## Migration policy

`MIGRATE-CONCEPT` — reconstruct the concept in ORION's new architecture with source attribution.

`MIGRATE-CODE` — port code only when the mechanic is still required and its contract survives the new architecture.

`REFERENCE` — leave the artifact in RAKL and point to it; do not duplicate historical bulk.

`DEFER` — potentially useful but not needed for the minimum working ORION.

`REJECT` — obsolete/duplicated material that should not enter the clean-generation repository except as negative-history reference.
