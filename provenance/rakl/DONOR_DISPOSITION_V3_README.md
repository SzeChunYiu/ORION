# Donor disposition V3 boundary

`DONOR_DISPOSITION_V3.json` is the machine-readable Phase-1 donor-search inventory pinned to RAKL `70f5f7c4...`.

A terminal disposition means **the donor-search decision is closed for the current Phase-1 scope**, not that every deferred capability is implemented. `DEFER_WITH_TRIGGER` is an explicit reopen contract. When its trigger becomes true, ORION must reopen the RAKL donor before designing a replacement.

The inventory is intentionally separate from scientific authority and from Phase-2 live performance. It exists to prevent clean-generation invention from outrunning known RAKL work.
