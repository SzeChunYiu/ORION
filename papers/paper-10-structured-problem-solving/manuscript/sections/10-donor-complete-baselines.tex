\section{Donor-complete baselines}
The donor-complete comparator includes:
\begin{enumerate}
    \item current theorem-proving/proof-state systems;
    \item LAMP-like proof-repair/tool agents;
    \item failure-triggered learned Lean interventions;
    \item premise retrieval and dependency-aware proof search;
    \item effect-grounded tactic models and tactic-library/macro mining;
    \item generic LLM/tool agents;
    \item exact and heuristic search;
    \item program synthesis;
    \item AlphaEvolve/CodeEvolve-style evolutionary method/program search;
    \item P9 structured representation without P10 method edits;
    \item search-more and compute-more controls;
    \item representation-change-only controls;
    \item oracle old-closure reach for exact synthetic worlds only.
\end{enumerate}
All runnable comparisons receive the same evaluator, task information, access model, and total resource accounting.
