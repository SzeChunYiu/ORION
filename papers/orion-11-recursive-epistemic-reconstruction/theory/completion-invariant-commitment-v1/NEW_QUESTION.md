# ORION-11 new scientific object — completion-invariant commitment

Identity: `ORION11.COMPLETION_INVARIANT_COMMITMENT.v1`.

The faithful Active-VOI result removes comparative mechanism necessity, and the costed-ordering study removes comparative economy. This identity does not compare search policies at all.

Let a partially reconstructed scientific state `p` induce the set `Comp(p)` of all total states consistent with every currently established fact, hard constraint and explicit unknown. Let `D(c)` be the irreversible scientific disposition that would be correct in a total completion `c` (for example retain/reopen, promote/refuse, or choose one formally registered terminal).

The question is:

> When is an irreversible disposition licensed before reconstruction is complete, and what is the smallest certificate showing that all still-admissible completions force the same disposition?

A commitment is **completion-invariant** iff `D` is constant on `Comp(p)`. This is a property of the information state, not of how a policy searched for it.

This object is not absorbed by Active-VOI matching ORION: two search policies may reach the same partial state, while the theorem asks whether *any* irreversible commitment from that state is logically licensed.
