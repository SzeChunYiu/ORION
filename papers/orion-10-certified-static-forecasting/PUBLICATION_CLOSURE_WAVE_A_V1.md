# ORION-10 Publication Closure Wave A V1

## Maximum current claim

ORION-10 separates feasible upper bounds, theorem-backed equalities/ceilings, exact counterexamples, and forecast-only rows for a compiler-specific setting. Current technical content is strong. The top-tier discriminator is whether those authority layers transfer to an independent public compiler family and improve a prospectively frozen decision—not merely whether another table agrees.

## Good specialist finish

- [ ] Independently check the all-n theorem, exact equality/ceiling claims, 10<11 counterexample, B′/F2 separation, and every forecast-only limitation.
- [ ] Keep timing descriptive unless environment and resource accounting are strong enough for comparison.
- [ ] Finalize Quantum-facing positioning, nearest work, clean source, figures/tables, current PDF audit, and package manifest.

## Top-tier discriminator — second public family plus decision value

- [ ] Select an independently maintained compiler/resource-estimation family materially different from the current family.
- [ ] Bind repository/tool revision, benchmark workloads, native objective/resource outputs, compiler configuration, and licence.
- [ ] Define how each ORION-10 authority layer maps to the family before reading outcomes. Unsupported mappings return `NOT_APPLICABLE`.
- [ ] Freeze the exact prediction and the downstream decision that consumes it.

## Acceptable downstream decisions

Choose one before outcomes:

- candidate/compiler-pass pruning while preserving the true optimum/feasible set;
- resource-budget admission/rejection;
- selection between native compilation strategies;
- early stop/continue decision for exact evaluation;
- certificate escalation decision.

The endpoint must measure wrong decisions, coverage, and resource savings/cost. Forecast agreement alone is secondary.

## Required comparators

- native/public resource estimator or compiler forecast;
- simple empirical/static baseline;
- theorem-free fitted predictor if appropriate;
- strongest donor-composed estimator with the same inputs;
- exact evaluator/oracle on the subset where available;
- ORION-10 authority-layered forecast.

All arms receive identical workload information, compiler access, preprocessing, cache, and budget.

## Primary endpoints

- invalid/wrong downstream decision rate;
- useful decision coverage;
- regret or quality loss relative to exact/native oracle;
- evaluator/compiler calls avoided or added;
- full resource vector;
- forecast calibration/error by authority layer;
- CANNOT_CHECK/NOT_APPLICABLE rate.

Use a non-compensatory correctness gate: savings cannot offset an excess invalid-decision rate beyond the frozen margin.

## Public/external resources

- independent public quantum compiler/toolchain and native estimator;
- public circuit/workload suite fixed before ORION analysis;
- deterministic simulator/equivalence/resource checker where feasible;
- original public donor implementations.
