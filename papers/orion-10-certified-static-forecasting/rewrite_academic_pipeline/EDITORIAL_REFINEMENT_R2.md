## 3. Refined abstract for adoption

Static resource forecasting can avoid unrestricted search only when the source of its authority is explicit. A theorem can certify a cost for every admitted size, a compact regime rule can explain which structure realizes that cost, and a finite benchmark can show that an implementation agrees with an exact referee. These claims need not rise and fall together.

For a shared-Tag TARE grammar under a fixed unit support-count objective, an all-size normal-form theorem proves that every unrestricted optimum has a representative in the complete support-at-most-two family. Minimizing over that family therefore returns the exact unrestricted cost for every admitted system size under the theorem assumptions. The implementation has zero error on 9,547 registered dynamic-programming comparisons, but this finite agreement validates the code path rather than proving exactness. A compact enlarged-borrow explanation repairs an earlier fresh-instance counterexample and fits its registered panels, yet a hostile study finds 64 exact hybrid witnesses among 740 instances outside that explanation. The cost theorem survives because every witness remains inside support two. A refined explanation closes 10,481 verified instances, while one all-size explanation sector remains open. Separately, 102 staged predictions committed before exact opening agree with their frozen outcomes.

The result is a hierarchy of scientific authority: theorem-backed cost exactness can survive exact refutation of a human-readable structural explanation. Finite zero error and prospective prediction provide implementation and forward-use evidence but do not substitute for proof. The theorem is restricted to the stated grammar and objective and carries no arbitrary-resource, hardware-performance, full-circuit, runtime, or quantum-advantage claim.
