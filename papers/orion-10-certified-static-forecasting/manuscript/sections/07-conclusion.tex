\section{Conclusion}

An interpretable static formula can be useful and still be wrong as a universal equality. Here, a single retained three-qubit counterexample separates that formula from a theorem-backed support-two evaluator. Later hostile cases separate exact cost from the first repaired explanation. Complete local-domain domination then closes the explanation classification without erasing either failed model.

The result is a layered certificate for one Pauli compilation grammar: feasible constructions bound the cost, support reduction certifies exactness, named families explain a minimizer, and frozen comparisons validate particular executable rows. The changed-objective witness shows exactly where this authority stops. Preserving these distinctions makes static forecasts more auditable and makes counterexamples informative rather than inconvenient.
