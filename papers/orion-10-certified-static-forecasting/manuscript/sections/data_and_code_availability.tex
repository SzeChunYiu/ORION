\section{Data and code availability}

The submission package contains the exact result records, frozen protocols, selected analysis code, complete state-preparation panel records, table-generation code and independent or separately implemented checkers used for the headline values.  A machine-readable manifest binds every included file and both manuscript PDFs.  The public repository is \url{https://github.com/SzeChunYiu/ORION}; a permanent archive DOI and final reuse licence are not asserted in this version.  Row-level exactness is reported only where an exact referee or theorem binding exists.
