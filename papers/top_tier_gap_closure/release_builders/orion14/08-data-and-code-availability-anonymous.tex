\section{Data and code availability}
\label{sec:availability}

A double-blind supplementary research package accompanies the review submission. It contains the safe aggregate result objects used for the bounded V2, V3, and P4-X results, a small verifier for the reported headline counts, and checksums for the packaged files. Public repository identity, author-linked URLs, CI run identifiers, commit locators, and other operational identifiers that would reveal authorship are deliberately withheld from the review manuscript and are restored in the named archival version.

The study protocols and result-bearing analyses were frozen before the corresponding protected outcomes were accessed. The anonymous supplement exposes only material needed to audit the bounded reported results. Protected per-case gold, raw protected traces, secret seeds, credentials, and candidate-hidden fields are not exported. Their absence is part of the protected-evaluation custody model and is not presented as full external reproduction or independent replication.

The review package permits verification of the published aggregate counts and retained claim boundaries without requiring author identity. After double-blind review, the named archival version provides the public repository location, exact protocol and artifact paths, execution receipts, commit identities, and content digests that bind the complete reproducibility record.
