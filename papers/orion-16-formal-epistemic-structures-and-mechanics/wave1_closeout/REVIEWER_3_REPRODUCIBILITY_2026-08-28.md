# Reviewer 3 — reproducibility, reporting and reader surfaces

## Posture

**Major revision; no current upload surface is authorized.**

## Major concerns

### R3-16-001 — canonical-source conflict

The designated current science source is a versioned overlay, while the target
submission source is an older scientific manuscript. A reader cannot determine
one canonical article from the package. **Resolution test:** designate one
standalone source whose abstract, results, limits and conclusion all express
the same current claim.

### R3-16-002 — the documented reproduction path is red

The clean path stops on stale negative-history provenance before completing the
formal suite. **Resolution test:** the full documented command passes from a
clean environment while retaining the adverse history and exact correction.

### R3-16-003 — reader-facing project leakage

The current source/PDF contains internal paper and contract identifiers,
version narration, repository paths and module names, hashes, run numbers,
continuous-integration history and machine terminal strings. **Resolution
test:** exact PDF, source archive, review archive, cover letter and availability
statement pass a strict text/member-name scan and every PDF page passes visual
inspection.

### R3-16-004 — no current review archive or filing binding

The available package does not bind sanitized current source, proof materials,
human-only declarations and the exact PDF as one non-stale filing object.
**Resolution test:** a private byte binding plus a generic reader-facing package
is created only after the scientific gate closes.
