# SAGE Short-Form External V1 Evidence

The hit@50 metrics reported in `score.json` carry a candidate-pool-size confound documented in `cutoff50_diagnostic.md` — see that file for the full analysis (restricted to tasks where both systems have ≥50 candidates, the 12-hit full-sample gap narrows to a persistent 1-hit margin).

All other evidence files are raw outputs from the SAGE runner (`scripts/run_sage_shortform.py`) under the DECLARED_DEVIATION_NEVER_OFFICIAL authority model — SAGE's 200k corpus and evaluator are unpublished, so results are runnable but not officially scorable.
