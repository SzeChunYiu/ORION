# Information Processing & Management submission checklist

- [x] Anonymous Elsevier CAS single-column manuscript PDF supplied.
- [x] Anonymous editable LaTeX source archive supplied and clean-built.
- [x] Separate identified title page supplied.
- [x] Abstract is 211 words and below the recorded 250-word limit.
- [x] Keywords, highlights, declarations, CRediT statement, figure captions,
  glossary, data/code availability, and generative-AI disclosure supplied.
- [x] Journal PDF, TeX, and source archive contain no author identity.
- [x] Internal analysis labels are absent from the review PDF and public figures.
- [x] Adverse, null, undetermined, and unaccessed outcomes remain visible.
- [ ] Author confirms originality, exclusive consideration, funding, conflicts,
  ORCID disposition, licence, classifications, and any portal-only fields.
- [ ] Reopen the official Guide for Authors immediately before upload.
