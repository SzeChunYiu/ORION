# arXiv submission checklist

- [x] Attributed PDF and complete buildable source archive supplied.
- [x] Author, affiliation, and email appear in both PDF and source.
- [x] Abstract is self-contained and contains no citations.
- [x] Figures and references render without unresolved citations or references.
- [x] Internal analysis labels are absent from the PDF and reader-facing figure files.
- [x] Null, adverse, undetermined, and unaccessed outcomes remain visible.
- [ ] Author selects the arXiv licence and confirms category/cross-list choices.
- [ ] Author confirms portal metadata and submits the files.
