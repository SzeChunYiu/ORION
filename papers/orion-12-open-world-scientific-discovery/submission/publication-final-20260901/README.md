# ORION-12 publication package

This directory contains two filing objects generated from one scientific body:

- `arxiv/manuscript.pdf` and `arxiv/source.zip` are attributed and ready for an
  arXiv upload after the author selects the licence and confirms portal fields.
- `journal/manuscript_anonymous.pdf` and `journal/source_anonymous.zip` are the
  anonymous Elsevier CAS files for Information Processing & Management. Upload
  `journal/TITLE_PAGE.md` separately; do not merge it into the review manuscript.

The files are not interchangeable. The journal PDF/source are anonymous, while
the arXiv PDF/source identify the author. `PACKAGE_MANIFEST.json` binds both PDFs
to clean rebuilds from the distributed source archives, and `SHA256SUMS` binds
all package files.

Scientific scope is fixed: bounded acquisition-authority control, controlled
mechanism evidence, exact-contract conformance, an adverse descriptive
TREC-COVID recall and cost comparison, decision-inert ArguAna successors, provider-invalid OpenAIRE evidence,
and an unaccessed fresh 48-task campaign. No external retrieval-superiority or
open-world-completeness claim is made.
