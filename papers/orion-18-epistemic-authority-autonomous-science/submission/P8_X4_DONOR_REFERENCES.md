# ORION-18-X4 donor reference ledger for later bibliography integration

Date: 2026-08-19

This source ledger records the donor identities used by the V3 science update. It is not a claim of exhaustive literature coverage. Metadata should be re-audited when the final JAAMAS PDF/bibliography is regenerated.

## Action / delegation / authorization donors

- **FAVA — Formal Agent Verification Architecture**. arXiv:2607.27267. Contribution used by ORION-18: evidence-backed permission graphs, deterministic authorization and external runtime enforcement.
- **Proof-Carrying Agent Actions (PCAA): A Protocol for Evidence-Bound Execution in Agentic Systems**. arXiv:2606.04104. Contribution used: portable action identity, approval/runtime/outcome receipts and replay-ready proof.
- **Human Delegation Provenance (HDP)**. arXiv:2604.04522. Contribution used: cryptographically verifiable human authorization context propagated through append-only delegation chains.
- **SentinelAgent**. arXiv:2604.02767. Contribution used: deterministic authority narrowing, policy preservation, forensic reconstructibility, cascade containment and scope/action conformance.
- **Bounded Agents / Agentic Principal Chain**. arXiv:2608.15888. Contribution used: accumulated-session authorization, principal-chain restriction, composition closure and blast-radius monotonicity.
- **Evidence-Carrying Agents (ECA)**. arXiv:2605.19192. Contribution used: typed verifier certificates for action-critical predicates and deterministic privilege gates.
- **Authorization Evidence Chains: Composing Heterogeneous Agent-Action Evidence**. IETF Internet-Draft, `draft-schrock-ep-authorization-evidence-chain-04`, 2026. Contribution used: heterogeneous authorization-receipt composition, native verifier dispatch, canonical action binding and fail-closed requirement expressions.
- **Authority Resolution Framework (ARF)**. arXiv:2608.15832. Contribution used: generic cross-domain authority relation over actor/action/object/context/justification.

## Scientific claim / release / adjudication donors

- **CogEEGAgent**. arXiv:2607.25045. Contribution used: domain scientific harness separating semantic and scientific authority through typed analysis contracts, confirmation isolation and evidence-bound release.
- **ScientistOne / Chain-of-Evidence**. arXiv:2605.26340. Contribution used: claim-to-evidence chains, deterministic grounding, per-claim verification and integrity checks.
- **Xcientist**. arXiv:2606.18874. Contribution used: persistent contract-governed research artifacts linking evidence, ideas, implementation, ablations and validation with claim-drift control.
- **StatefulDiscovery**. arXiv:2606.11851. Contribution used: explicit investigation state and evidence-calibrated claim adjudication.
- **Evidence-Ledger Adjudication**. arXiv:2607.26512. Contribution used: claim/evidence packets, explicit support relations and routing of weak or contradicted claims for revision.
