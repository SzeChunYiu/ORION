# Anonymous review materials

This archive supports the manuscript **“Diagnosing Learning-System Failures Before Escalating Compute.”**

It contains:

- `evidence.json`: reader-facing primary-family outcomes, corrected matched resource vectors, and secondary positive, null, negative, adverse, and indeterminate results;
- `verify.py`: a standard-library verifier that recomputes the reported primary counts and checks that the limiting results remain present.

Run `python verify.py` in this directory. The verifier should report four successful checks.

The archive is intentionally limited to scientific review material. It contains no author identity, private development history, repository transport details, or execution-system receipts. The numerical tables are sufficient to reconstruct every aggregate outcome reported in the manuscript; they do not replace the full public research artifact planned after peer review.
