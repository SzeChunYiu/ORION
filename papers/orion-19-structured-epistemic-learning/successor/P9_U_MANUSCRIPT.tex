\begin{abstract}
Graph-structured reasoning, structured prompting, relational architectures, context compression, query interfaces and test-time scaling already show that presentation and access geometry can materially change reasoning performance. ORION Paper IX therefore targets a stronger claim: under matched semantic information and fully charged preprocessing, can one predict how representation changes the model scale, sample budget and inference compute required to reach a fixed verified quality target across task and model families? P9-U prospectively freezes the performance surface $Q(k,R,F,S,N,C)$ and critical frontiers $S^*,N^*,C^*$ rather than selecting one favorable benchmark point. Historical positive, tied and negative P9/P10 cells remain immutable. Every failed frontier cell enters \textbf{Adaptive Access Geometry Discovery (AAGD)}, which first rules out information leakage, answer-computing preprocessing, length, architecture and extra-compute explanations before proposing a new access coordinate, query interface or local operator. The intended terminal is \textbf{GENERAL\_REPRESENTATION\_ACCESSIBILITY\_SCALING\_LAW}, replicated across at least two open-weight model families and heterogeneous held-out domains.
\end{abstract}

\section{Donor boundary}
Structured reasoning is not the novelty claim. Graph Reasoning Paradigm uses graph-structured symbolic reasoning and structured evaluation for mathematical and code tasks \cite{grp2026}; StrucSum injects graph structure into long-document reasoning \cite{strucsum2026}; BRIEF-Pro supplies a strong context-compression route for multi-hop reasoning \cite{brief2026}. Graph/relational architectures, structured prompting, exact query engines, compression, representation compilers and adaptive test-time compute are all donor-owned.

P9's residual is the resource-frontier law: for complexity $k$, representation $R$, model family $F$, scale $S$, sample budget $N$, inference budget $C$ and verified target $q$,
\[
Q(k,R,F,S,N,C),\qquad S^*(k,q\mid R),\ N^*(k,q\mid R),\ C^*(k,q\mid R).
\]
The paper asks when information-equivalent access geometry changes these frontiers and when stronger models, architecture priors or more compute erase the effect.

\section{Matched-information requirement}
A structured arm is comparable to a flat arm only when semantic information equivalence is independently established by reversible round-trip or a frozen formal correspondence. Additional task labels, hidden intermediate answers or oracle-derived coordinates invalidate the frontier comparison.

Representation construction is never free. Tokenization, indexing, retrieval, graph construction, compilation, memory, storage and query generation are charged to the same total resource accounting. A preprocessing system that effectively solves the task is an oracle/donor computation, not evidence that a downstream model gained accessibility.

\section{Frozen factorial design}
The prospective grid varies relational/task complexity $k$, representation family $R$, model family $F$, model scale $S$, sample budget $N$, inference/search budget $C$ and verified target $q$. Primary analysis estimates predeclared threshold and crossover frontiers on the frozen grid. A power-law exponent is secondary unless its functional form and diagnostics are frozen before protected outcomes.

Representation families include flat/text serialization, reversible indexing, typed tuples/sets, typed graph state, query-matched interfaces, architecture-prior controls, adaptive-compute-only arms and representation-plus-adaptive-compute arms. Equal-token/length controls, order/symbol reminting, semantic-orbit controls and exact information checks are mandatory.

Task families span formal/mathematical relational reasoning, algorithmic/procedural reasoning, graph/dependency reasoning and at least one non-formal scientific/procedural domain. One domain is held out entirely from access-mechanic tuning.

\section{Adaptive Access Geometry Discovery}
AAGD is the ChatGPT-led negative-to-positive programme for failed/tied scale cells. It uses the existing ORION #586 causal classes: unknown operator/transformation, unknown failure applicability, wrong access geometry/serialization and wrong hypothesis/model class.

For each negative, the programme freezes a discriminator and tests, in order, whether the cause is information mismatch/leakage, token/length confound, preprocessing answer computation, architecture substitution, insufficient compute, exact donor solution, absent local operator, access geometry or hypothesis-class inadequacy. A new representation/query/operator is proposed only after lower-level explanations are excluded.

A proposed mechanic is positive P9 evidence only if it prospectively shifts a frozen frontier, transfers to fresh tasks or a second model-family cell, and remains beneficial after representation-construction cost is charged. A no-crossing cell remains a scientific result rather than being removed.

\section{Donor-complete baselines}
Required comparators include larger flat/text models, equal-parameter structured models, Graph Reasoning Paradigm-style structured reasoning \cite{grp2026}, graph/relational architectures, StrucSum-style graph prompting \cite{strucsum2026}, BRIEF-Pro-style compression \cite{brief2026}, exact task-sufficient query engines, adaptive inference/test-time compute, charged representation compilers, and a donor-complete system combining structure, architecture prior and adaptive compute. A second open-weight model family is mandatory for replication.

\section{Primary hypotheses}
H1: the critical model-scale frontier grows more slowly or crosses earlier under task-accessible representation. H2: matched-scale inference frontier is lower. H3: matched-scale/compute sample frontier is lower. H4: the effect survives information/length/reminting/orbit, architecture, preprocessing and stronger-model attacks. H5: the frontier shift replicates on a second open-weight model family and heterogeneous domains. H6: at least one retained negative yields a newly learned access coordinate/operator/query interface that transfers beyond the originating scale cell.

\section{Statistics and reporting}
The task instance or prospectively declared task cluster is the scientific independent unit. Repeated decodes, remints, scale checkpoints and seeds are technical repeats. Freeze task sampling, grid, threshold estimator, interval method, multiplicity, no-crossing handling and resource accounting before protected outcomes.

Report $S^*,N^*,C^*$, verified quality at matched resources, representation/token/memory/compile cost, robustness controls, cross-model/domain effects and every failure/no-crossing cell. The paper does not promote a frontier by selecting only cells where a crossing occurs.
