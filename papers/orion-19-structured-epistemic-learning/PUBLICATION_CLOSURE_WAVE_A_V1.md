# ORION-19 Publication Closure Wave A V1

## Maximum current claim

ORION-19 separates failure caused by unavailable information, inaccessible representation, and insufficient computation under a bounded resource ledger. Current evidence intentionally contains positives, a null, and a protected scaling negative. The open top-tier gate is whether the diagnosis survives hostile representation/format changes and transfers across independently developed public models/tasks without hidden resource transfers.

## Top-tier discriminator A — hostile representation/format attacks

Freeze a factorial attack panel before results. At minimum vary:

- semantically equivalent short versus long representation;
- canonical versus adversarial formatting/order;
- redundant versus compressed encoding;
- renamed identifiers with unchanged semantics;
- surface-similar representations with changed semantics;
- context-window boundary placement;
- serialization/parser variation;
- hidden preprocessing/cache availability.

Every attack must specify which latent class should remain unchanged and which observed access/computation measurements may change.

## Top-tier discriminator B — public multi-model/task transfer

- [ ] Select at least three unrelated open-weight model families or procedural systems whose checkpoints/configurations are public and immutable.
- [ ] Use public tasks with pre-existing labels/verifiers and at least two qualitatively different task families if claiming transfer.
- [ ] Keep model prompts/tools/information fixed across diagnosis arms; record tokens, latency, preprocessing, memory/cache, search, tool calls, retries, and reconstruction.
- [ ] Freeze task denominator and model revisions before outcomes.

Smaller public models are acceptable. Heterogeneity and auditability matter more than parameter count.

## Required comparators

- generic “add compute” escalation;
- generic “retrieve more information” escalation;
- generic reformat/re-encode intervention;
- strongest donor-composed diagnostic using all publicly available signals except ORION's structured distinction;
- oracle controls only when clearly labelled unattainable upper bounds;
- ORION-19 diagnosis/intervention policy.

## Primary endpoints

- failure-origin classification accuracy or verifier-backed intervention success;
- false compute escalation rate;
- false information-acquisition rate;
- false representation intervention rate;
- terminal flip/value after the prescribed intervention;
- full resource vector and Pareto/dominance analysis;
- abstention/CANNOT_CHECK and catastrophic regression.

Freeze margins, uncertainty, multiplicity, missing-run, timeout, parser-failure, and unsupported-model policies.

## Ground truth

Prefer intervention-based truth: a diagnosis is supported only when the prospectively specified intervention changes the outcome in the predicted direction while matched alternatives do not, under a verifier/official evaluator. Do not infer causal origin solely from model self-report.

## Hostile controls

- [ ] semantically null formatting changes;
- [ ] compute increase that cannot expose missing information;
- [ ] information increase in a task limited by computation;
- [ ] representation repair with unchanged access and compute;
- [ ] confounded intervention combining information and format, registered as invalid for causal attribution;
- [ ] label/prompt leakage scan;
- [ ] resource-accounting mutation tests;
- [ ] one model/task regime expected not to benefit.
