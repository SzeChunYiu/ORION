## Purpose

This packet selects the ORION papers nearest to a strong specialist or top-tier submission and turns their remaining gaps into an ordered, fail-closed execution wave. It does not grant novelty, scientific, journal, or submission authority. A paper moves only when the corresponding result/proof/package bytes exist and pass independent checks.

3. **ORION-23 — Responsibility-Carrying State:** close one public real-workflow transfer with responsibility ground truth and matched donor baselines.
4. **ORION-19 — Structured Epistemic Learning:** execute hostile representation/format attacks and multi-model/public-task transfer.

6. **ORION-17 — Epistemic Navigation in Open Worlds:** resolve target ambiguity and run a stronger external donor/lens comparator on public regime-change classes.
7. **ORION-22 — Adaptive State Reasoning:** execute the already named price-shift, task-shift, and hidden-parameter robustness suite.
8. **ORION-10 — Certified Static Forecasting:** add one independent compiler family and measure downstream decision value.

## Non-negotiable execution rules

- Fetch and record the exact current `origin/main` SHA before every paper lane.
- Read the paper's current manuscript, claim ledger/authority, result receipts, promotion/readiness documents, reproducibility instructions, and all active issues/PRs before editing.
- Do not duplicate an experiment already active on another branch or PR.
- Separate work into: `PACKAGE_ONLY`, `PROTOCOL_FREEZE`, `OUTCOME_EXECUTION`, `INDEPENDENT_REPLAY`, and `MANUSCRIPT_BINDING` commits. A package or prose commit cannot promote science.
- Prefer public authority external to ORION: official benchmark labels/evaluators, independently maintained datasets, original public baseline implementations, open-weight models, formal verifiers, standards, and public version histories.
- Isolated AI sessions may implement, audit, reproduce, and review. They must be labelled model-based audits/reimplementations, not human expert review.
- Freeze task, split, evaluator, baseline, model, preprocessing, resource, endpoint, multiplicity, missing-run, and adverse-terminal identities before accessing protected outcomes.
- Preserve every null, adverse, invalid, contaminated, unavailable, and `CANNOT_CHECK` outcome.
- Use the strongest donor product available. A weak proxy cannot support a superiority claim.
- Match semantic information, preprocessing, model/tool access, search/verifier calls, latency/cost accounting, and any cached state that can affect the outcome.
- Require an independent implementation, independent recomputation, or deterministic external verifier for every load-bearing result.
- No broad cross-domain wording from one domain. No universal wording from finite evidence. No top-tier status from text-only edits.

## Externality without collaborators

For this wave, “external” means independent of the ORION construction/evaluation loop, not necessarily another funded researcher. The preferred hierarchy is:

1. deterministic official/formal verifier or pre-existing ground truth;
2. original public implementation and official evaluator;
3. independently maintained public dataset/system/model with fixed labels;
4. faithful isolated reimplementation from a published specification;
5. blinded isolated-model adjudication with agreement analysis;
6. human/domain expert only where correctness cannot be made public or mechanical.

## Required commit sequence for each outcome-bearing lane

1. `protocol:` freeze question, hypotheses, split/task/model/baseline identities, endpoints, negative controls, resource vector, and all possible terminals.
2. `implementation:` add harness and outcome-blind hostile/self-tests only.
3. `execution:` run once on the frozen subject; archive raw outputs, environment, logs, failures, and receipt.
4. `verification:` reproduce from an isolated implementation/session or external verifier; compare exact headline values.
5. `paper:` update claim authority, manuscript, figures/tables, limitations, data/code statement, package manifest, and submission bytes from generated evidence only.

If the registered top-tier terminal fails, complete the strongest honest specialist paper instead. Do not tune a second relation, split, metric, baseline, or model after outcome access unless a new independent protocol is explicitly justified and frozen.
