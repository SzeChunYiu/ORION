# ORION-17 Publication Closure Wave A V1

## Maximum current claim

ORION-17 has bounded regime-transport theory and three non-synthetic change classes with strong within-class evidence. The top-tier gap is not more examples of the same type. It is to remove any assumed target-identity premise, compare against the strongest donor/lens product, and test transport on public regime changes whose outcomes were not authored for ORION.

## Good specialist finish

- [ ] Bind the current three-class result, exact theorem assumptions, target-ambiguity limitation, negative/path-dependent cases, independent replay, and resource accounting to one active manuscript/package.
- [ ] Avoid “arbitrary regime change” or universal-law wording.
- [ ] Ensure each change class has an explicit source, target, transported object, witness, failure condition, and authority boundary.
- [ ] Complete current references, clean reproduction, figure/table regeneration, target-fit decision, PDF audit, and package hashes.

The public target-ambiguity and donor-lens experiments below are **optional top-tier discriminators**. They are not prerequisites for a bounded specialist submission once the Good specialist finish is mechanically green.

## Gate A — resolve target ambiguity without assuming it

Before new outcome access:

- [ ] Define target candidates and the observable information available to every arm.
- [ ] Freeze an ambiguity detector that can return a set, abstain, or `CANNOT_CHECK`; it may not choose the target using post-change gold.
- [ ] Separate target identification from transport validity in analysis and claims.
- [ ] Include cases with unique target, multiple admissible targets, no admissible target, and misleading surface similarity.
- [ ] Register a premise failure terminal; do not discard ambiguous cases from the denominator.

## Gate B — strongest donor/lens comparator

Build the strongest feasible comparator from public prior mechanisms:

- value/state-only transfer;
- representation/provenance-aware transfer;
- dependency/path-aware transfer;
- always reopen/recompute;
- donor-composed lens using every public signal available to ORION except its proposed witness-aware transport law;
- ORION-17.

Use original public implementations where available; otherwise use isolated source-bound reimplementations with fidelity tests.

## Gate C — external public regime-change classes

Select at least two public classes materially different from the current internal construction. Feasible sources include:

- versioned schemas/representations with public migration tests;
- scientific workflow/provenance changes;
- public policy/configuration changes with validators;
- objective/obligation changes in public benchmark tasks;
- software/API version transitions with compatibility suites.

Freeze repository revision, change events, denominator, target truth, transport object, evaluator, and exclusions before execution.

## Primary endpoints

- target-identification accuracy/set coverage/abstention;
- valid transport coverage;
- unsound transport rate;
- needless reopen/reconstruction rate;
- outcome/task success;
- path-dependence violations;
- complete resource vector;
- CANNOT_CHECK and unsupported cases.

Unsound transport is non-compensatory: efficiency cannot offset a registered excess safety/validity failure.

## Secondary endpoints

- per-change-class error decomposition;
- ambiguity-set size and calibration;
- reconstruction latency and memory;
- donor fidelity failures and unsupported cases.

## Hostile controls

- [ ] same surface target but changed obligation;
- [ ] changed identifier but equivalent target;
- [ ] multiple plausible targets;
- [ ] target absent from candidate set;
- [ ] path-dependent transition whose direct endpoint comparison is insufficient;
- [ ] donor receives exactly the same metadata/history/tools;
- [ ] shuffled witnesses;
- [ ] resource-matched always-reopen baseline;
- [ ] one regime predicted not to transport.
