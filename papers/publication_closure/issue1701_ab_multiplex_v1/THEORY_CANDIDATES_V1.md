# Theory candidates v1 — competing, falsifiable routes

This file is an experiment/theorem queue, not a claims ledger. Every candidate has a predeclared rival or falsifier. A failed candidate is useful if it removes a whole class of rescue attempts.

## ORION-01 — certificate realization

**C1 source-complete grammar.** Treat completeness as an extensional equivalence between source-declared move constructors and runtime-emitted move kinds. The negative control is a deliberately hidden operation. A single undetected emitted move kills completeness.

**C2 confluence/termination.** Once C1 is complete, enumerate critical pairs and search for a machine-checkable well-founded measure. A non-joinable pair is a constructive theorem boundary, not a reason to increase the old search cap.

**C3 consequence.** Compare certificate-aware search to an information-matched baseline at the *same historical cap*. If the gain requires a larger cap, the old cap-limited identity is not rescued.

## ORION-04 — rooted completion

Run three routes concurrently: proof-producing complete D4 replay; a symmetry/orbit reduction theorem; and a prospectively specified construction search beyond the current finite boundary. Whichever route closes first determines whether the next paper is a theorem, a complete finite classification, or a sharp counterexample/construction paper.

## ORION-05 — TARE expressivity

**C1 finite basis:** all support-one gaps in the exact n=2 distinct-target all-matchings census contain a frozen obstruction.

**C2 relaxation law:** the historical fixed-matching 6/5 gaps disappear when matching is optimized too. This is already true for the three historical controls and may itself be the more general phenomenon.

**C3 gap-preservation class:** among repeated-target multisets, gaps that *survive* matching relaxation may form a small symmetry-closed class. Discover only on a calibration multiset subdomain; freeze; confirm on a disjoint subdomain.

These candidates share computation but have different terminals. C2/C3 are not fallback prose for a failed C1; they are separately testable theories.

## ORION-09 — compilation regime geometry

The universal compact-separator route is retired. New candidates are: (1) a theorem that exact-cost authority survives explanation failure under explicit containment premises; (2) a family-indexed obstruction atlas that predicts *which* compact explanations fail; (3) a separate practical-compiler value study that charges every feature/certificate cost. A negative C3 protects the theory paper from value inflation.

## ORION-10 — certified static forecasting

Use fibre mixedness to seek a **minimum explanation-vocabulary lower bound**, while keeping the theorem-backed exact forecast F2 separate. The strongest result would be a separation theorem: exact cost is cheaply certifiable, but any human-readable vocabulary below complexity K must mix exact-cost fibres. A second grammar is admissible only after the premises are frozen.

## ORION-14 — verified scientific discovery

Before any external transfer, determine whether the protected-campaign headline survives the true independent unit. Recompute on source/task families rather than 360 labels. If cluster-respecting uncertainty is null/undetermined, that is the terminal for the current effect size; do not compensate by adding labels inside the same families.

## ORION-17 — open-world navigation

The next experiment is not “more repositories.” It is **repositories selected to make the rival rules disagree before outcomes exist**. Density competes symmetrically with fixed module-count and edge-count thresholds. If neither wins, retire scalar-mechanism language and create a fresh higher-order graph-structure identity on a new cohort.

## ORION-19 — structured epistemic learning

Three hierarchical candidates: paired family-level decision advantage; cost-normalized net benefit; ambiguity-specific mechanism. The latter two unlock only if the first passes. This prevents a favourable mechanism slice or cost definition from rescuing a failed primary comparison.

## ORION-21 — state as computation

Do not repair the old width law. Quotient by tie-equivalence first. Candidate C1 is a representative-invariant phase statistic; C2 is an impossibility result for the registered feature family. Exhaustive finite failure of C1 can therefore become a clean negative theorem rather than another tie-handling patch.

## ORION-24 — recursive scientific evaluation

Competing explanations are explicit: **broad construct advantage** vs **negative-retention-specific advantage**. The external packet is balanced by construct family, not by raw case count. Frontier-agent benefit is a separate identity after construct validity; conformance of the governance machinery can never be substituted for agent performance.
