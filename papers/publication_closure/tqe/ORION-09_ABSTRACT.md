Algorithm selection and Instance Space Analysis already map where algorithms perform well. We ask a narrower question for exact quantum-compilation families: which boundaries are intrinsic, which are only proof-system ceilings, which depend on the objective, and when is a proposed regime boundary not identifiable from the chosen features? We organize these objects as a compilation regime geometry rather than a universal phase diagram. In shared-Tag R6M TARE, an all-`n` theorem confines exact optima to frame support at most two even though exact counterexamples repeatedly defeat smaller named support-two families. In a distinct R6I grammar, whole-system normalization proves the tight intrinsic result `kappa=1`, while a separate objective-indexed cone specifies where that certificate remains valid and a conserved-syndrome analysis supplies a looser safe ceiling. SixLCU exhibits a theorem-grade simple incumbent-exact boundary. StabPrep supplies the opposite outcome: a prospectively frozen `n=4` forecast is refuted, and the registered feature vocabulary contains mixed cells with opposite donor-exactness labels. Current learned compiler-option selection and pass tuning therefore remain prior work; the residual contribution is exact family-specific geometry linking witnesses, intrinsic support, certified ceilings, objective validity, feature identifiability, and prospective falsification.
