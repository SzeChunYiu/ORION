## Priority 1 — ORION-21: tie-robust phase boundaries

### Candidate ID

`ORION21.TIE_ROBUST_PHASE.v1`

### Trigger

The exact-anchor forensic successor in #1612 localizes the NR07 n=64 discrepancy to one top-r support-boundary equality class. At cell `[14,3,3]`, query 0 has fixed features `16,311` and three legal candidates `35,93,263`, all tied at absolute correlation `24/64` for the final support slot.

The three tie-consistent aggregate worlds have exact accuracies

- `19438/20480 = 0.94912109375`,
- `19439/20480 = 0.949169921875`,
- `19476/20480 = 0.9509765625`.

Therefore the under-specified tie is not merely a one-count reproducibility nuisance: the admissible result set **straddles the registered 0.95 phase threshold**.

### Candidate theorem — tie-robust threshold criterion

Let a frozen scoring rule induce a nonempty set `S(x)` of all supports consistent with its declared ordering, including every equality-boundary choice. Let `M(s,x)` be the exact downstream metric for support `s`, and let `tau` be a preregistered phase threshold.

A threshold conclusion for input `x` is tie-robust iff

`max_{s in S(x)} M(s,x) < tau`

or

`min_{s in S(x)} M(s,x) >= tau`.

If

`min M < tau <= max M`,

then no implementation-specific tie ordering can establish the phase label unless that secondary ordering was itself part of the prospectively frozen scientific object.

This criterion is almost definitional once `S(x)` is made explicit; the scientific work is to make the set-valued support semantics part of the registered measurement object and to characterize when equality classes occur.

### Strongest falsifier

Show that the registered phase claim remains invariant after exhaustive enumeration of every top-r equality class on every protected cell, or prove that the scientific estimand was always a specific prospectively bound deterministic secondary order rather than the score-defined support class.

The current NR07 anchor fails the first route because its admissible interval crosses 0.95.

### Minimal successor

Freeze `ORION21.NR07.TIE_ROBUST_PHASE.v1` with:

1. exact integer correlations, never floating comparison tolerances;
2. a support-identification margin `gamma = score_(r) - score_(r+1)`;
3. exhaustive enumeration whenever `gamma=0`;
4. raw ordered labels/predictions and exact rational scores for each admissible support world;
5. a primary set-valued phase interval `[min M,max M]`;
6. a deterministic secondary tie key only for byte reproducibility, explicitly not substituting for tie-robust scientific authority;
7. a structurally independent scorer.

If the protected phase statement is tie-robust, retain it. If it straddles the phase boundary, remove the point phase claim and report the ambiguity as the result.

## Priority 2 — ORION-02: fibre ambiguity implies a coverage-risk frontier

### Candidate ID

`ORION02.FIBRE_AMBIGUITY_RISK.v1`

### Trigger

The existing theorem paper already proves exact representation fibres: for every `t>=1`, two compiler families `A_t,B_t` have identical complete labelled pair information but exact improvements

`Delta_A = 12t-2`, `Delta_B = 10t-1`,

and incompatible optimizer structure. R24 then repaired empirical coverage to `44/44` but its raw selected-development fibre maximum violated on `20/44` held-out decisions; the matched no-geometry lexical control also covered `44/44`.

This suggests a stronger explanation than “geometry needs another tuning pass”: **coverage of a representation fibre is not the same object as calibration of the target conditional on that fibre.**

### Candidate theorem — accepted-fibre diameter lower bound

Let `phi(x)` be the information available to a certificate and let the target be a real value `V(x)`. For any representation fibre

`F_z = {x : phi(x)=z}`,

define its target diameter

`D(z) = sup_{x,x' in F_z} |V(x)-V(x')|`.

Any deterministic point certificate `c(z)` accepted on the whole fibre has worst-case absolute error at least

`D(z)/2`.

More generally, any accepted interval of radius `< D(z)/2` must miss at least one member of that fibre. On a balanced two-point distribution supported on a diameter-attaining pair, conditional miscoverage is at least `1/2`.

For the existing `A_t/B_t` pair-information fibre,

`D(z) >= 2t-1`,

so any pair-only accepted point certificate has radius at least `(2t-1)/2`; an integer certificate needs radius at least `t`. The already-proved multiplicative pair also gives a one-sided factor obstruction approaching `6/5` unless the fibre is rejected or refined.

### Scientific implication

The empirical successor should not optimize raw coverage first. It should estimate or upper-bound **accepted-fibre ambiguity/risk** and allow abstention where the observed representation cannot support the requested certificate.

Geometry earns value only if it refines lexical fibres in a way that measurably shrinks held-out target ambiguity; 44/44 geometric coverage by itself is irrelevant if the conditional target spread remains large.

### Strongest falsifier

On prospectively held-out data, show that the proposed refined representation has high coverage while its calibration-set upper risk bound controls held-out violation at the registered level, and that removing the geometric refinement materially worsens the same risk/coverage frontier. If the lexical representation achieves the same frontier, geometry has no residual empirical role.

### Minimal successor

`ORION02.SELECTIVE_FIBRE_RISK.v1` should use disjoint train/calibration/test partitions and predeclare:

- an accepted-fibre risk functional rather than a raw selected maximum;
- finite-sample calibration/UCB logic;
- coverage as a co-primary quantity, not a substitute for validity;
- matched lexical and strongest learned controls with identical information/budget;
- explicit abstention;
- the theorem-level impossibility witness as a negative control.

Generic conditional-coverage/conformal-risk theory is donor-owned. The possible ORION residual is the exact compiler fibre-diameter obstruction plus a prospective test of whether a specific representation refinement reduces that obstruction.

## Priority 3 — ORION-22: observation aliasing exactly characterizes zero-regret robustness

### Candidate ID

`ORION22.OBSERVATION_ALIASING_ROBUSTNESS.v1`

### Trigger

The frozen allocator transfers unchanged on the registered exact domains, but the robustness stress records `price_axis=BROKEN` and `distribution_shift_axis=BROKEN`. A separately preregistered price-aware successor has zero priced regret across 195 frozen cells conditional on exact published charge certificates; forward-time availability of those certificates remains `CANNOT_CHECK`.

### Candidate theorem — common-optimum intersection criterion

Let `E` be a finite environment family, `h:E->Z` the information available before action, `A` the action set, and `O(e) subseteq A` the set of optimal actions in environment `e`.

There exists a deterministic observation-based zero-regret policy `pi:Z->A` iff, for every observation class `z`,

`intersection_{e: h(e)=z} O(e) != emptyset`.

**Necessity:** one action `pi(z)` must be optimal for every environment sharing observation `z`.  
**Sufficiency:** choose any action in the nonempty common-optimum intersection for each class.

This gives an exact distinction between a **policy failure** and an **information failure**. If a price-blind observation class contains environments with disjoint optimal-action sets, no retuning of a price-blind policy can make it robust. A certificate/price refinement helps only by splitting such aliased classes until the common-optimum condition is restored.

### Strongest falsifier

Recompute the frozen robustness battery at the information-class level. If every original price/shift-blind class has a nonempty common-optimum intersection, the observed BROKEN result is policy-specific and this theorem does not explain it. If some intersections are empty and the exact-certificate refinement resolves them, the negative becomes an information-theoretic boundary rather than a tuning failure.

### Minimal successor

No new stochastic campaign is initially required. Build an independent analyzer over the already-frozen battery that reports:

- observation equivalence classes under the original allocator inputs;
- optimal-action sets per environment;
- common-optimum intersections;
- the coarsest tested refinement that removes empty intersections;
- a forward-time availability flag for every refining field.

If the theorem survives the existing battery, a later prospective study can ask whether the required refinement is observable before action in a realistic domain.

State abstraction/partial-observation theory is donor territory. The ORION object is the exact criterion instantiated on the registered resource-allocation contract and its frozen adverse battery.

## Priority 4 — ORION-11: costed responsibility ordering after faithful-comparator falsification

### Candidate ID

`ORION11.COSTED_RESPONSIBILITY_ORDERING.v1`

### Trigger

The R4 faithful comparator in #1603 kills comparative mechanism necessity: `activevoi_search_admitted_parent` matches ORION on the registered hidden-shift success/safety criterion. But the traces expose a different candidate quantity. On the frozen run, both achieve hidden-shift success `1.0` with forbidden high-level mutation `0`, while mean spent budget is approximately `1.8341` for ORION and `2.6676` for the faithful Active-VOI search comparator.

That gap is not yet scientific authority, but it points to a cost/search-economy question instead of another necessity claim.

### Candidate theorem — priced diagnosis ordering

In the simplest model, exactly one latent repair class `i` is correct, prior/posterior mass is `p_i`, checking class `i` costs `c_i>0`, checks are serial, and search stops when the correct class is found. An expected-cost-minimizing order sorts by nonincreasing

`p_i/c_i`.

The proof is the standard adjacent-exchange argument: for two adjacent candidates `i,j`, placing `i` first is no worse exactly when `p_i/c_i >= p_j/c_j`.

With dependency precedence constraints, any adjacent incomparable inversion of this ratio can still be swapped to weakly reduce expected cost; therefore an optimal topological ordering has no such swappable inversion.

### ORION-specific hypothesis

Responsibility typing is useful only insofar as it improves one or more measurable terms in this cost problem:

- better probability/risk ordering of repair classes;
- lower safe intervention cost;
- lower dependency-reopening cost;
- fewer forbidden high-level mutations at equal task success.

The generic `p/c` ordering is donor-owned. The ORION question is whether responsibility-targeted state supplies enough structured information to improve the **costed, safety-constrained** search over a faithful comparator with the same action/search authority.

### Strongest falsifier

A prospectively frozen simple cost-aware Active-VOI/`p/c` comparator matches or beats ORION on expected total cost while preserving the same task-success, sibling-regression, and forbidden-mutation gates.

If that happens, withdraw the search-economy advantage too.

### Minimal successor

`ORION11.COSTED_EPISTEMIC_ORDERING.v1` should bind every action trace and decompose cost before outcomes into inspection, intervention, reopening, and total units. The primary comparison is conditional on both systems satisfying identical success/safety gates; only then compare cost. Include the simple `p/c` donor baseline, not merely the old uncosted parent.

## Priority 5 — ORION-25: security comes from independent trust domains, not chain length

### Candidate ID

`ORION25.TRUST_DOMAIN_FRONTIER.v1`

### Trigger

The attestation-composition study detects all registered non-compromise tamper/replay attacks with zero observed valid-workload false rejection, yet full key-set compromise is detected `0/6` at the signature layer. Treating a valid chain as scientific truth false-promotes every forged-clean compromise case. Production key custody and real Sigstore/in-toto-class comparison remain open.

### Candidate theorem — trust-domain threshold law

Partition required attestations by independently compromisable trust domains. For an acceptance rule, define its **compromise threshold** as the minimum number (or minimum attack cost) of trust domains whose compromise is sufficient to construct an accepted forged record.

Adding signatures inside one common compromise domain does not increase this threshold. In particular, a serial `k`-link chain whose signing authorities share one compromise domain can still have threshold `1`.

For an AND rule over genuinely independent domains with compromise probabilities `q_d`, the idealized false-promotion probability from key compromise is

`product_d q_d`.

If benign domain failure probabilities are `f_d`, the corresponding availability-side false-rejection probability is

`1 - product_d (1-f_d)`.

Threshold/t-of-k rules move along a false-promotion/false-rejection frontier. Under common-mode or correlated compromise, the multiplicative security gain can disappear.

None of these cryptographic statements establish fact truth or scientific validity; a semantic/scientific admission layer remains separately necessary.

### Strongest falsifier

A purported multi-root deployment has a shared compromise path, or independent-root separation fails to improve false-promotion resistance under matched attack models after accounting for false rejection and overhead. Either result narrows the design claim.

### Minimal successor

Extend the production-like fault campaign with:

- same-domain three-link chain;
- genuinely separated trust-domain chain;
- independent-root compromise, common-mode compromise, stale/replay/substitution, host/process faults;
- matched false-promotion and false-rejection endpoints;
- runtime/storage/verification overhead;
- cross-site replay where available.

Supply-chain attestation and generic trust-metric theory are donor areas. The ORION residual is the measured scientific-admission boundary and the cost/error tradeoff under realistic execution faults.

Later larger bounded search still terminates `CANNOT_CHECK_MOVE_COMPLETENESS`.

The missing object is therefore not another state cap. It is scheduler/control context.

### Candidate formal object

Model the production compiler as a labelled transition system over configurations

`C = (semantic graph/state, scheduler context)`.

A source transition schema includes at least:

`(control location, rule/macro identity, exact application guard/match class, context update)`.

Let `Q` be a finite quotient of production configurations preserving every future-relevant guard/control distinction and the semantic/resource observables used by the certificate experiment.

### Candidate theorem — quotient soundness/completeness contract

If the quotient map is:

1. **transition-preserving:** every production transition maps to a quotient transition;
2. **transition-reflecting:** every quotient transition has a production witness in every represented context for which it is exposed;
3. **observable-preserving:** semantic-equivalence and registered resource observables are constant on each quotient class;

then quotient reachability is sound and trace-complete for the production scheduler relative to the represented source grammar.

The theorem itself is a standard transition-system fact. The hard scientific task is constructing a **source-complete finite quotient** for the pinned compiler rather than assuming callable macros form the language.

### Strongest falsifier

Find either:

- a real `full_reduce` production transition absent from the quotient;
- a quotient-exposed transition with no production witness in the represented scheduler context;
- two concrete scheduler states collapsed into one quotient class that differ in legal next schemas or registered semantics.

Any one is a genuine completeness failure.

### Minimal successor

Build `ORION01.SCHEMA_QUOTIENT_REALIZATION.v1` from source control flow, not observed execution traces alone. Enumerate schemas and guards independently, prove/verify the quotient contract, then run certificate-realization search over quotient states. # Cross-paper research principle

The six failures share one useful design principle:

> **Information sufficiency is claim-relative.**

- ORION-01: state without scheduler context is insufficient for sound production moves.
- ORION-02: pair/fibre information can be sufficient for one decision while insufficient for value/certificate validity.
- ORION-11: success alone is insufficient to distinguish faithful policies; cost and safe reopening may be the discriminating quantities.
- ORION-21: a score with a boundary tie is insufficient for a unique support or point phase label.
- ORION-22: an observation class is insufficient for robust action when its environments have no common optimal action.
- ORION-25: attestation is sufficient for some integrity/attribution facts while insufficient for custody, fact truth, or scientific authority.

This is a research-design principle, not a portfolio novelty claim. Generic sufficiency, abstraction, information, search, risk-control, and trust theory remain donor-owned.
