# ORION papers

The paper tree is a first-class projection of the executable framework, not a separate historical archive.

## Rule

A paper may describe only mechanics present in the canonical ORION registry or explicitly label a mechanic as proposed/research-only. Framework-changing commits must update the paper snapshot when they alter a published mechanic, state coordinate, authority rule, or saturation rule.

## Current programme

- `paper-01-recursive-epistemic-reconstruction/` — active working draft for the core framework and recursive engine.
- `paper-02-global-knowledge-portrait/` — planned paper on absorption, GLUE/JUMP, representations, and global portrait reconstruction.
- `paper-03-verified-discovery/` — planned paper on evaluation, verification and protected scientific authority.
- `paper-04-self-orion/` — planned paper on failure learning and governed method evolution.

RAKL papers remain immutable provenance and are selectively remapped in `legacy-rakl-map.md`.
