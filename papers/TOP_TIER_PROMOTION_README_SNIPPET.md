# ORION-16–ORION-25 top-tier promotion entry point

The active upward-claim promotion programme is `TOP_TIER_PROMOTION_PROGRAM_V1.md` and issue #977.

Every ORION-16–ORION-25 paper now carries `TOP_TIER_PROMOTION_V1.md`. These files do **not** promote scientific authority. They define the maximum claim to earn, strongest donor-product baseline, protected evidence required, hostile falsifiers, independent-authority rule and paper-specific `TOP_TIER_SUBMISSION_READY` gate.

The programme deliberately distinguishes the repository's existing bounded/controlled peer-review-ready terminals from a stronger top-tier external-promotion terminal. Existing controlled results remain valid; broader cross-domain/real-system claims remain pending until protected external evidence closes their gates.

The normative policy is: absorb nearest work rather than avoid it, generalize the scientific question upward, and preserve negatives/nulls/subsumed results while testing the stronger claim.
