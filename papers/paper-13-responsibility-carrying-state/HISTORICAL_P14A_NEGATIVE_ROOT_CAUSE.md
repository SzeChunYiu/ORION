## Harness root cause

The old runner's `bayes_acc` function:

1. groups the finite sample by compact representation;
2. chooses the majority target value within each group using that same sample;
3. evaluates the chosen majority on the same observations;
4. compares the resubstitution score to the population value;
5. takes the maximum absolute deviation across all representations/tasks and 100 independent replicates.

This is an indirect and unstable sentinel for the exact responsibility question. Same-sample majority selection creates resubstitution optimism, while taking the maximum over 100 replicates creates an extreme-value penalty. The observed replicate-92 value is therefore evidence that the registered sentinel failed, not evidence that the exact population ladder is wrong.
