# ORION-21 submission declarations interface

This file separates scientific closure from author-controlled submission attestations.

## Data and code availability

The result-bearing source manifests, invalidated and corrected result archives, null distributions, native receipt records, checker scripts, mutation tests, and reproduction instructions are committed in the ORION repository under `papers/candidates/paper-10-content-bound-math-evaluation/`.

## Reproducibility

The manuscript's source-analysis claims are reproducible from committed artifacts and scripts. Native replay additionally requires the exact upstream Mathlib checkout and Lean 4.34.0-rc1 environment recorded in `P11_REPRODUCE.md`.

## Generative AI use

Generative AI systems were used as research and writing assistants in the ORION programme. Model output is not treated as experimental authority. Result-bearing claims are restricted to committed artifacts, protocol records, external primary sources, native checks, and mechanically checkable repository evidence.

## Ethics / human subjects

The reported study evaluates public formal source code, proof-assistant execution, and repository artifacts. It reports no human-subject experiment.

## Author-controlled fields

The repository does not infer or fabricate the following submission attestations:

- institutional affiliation;
- funding statement;
- competing-interest declaration;
- ORCID;
- acknowledgements involving external people or organizations;
- preferred/non-preferred reviewers.

These fields must be confirmed by the author in the journal/conference submission portal. Their absence from this repository file does not alter the scientific claim ledger.
