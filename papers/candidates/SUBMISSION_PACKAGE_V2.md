## Paper VI

### Title
**Formal Epistemic Structures and Mechanics**

### Short abstract
Scientific agents update more than propositions: they change representations, procedures, evidence bindings, certified claims and authority-bearing state. We present a typed mechanic-contract semantics that engulfs dependency maintenance, incremental computation, effect typing and authorization as donor structures while distinguishing computational change from scientific admissibility. The theory gives root-inclusive certificate-aware reopening, history-aware composition, hard-obligation persistence, non-escalating authority and a typed-erasure separation theorem showing that identical bare computation/dependency semantics can have different scientific admissibility.

### Keywords
knowledge representation; formal reasoning; truth maintenance; incremental computation; agent effects; scientific provenance; epistemic authority; autonomous science.

### One-sentence contribution
**Computationally correct repair is not sufficient to preserve scientifically certified state when obligations, provenance and commit authority are active.**

### Primary venue path
Artificial Intelligence (AIJ).

## Paper VII

### Title
**Epistemic Navigation in Open Worlds**

### Short abstract
Open-ended scientific inquiry can change not only the current search state but the representation and objective that define reachability and completion. We formalize an epistemic atlas that engulfs fixed graph navigation, belief-space planning, planning abstraction, schema transformations, goal evolution and world-model revision as donor structures. We prove an open-world stopping result under extension ambiguity, a fixed-information representation-refinement solvability result with a harmful-coarsening control, and a separation theorem showing that evidence can remain valid while scientific closure fails to transport. Complete support/obligation witnesses license closure transport; ambiguous incomplete transforms must reopen or return `CANNOT_CHECK`.

### Keywords
open-world search; planning; knowledge representation; abstraction; representation change; goal evolution; scientific discovery; stopping criteria.

### One-sentence contribution
**Evidence can survive a representation or objective change without carrying the old authority to declare the scientific task complete.**

### Primary venue path
Artificial Intelligence (AIJ).

## Paper VIII

### Title
**A Theory of Epistemic Authority for Autonomous Science**

### Short abstract
Autonomous scientific systems combine capabilities governed by heterogeneous evidential standards: reframing, search stopping, semantic merging, scientific assertion and self-modification. We engulf authorization logic, usage control, effect systems, multi-authority governance, provenance and abstention as donor mechanisms and formalize the remaining interface: which source judgments discharge which target scientific obligations. Every judgment is typed by domain, kind, scope, content and epoch; cross-domain use requires a protected composable coercion; revocation respects alternative complete derivations; and commit-time freshness is mandatory. A product-decomposition theorem proves that a shared calculus is not intrinsically more expressive than an ideal typed product of domain gates, ruling out centralization as a novelty claim.

### Keywords
AI agents; authorization; epistemic authority; provenance; abstention; usage control; scientific verification; autonomous science.

### One-sentence contribution
**Generic permission or success in one agent subsystem does not become scientific authority in another unless the exact target obligation is discharged.**

### Primary venue path
Autonomous Agents and Multi-Agent Systems (JAAMAS).
