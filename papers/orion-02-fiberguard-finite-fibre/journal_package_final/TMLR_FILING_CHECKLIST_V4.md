# ORION-02 TMLR filing checklist V4

Official guidance checked on 2026-08-31:
- https://jmlr.org/tmlr/submissions.html
- https://jmlr.org/tmlr/editorial-policies.html
- https://jmlr.org/tmlr/author-guide.html

## Repository-side complete

- [x] Anonymous review PDF uses the mandatory unmodified TMLR style.
- [x] Manuscript is complete and may be any length under current guidance.
- [x] Venue-budget ledger records the measured seven-page PDF and does not invent a total word/page limit.
- [x] Anonymous supplementary ZIP is below the 100 MB limit.
- [x] Source and supplement archives are deterministic and digest-bound.
- [x] Negative, null, retracted and CANNOT_CHECK boundaries are visible.
- [x] Data/code availability distinguishes enclosed rechecks from upstream reruns.
- [x] Generative-AI disclosure assigns responsibility to the author.
- [x] PDF and supplement passed anonymity checks.
- [x] Manuscript-excellence E1-E9 and section-function audit is materialized for independent clean-reader review.
- [x] TMLR source revision and style-file revision are recorded.
- [x] A separate identified arXiv preprint PDF and source archive are built from the identical scientific body using the official TMLR `preprint` option.
- [x] The identified arXiv artifacts are excluded from the anonymous TMLR upload set and are not linked from the review submission.
- [x] CC BY 4.0 submission licensing requirement is recorded.

## Human confirmation before upload

- [ ] Approve final title, abstract, manuscript, author order and contribution.
- [ ] Confirm every author satisfies TMLR authorship criteria.
- [ ] Confirm every author has a complete active OpenReview profile.
- [ ] Confirm every author has sufficient annual TMLR submission quota.
- [ ] Confirm no overlapping publication or disallowed dual submission.
- [ ] Complete institutional and personal conflicts accurately.
- [ ] Complete funding and competing-interest declarations.
- [ ] Confirm human-subject/IRB response and broader-impact/risk response.
- [ ] Recommend appropriate non-conflicted action editors.
- [ ] Upload the PDF and anonymous supplement.
- [ ] Inspect the portal-rendered files before final submission.
- [ ] Preserve the final OpenReview submission identifier after filing.

No unchecked item above grants or withholds scientific authority; these are author and portal actions.
