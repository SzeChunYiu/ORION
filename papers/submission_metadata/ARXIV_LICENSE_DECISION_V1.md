# ORION arXiv license decision V1

**Decision date:** 2026-08-30  
**Selected license for every initial ORION arXiv submission:** arXiv.org perpetual, non-exclusive license to distribute.

## Reason

This license permits arXiv to distribute each submitted version while preserving the widest practical flexibility for later journal copyright or licence arrangements. The choice is version-specific and irrevocable for a posted version. It does not transfer copyright ownership to arXiv and it does not by itself make repository code, data, third-party figures, or protected evidence redistributable.

## Submission rule

Before each upload:

1. confirm the author has the right to submit every source file, figure, table and supplement;
2. exclude third-party material whose licence does not permit arXiv redistribution;
3. upload the complete TeX source and every required figure/style/bibliography file when TeX is used;
4. inspect arXiv's generated PDF before final submission;
5. record the arXiv identifier and exact source/PDF hashes after announcement;
6. update the journal package to cite the preprint without changing the scientific claim boundary.
