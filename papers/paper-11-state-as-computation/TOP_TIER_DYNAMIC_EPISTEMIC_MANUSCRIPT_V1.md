## Abstract

A scientific state is a placement of computation. Compiling a compact state may save future reasoning while losing optionality, imposing compiler cost, or laundering protected answers. P11 defines a dynamic state/compiler/decoder system with responsibility quotients, compilation, service horizon, drift, invalidation, recovery, and total resource vectors. It absorbs sufficient representation theory, information bottlenecks, caching, partial evaluation, memory systems, and communication complexity. We derive responsibility sufficiency, width lower bounds, compile/reason phase laws, optionality boundaries, and no-answer-laundering. Learned compilers will be compared with raw/full context, retrieval, oracle compilers, feature selection, partial evaluation, and stronger decoders across real long-horizon and formal systems.
