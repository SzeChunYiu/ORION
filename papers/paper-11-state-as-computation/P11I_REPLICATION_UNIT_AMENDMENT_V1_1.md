# P11I replication-unit amendment v1.1

This amendment corrects an experimental-unit description; it does not change a
seed, geometry, query, attack, threshold, gate, terminal or measured value.

`P11I_WIDE_HIGH_WIDTH_REPLICATION_PROTOCOL_V1.md` called each seed-by-geometry
cell an independent unit.  The three geometry levels are fixed repeated
conditions crossed inside each stochastic execution seed.  The independent
random unit is therefore the execution seed (`n=3`), and the experiment contains
nine prespecified seed-by-geometry cells.  The five queries remain technical
repeated measurements inside each cell.

All nine cells must still pass noncompensatorily.  This correction reduces the
reported independent replication count from nine to three and grants no broader
claim authority.
