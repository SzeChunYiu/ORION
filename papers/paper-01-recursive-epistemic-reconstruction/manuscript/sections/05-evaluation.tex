\section{Falsifiable hypotheses and current evidence}

\subsection{Hypotheses}

The research object defines a prospective comparison rather than a success-by-definition architecture claim. The outcome-blind external design is frozen as \texttt{P1.hidden-formulation.v1}. Its primary hypothesis is:

\begin{quote}
On tasks where the initial formulation, representation, decomposition, measurement model, or relevant search universe is insufficient, full ORION improves root task success versus the strongest matched static or recursive baseline.
\end{quote}

The safety/mechanistic secondary hypotheses test whether ORION avoids unnecessary reframes on evidence-only/execution-only controls, reopens dependent closure more precisely than no reset or full reset, and preserves mechanic obligations and authority/invariant structure with recursion depth. The design target for the primary superiority comparison is an absolute root-success improvement of at least five percentage points; unnecessary-reframe rate is prospectively guarded by a two-percentage-point non-inferiority margin. These are design thresholds, not claimed outcomes.

The registered task families are hidden parent-domain, hidden representation/coordinate system, hidden decomposition/interface, hidden measurement/operationalization, evidence-only negative controls, and execution-only negative controls. Required matched baselines include a static tool workflow, iterative/tree research, an AREX-like recursive audit/follow-up controller, a SCION-like dependency-aware execution plan, and an Iris-like revisable information-state controller. Full ORION is separately ablated by removing explicit $W$, explicit $M$, typed reframing, dependency-directed reopening, and mechanic self-audit.

The evaluation packet tracks root success, hidden-shift success, unnecessary-reframe rate, responsibility macro-F1, reframe-target accuracy, reopen precision/recall/F1, stale-closure survival, invariant/authority violations, trace fidelity and resource cost. Candidate-caused failures, timeouts, malformed actions and abstentions remain in the denominator. Standalone rates receive Wilson intervals; matched system differences use a paired percentile bootstrap over frozen tasks, with stochastic repetitions nested within task/system.

\subsection{Prospective design freeze}

The complete machine-readable design is stored at \texttt{protocol/PROTOCOL\_V1.json}, with case requirements in \texttt{protocol/HIDDEN\_SHIFT\_CASE\_SCHEMA\_V1.json}. Its state is \texttt{DESIGN\_FROZEN} and \texttt{outcome\_accessed=false}. This freezes hypotheses, task families, baselines, ablations, metrics, resource/exclusion rules, statistics, access policy and result-figure/table definitions before final outcomes exist.

This is deliberately weaker than an execution freeze. The final subject revision, hidden-shift case-set hash, model/provider versions, baseline configuration hashes, protected evaluator/adjudication hash, split hashes and evaluation epoch remain unbound. Those identities must be frozen before the first final test outcome is inspected; otherwise the run cannot support the publication claim. Any post-outcome scientific-design change creates a new protocol version rather than rewriting V1.

\subsection{Frozen local falsifier V1}

The repository contains a deterministic Paper-I suite covering hidden-domain, hidden-representation, missing-evidence, and execution-only worlds. At the frozen evidence snapshot, the suite passed at commit
\texttt{8a8a7feed588363f8e2cd820d3399a33b7af3074}
with CI run \texttt{31933432314}.

The important local result is not the pass label alone. The suite exposed an over-broad rule: singular \texttt{EVIDENCE}/\texttt{EXECUTION} responsibility could previously enter the reframe path. That behavior would have allowed the system to rewrite the formulation when ordinary evidence acquisition or execution repair was the supported response. The gate was changed so those cases can no longer reframe merely because responsibility is singular.

This is architecture-local falsification evidence. It supports the claim that the implemented contracts distinguish at least these registered known worlds and that the falsifier was capable of changing the design. It does not establish open-world adequacy or external superiority.

\subsection{Historical parent-domain replay}

A bounded replay reconstructs a RAKL-era omission in which computational linguistics and psychometrics were not explicit members of a frozen discipline basis. Because the historical workflow also required cross-domain and alternate-vocabulary search, the omission does not prove that faithful execution could not have discovered those fields. The original retrieval and recognition trace is not registered, so the historical cause remains only partially identified.

The current discriminator instead asks whether name-independent functional signatures can recover mature parent disciplines for scientific-language interpretation, construct/benchmark validity, and fresh transfer cases. Success shows that these known worlds can be expressed without inventing a new method primitive. It does not establish open-world parent-discipline recall.

\subsection{External promotion gate}

The publication-level test remains unexecuted. Final evidence requires the execution bindings above, fresh hidden-formulation tasks, matched current baselines, protected labels/evaluation, and the frozen statistical analysis. Until those conditions are satisfied and the external evidence manifest is independently bound, the external state is \texttt{CANNOT\_CHECK}. Repository tests and the prospective protocol cannot convert that state into a novelty or superiority claim.
