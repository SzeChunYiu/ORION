\section*{Data and Code Availability}
All primary study worlds in this manuscript are synthetic and generated deterministically
from frozen protocols and code. The anonymous review package supplies the result receipts for
the six primary studies and two donor/negative controls together with the code required to
replay the bound computations. Repository identity and permanent public-release metadata are
withheld from the review version to preserve double-blind evaluation and will be restored in
the named archival version after the corresponding release is deposited and authorized. No
protected or private human dataset is used in this study.
