## Common benchmark delta

The unifying object is not any one primitive. It is the family-level experimental contract:

`same factual world -> vary explicit epistemic relation used by the decision rule -> matched strong comparator -> hostile/no-value control -> exact bounded terminal`.

The six studies were preregistered separately. The cross-family `epistemic binding` taxonomy is a post-study synthesis and must remain labeled as such.
