\section{Data and code availability}
\label{sec:availability}

The public-reference case records, source registry, frozen confirmatory
protocol, deterministic analysis, generated tables and separate-implementation
verification record are included in the versioned research package supporting
this manuscript. The initial and confirmatory case archives are bound by
256-bit Secure Hash Algorithm (SHA-256) digests
\nolinkurl{35f9e39b75ff53b7f0ec82cd03ebcaaa82509ee0aea3f5b96aac3fd62c854ed8}
and
\nolinkurl{13a76c68c149c2552f3543babeca6e1ad5afe23c45ea9c0dc365c1445cf2782b},
respectively. Deterministic instructions regenerate the analysis and
publication tables from these records.
