## 2026 nearest-work pressure that must be baseline/composition pressure

The following mechanics are not ORION novelty and must be executed where task-valid/runnable or recorded explicitly unavailable:

- **SAGE** — strong BM25 pressure in scientific-agent workflows plus corpus metadata/keyword augmentation.
- **AgentIR** — reasoning-aware retrieval using agent reasoning state jointly with query.
- **SIEVE / Search-Inspect-Fetch** — field-aware Boolean admission, structure-rich inspection, selective section fetch.

- dense, lexical, hybrid, metadata-aware, citation-aware and one-pass/agentic retrieval controls.

## Phase A — retrieval/candidate-generation development

Use the known Deep failure surface as a development set only.

Under matched candidate/query budgets compare:

2. full-text/field-aware BM25 where corpus access permits;
3. dense retrieval;
4. sparse+dense hybrid/RRF;
5. SAGE-style metadata/keyword augmentation;
6. AgentIR-style reasoning-aware retrieval;
7. SIEVE-style fielded Boolean admission + structure-aware inspection;
8. query decomposition + diversification;
9. bibliography/citation expansion;
10. ORION composition variants containing only prospectively declared subsets of the above.

Every missed target gets one earliest-stage label:
`QUERY_DERIVATION`, `INDEX_COVERAGE`, `CANDIDATE_GENERATION`, `RANKING`, `SCREENING`, `IDENTITY`, `ROUTE_STOP`, `TASK_STOP`, `CENSORED`, `BUDGET`, `EVALUATOR`, `OTHER`.

### Development promotion condition
Do not advance stopping claims until candidate recall is materially above the current failure floor and strong retrieval baselines have been pressure-tested.

## Phase B — ORION residual identification

Only the following residuals may remain candidate ORION contribution after donor subtraction:

### R1 — typed authority under censored/unknown coverage
Retrieval utility, relevance, confidence and coverage signals may guide acquisition but cannot silently authorize global closure while material route/task obligations remain unresolved.

### R2 — route-local vs task-global stopping separation
Local route exhaustion cannot certify global task completion unless all frozen task-level obligations are discharged.

### R3 — earned route independence
A route counts as independent only from content/provenance evidence, not tool/provider naming.

### R4 — dual content/read-state bookkeeping
Content identity prevents duplicate-discovery inflation while question-conditioned read state permits justified rereading for a distinct extraction question.

Each residual requires a direct ablation and a strongest relevant donor baseline.

## Phase C — stopping/authority hostile suite

Freeze cases before result access covering:

- one route exhausted while another contains late unique evidence;
- unavailable/censored source with unresolved obligation;
- duplicate tools/providers exposing the same corpus while claiming route diversity;
- high-confidence/high-coverage but incomplete evidence;
- no-gold / unknown-denominator case;
- delayed relevant evidence after a plausible local stop;
- coverage estimator disagreement;
- route reopening after a changed query/representation;
- legitimate reread of same content for a changed extraction question;
- duplicate rediscovery under changed URL/provider identity.

Baselines must include fixed-depth stopping, confidence/sufficiency stopping, HALT-style verification coverage, structured Search-R1-style stopping judgment, and a continuation/utility baseline where task-valid.

Primary safety outcomes:
- premature task closure;
- unresolved-obligation-at-closure rate;
- route-stop false-positive/false-negative rates where denominator exists;
- final recall/IoU/target success;
- queries/tokens/resource count;
- correct OPEN/CANNOT_CHECK rate.

A resource saving is not a positive if it violates the frozen stopping-safety margin.

## Statistical / promotion rule

Paper promotion requires all of:

- prospective freeze satisfied;
- denominator handling independently audited;
- strongest runnable baseline pressure complete;
- direct residual ablation supports the named mechanism;
- absolute misses/failures reported;
- uncertainty/effect sizes reported;
- no frozen stopping-safety violation;
- independent scorer/verification agrees;
- fresh/held-out pressure passes for any generality claim;
- current nearest-work refresh leaves the claimed residual unabsorbed.

No p-hacking, margin relaxation, post-outcome baseline deletion, selective task-family deletion, or scorer substitution is admissible.
