# NQ Engine-A bounded checkpoint/resource pilot

## Authority boundary

This is a prospective and then locally executed **engineering resource pilot**. It is not a
full census, an independent replay, a two-engine pass, a theorem result, or paper/journal
evidence. The permanent terminals are:

- `ENGINE_B_EXPOSURE_IN_PRIOR_CONTEXT__CANNOT_CHECK`
- `EXPECTED_OUTCOME_EXPOSURE`
- independence/science: `CANNOT_CHECK`

Neither a checkpoint nor a donor range can support a global negative. Resource exhaustion is
`CANNOT_CHECK_RESOURCE_BOUND`; any stale, malformed, or drifted checkpoint is
`CANNOT_CHECK_CHECKPOINT_MISMATCH`.

## Frozen denominator

`TARGET_RESOURCE_PILOT_PROTOCOL.json` was hashed before executing any new pilot outcome. It
binds the already frozen `C_5^3` length-three denominator: 20 canonical parent records with
SHA-256 `4de1ffc69d855e58f7f05fd11778dc3e46aca058ccd69b362f0a7b24a7766a10`.
Only child level four over parent range `[0,20)` is built. Each resumable invocation processes
at most seven candidate edges. The uninterrupted route exists only as a local equivalence
reference; it is not an authorized execution configuration.

The checkpoint cursor is the **next unprocessed** `(parent_index,
extension_representative_index)` edge. State is canonical JSON and binds the protocol,
source manifest, ordered parent digest, exact range, profile, budget, candidates, accepted
children, counters, exposure markers, and a self-digest. Resume first replays the processed
edge/evaluation prefix. Partial child records are inaccessible.

## Donor class-index slices

The ordered 20-class parent manifest is partitioned exactly into `[0,8)`, `[8,16)`, and
`[16,20)`. Every class, including a legitimate zero-image rank-deficient class, has a manifest
entry with source-class digest, donor-image count, donor-image digest, and labeled output.
Merge accepts only the declared order and exact contiguous cover, recomputes every range, and
requires labeled union/dedup equality with uninterrupted expansion.

## Target-length kernel panel

Exactly 16 invertible matrices are derived from the frozen SHA-256 seed rule and applied to the
permitted 19-term D2 lower witness. One measurement per case covers:

1. exact GL canonicalization;
2. complete declared donor-slice expansion;
3. extension-orbit/stabilizer construction;
4. exact two-bin DP with `max_states=250000`.

The panel records all positive, negative, and resource-bounded statuses without promotion. A
future SLURM envelope for this same pilot only is one CPU, at least 4 GiB, at least 30 minutes,
and otherwise four times observed maximum RSS and ten times observed elapsed time. No full
census runtime is extrapolated.

## Submission boundary

The prospective protocol explicitly sets `lunarc_submission_authorized=false`. A separate
source-bound submission contract may establish an immutable non-duplication key for a future
same-pilot SLURM run, but creating that contract does not submit it and does not authorize a
full census.
