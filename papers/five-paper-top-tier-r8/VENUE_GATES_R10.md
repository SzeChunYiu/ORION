## Venue-specific writing consequences

### Q1 / PRX Quantum

Do not lead with candidate-count asymptotics alone. Lead with the sharp structural theorem; application evidence must then establish either exceptional capability (certified exact compilation) or an exceptional connection between representation support and block-encoding resource design. A null runtime/resource experiment should narrow the application claim rather than alter the theorem.

### FiberGuard / JMLR

JMLR states that it publishes theory/methods of machine learning rather than applications of machine learning to other domains. Therefore graph colouring, set cover, SAT and Pauli compilation should function as *testbeds for a general representation-safety methodology*. The main experimental target must be a learning-system design question: when should a model answer, acquire information, choose a solver, or abstain?

### Integrated A+B / programming-languages journal

The paper needs a programming-system consequence. A theorem saying restricted rewrite languages can exaggerate certificate complexity is mathematically clean; a top programming-languages journal case is stronger if a real rewrite registry, extraction objective and independent equivalence checker show the effect on actual compiler proof/optimization claims.

### D / security journal

Security impact requires a real threat boundary. The paper should explicitly distinguish protocol validation from downstream evidence composition. If a native gateway or policy engine already preserves all relevant binding and produces the same decisions as the typed layer, that is a valid null result and should move the paper toward a formal-methods contribution rather than a vulnerability narrative.

### NQ / Combinatorica

The journal emphasizes general techniques and unifying principles. The manuscript should therefore explain what the `C_5^3` computation teaches structurally: the short-zero-sum spectrum, the one-unit corridor, orbit/source-lift architecture, invariant-theory equality, and exact restricted-kernel reformulation. A table of machine outputs without reusable combinatorial structure is insufficient for the stretch target.
