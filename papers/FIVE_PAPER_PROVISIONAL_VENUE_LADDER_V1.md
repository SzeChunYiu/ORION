# Five-paper provisional venue ladder V1

Date: 2026-08-27

Status: PROVISIONAL FIT MATRIX — not a claim about objective journal rankings.

Parent publication control: `FIVE_PAPER_TOP_TIER_FIRST_PUBLICATION_PROGRAM_V1.md`.
Machine gate: `FIVE_PAPER_PUBLICATION_GATE_V1.json`.

The first venue is attempted only if the paper-specific top-tier gate passes. The fallback venue is considered only when the scientific core is independently clear but the broader significance/generalization/application gate is not met. Venue choice never changes scientific evidence authority.

All scopes/criteria must be rechecked from the venue's current official author/editor pages immediately before submission.

## ORION-05 / Q1

### First attempt: PRX Quantum

Use only if the final package plausibly satisfies PRX Quantum's exceptional-advance/connection/capability/insight criterion. A scoped theorem with no faithful production/resource consequence must receive an explicit venue-editor veto review before this attempt.

Official criterion source at programme creation:
`https://journals.aps.org/prxquantum/about`

### Specialist fallback: Quantum Science and Technology; then a narrower quantum-information/quantum-computing specialist journal after fit review

QST is itself highly selective and requires an important result with broader quantum-science interest, so it is a fallback in selectivity/fit, not a weakened-science route. If the resource interpretation remains null/unbound, the manuscript must foreground the sharp scoped theorem and exact boundaries rather than hardware impact.

Official scope source at programme creation:
`https://publishingsupport.iopscience.iop.org/journals/quantum-science-technology/about-quantum-science-technology/`

## ORION-02 / FiberGuard

### First attempt: Journal of Machine Learning Research

Use only if the final theory/application package is of interest beyond a narrow solver-selection subcommunity and clearly advances understanding of learning/decision systems. JMLR explicitly expects claims to be supported theoretically or empirically, reproducible experiments where appropriate, and theoretical work to explain practical utility.

Official scope source at programme creation:
`https://www.jmlr.org/author-info.html`

### Specialist fallback: Transactions on Machine Learning Research

TMLR is a particularly natural fallback for a technically rigorous boundary/null paper because its acceptance criteria emphasize accurate, convincing evidence and audience interest rather than requiring state-of-the-art performance or subjective high impact. This does not permit weaker evidence; it permits narrower significance.

Official criteria source at programme creation:
`https://jmlr.org/tmlr/acceptance-criteria.html`

## ORION-04 / NQ

### First attempt: Journal of Combinatorial Theory, Series A

Use only after the independent replay/novelty gate and only if the surviving result represents a significant step on an important combinatorial problem, a new technique, or another substantial advance. JCTA describes itself as setting very high standards.

Official scope source at programme creation:
`https://shop.elsevier.com/journals/journal-of-combinatorial-theory-series-a/0097-3165`

### Specialist fallback: European Journal of Combinatorics

A clean independently replayed D2/D3 exact result with D4 explicitly open may fit a high-standard specialist combinatorics journal even if the JCTA significance threshold is not met.

Official scope source at programme creation:
`https://shop.elsevier.com/journals/european-journal-of-combinatorics/0195-6698`

## ORION-01 / AB

### First attempt: SIAM Journal on Computing

Use only if the production/realization gate or the abstract theorem package yields a significant mathematical/formal computer-science contribution with continuing relevance to computing. A production interpretation is not required for SICOMP fit if the formal contribution itself is sufficiently significant, but unproved production language must be absent.

Official scope source at programme creation:
`https://www.siam.org/publications/siam-journals/siam-journal-on-computing/`

### Specialist fallback: Theoretical Computer Science

If production completeness remains unavailable but the abstract certificate-realization/non-identifiability theory is independently clear and computationally motivated, TCS explicitly welcomes mathematical, logical, and formal concepts motivated by computing.

Official scope source at programme creation:
`https://shop.elsevier.com/journals/theoretical-computer-science/0304-3975`

## ORION-03 / D

### First attempt: IEEE Transactions on Software Engineering

Use only if the independently maintained domain/policy experiment establishes a software-relevant theoretical or empirical result with potential impact on software construction, analysis, validation, reliability, tooling, or system design. A purely internal formal example is insufficient for a software-impact headline.

Official scope source at programme creation:
`https://www.computer.org/digital-library/journals/ts/cfp-ieee-transactions-on-software-engineering`

### Specialist fallback: Theoretical Computer Science, Logic/Semantics/Theory-of-Programming fit; alternate formal-methods journal only after current scope check

If external operational significance remains `CANNOT_CHECK`, contract to the formal typed-authority/nonpromotion calculus and merge-safety semantics. TCS explicitly includes logic, semantics, and formal methods motivated by computing. Do not retain a real-world authorization-impact claim in this route.

Official scope source at programme creation:
`https://shop.elsevier.com/journals/theoretical-computer-science/0304-3975`

## Submission-order rule

For each paper:

1. close scientific core and exact custody;
2. run the four-role veto board;
3. if `TOP_TIER_GATE_PASS__SUBMIT_STRONGEST_DEFENSIBLE_VENUE`, recheck the first-attempt venue's current official criteria and prepare that package;
4. if `TOP_TIER_SIGNIFICANCE_GATE_NOT_MET__SCIENTIFIC_CORE_CLEAR__SUBMIT_SPECIALIST_FALLBACK`, recheck the fallback venue's current scope and contract positioning without changing evidence;
5. if `SCIENTIFIC_CORE_NOT_CLEAR__DO_NOT_SUBMIT`, no venue package may be generated.

No simultaneous journal submissions are authorized. Venue-specific originality/dual-submission policies must be checked immediately before each submission.
