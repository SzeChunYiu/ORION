# ORION-03 additional prospective benchmark instances — protocol V1

**Frozen:** 2026-08-21  
**Publication-cut evidence base:** `main@ca7df1055a43f97eaf8d142a62011c4c261af368`  
**Purpose:** satisfy ORION-03's pre-existing requirement for 2–3 additional unresolved-frontier instances without retrospective scoring.  
**Authority:** protocol only; no scientific or publication positive follows until both lanes execute and deferred outcomes later exist.

## 1. Global contract

For each instance:

1. The scientific question is unresolved on the publication-cut base.
2. No file matching the registered future result prefix exists on that base (`QG7D_*` / `QG15C_*` absent at freeze).
3. Lane A and Lane B outputs must be created and content-digested **before** any deferred outcome/result receipt is read by the scoring step.
4. Lane A and Lane B may use the frozen public state listed for the instance; they may not read future branch/PR result artifacts for the registered question.
5. Lane A is an LLM/host-driven research diagnosis under the normal receipt path.
6. Lane B is a typed non-LLM controller decision over a frozen manifest whose hypotheses/moves are all outcome-reachable.
7. `AGREE`, `PARTIAL`, `DISAGREE`, and `CANNOT_CHECK` are all valid pre-outcome benchmark outcomes.
8. Instrument failure is not scientific disagreement. Invalid/malformed execution maps to `CANNOT_CHECK` and the instance remains in the audit ledger.
9. Deferred scoring is performed only when an independently generated QG result/terminal exists after the two lane freezes.
10. All valid additional instances are reported, irrespective of agreement or deferred alignment.

No agreement, alignment, or number of matching cases confers authority on the underlying QG result.

## Question

> What is the most responsible diagnosis of the remaining QG-7c gap, and which next scientific move should be executed before any new family/completeness claim?

## Frozen diagnosis vocabulary

- `D1_MISSING_EXCHANGE_OR_COMPOSITION_LEMMA` — current evidence favors the existing family identity; proof machinery is insufficient on the pinned sector.
- `D2_UNSEEN_FIFTH_CONFIGURATION_PLAUSIBLE` — current family may be incomplete; evidence is insufficient to privilege proof repair.
- `D3_OBJECTIVE_OR_GRAMMAR_SCOPE_MISMATCH` — apparent gap is caused by applying the wrong objective/grammar theorem.
- `D4_MEASUREMENT_OR_REFEREE_DEFECT` — current local/hostile evidence is not trustworthy enough to diagnose the mathematics.
- `D5_CANNOT_CHECK` — available evidence cannot distinguish the above responsibly.

## Frozen move vocabulary

- `M1_TARGETED_SHARPER_EXCHANGE_PROOF` — attack exactly the 135,604 pinned failure patterns with a sharper exchange/composition lemma; no family enlargement.
- `M2_TARGETED_EXACT_COUNTEREXAMPLE_SEARCH` — construct exact instances directly from the worst pinned patterns and search for a real identity gap.
- `M3_FREEZE_NEW_BTRIPLE_FAMILY` — introduce/enlarge a fifth configuration family before a new exact witness.
- `M4_REOPEN_OBJECTIVE_OR_GRAMMAR` — change the scientific object.
- `M5_STOP_CANNOT_CHECK`.

Lane decisions may select one primary diagnosis and one primary move, plus a secondary move only if explicitly ordered and non-compensatory.

## Deferred-scoring map

Later independent QG-7d outcome is mapped without changing this protocol:

- all-`n` closure of pinned sector by sharper proof, no fifth witness -> strongest alignment with `D1` / `M1`;
- exact fifth-configuration witness from the pinned sector -> strongest alignment with `D2` / `M2`; `M3` receives credit only if its frozen family exactly matches a pre-witness move rather than being outcome-aware;

- unresolved/invalid run -> deferred score `UNRESOLVED`, not a negative alignment.

The later outcome may support multiple secondary interpretations; primary alignment is scored only against the frozen primary diagnosis/move.

# Instance ORION-03-V2 — QG-15c StabPrep boundary representation

## Frozen unresolved state

Source: committed QG15/QG15b entries in `QG_WAVE2_RECORD.md`.

Known at freeze:

- StabPrep transfers the regime-geometry template under an exact Dijkstra referee over registered complete state graphs.
- The original frozen low-order predicate ladder fails on the donor-exact boundary.

- The QG record registers QG-15c as the successor question: whether an enlarged path/schedule-aware vocabulary restores feature determination.
- No committed `QG15C_*` outcome exists at this freeze.

## Question

> Is the responsible next move to enlarge the StabPrep structural representation and retest exact boundary determination, or does current evidence justify a different diagnosis of the mixed-cell failure?

## Frozen diagnosis vocabulary

- `S1_FEATURE_VOCABULARY_INSUFFICIENT` — deterministic regime labels require path/schedule/global information absent from the frozen 13-feature representation.
- `S2_BOUNDARY_REQUIRES_HIGH_COMPLEXITY_WITHIN_EXISTING_FEATURES` — the features are sufficient but the prior predicate class was too weak.
- `S3_LABEL_OR_REFEREE_NONIDENTIFIABILITY` — exact labels/referee are themselves unstable or not uniquely defined.
- `S4_NO_USEFUL_STATIC_BOUNDARY_OBJECT` — representation enlargement is unlikely to restore a useful input-side boundary; focus should shift to exact search/budget bounds.
- `S5_CANNOT_CHECK`.

Because QG15b already contains identical feature vectors with opposite exact labels, `S2` is admissible only if the lane identifies an explicit reason the mixed-cell result does not actually apply to the decision object; otherwise a Lane-B manifest may mark it contradicted.

## Frozen move vocabulary

- `N1_FREEZE_ENLARGED_PATH_SCHEDULE_VOCABULARY` — define additional path/schedule/global features before opening new boundary labels, then test mixed-cell collapse and classifier exactness.
- `N2_INCREASE_CLASSIFIER_COMPLEXITY_ONLY` — retain the 13-feature vocabulary and search a richer classifier.
- `N3_ABANDON_STATIC_PREDICATE_AND_PRIORITIZE_EXACT_SEARCH_BOUND`.
- `N4_REAUDIT_REFEREE_LABELS`.
- `N5_STOP_CANNOT_CHECK`.

## Deferred-scoring map

- enlarged pre-frozen vocabulary eliminates mixed cells / yields exact deterministic boundary on registered holdout -> alignment with `S1` / `N1`;
- enlarged vocabulary still contains irreducible mixed cells but an exact search/budget theorem closes useful decision making -> supports `S4` / `N3` more than `S1`;
- referee/label correction invalidates mixed-cell premise -> alignment with `S3` / `N4`;
- complexity-only method succeeds **without changing features** only if the prior mixed-cell contradiction is resolved by a valid scope correction; otherwise it cannot count as support for `S2`;
- unresolved/invalid run -> `UNRESOLVED`.
