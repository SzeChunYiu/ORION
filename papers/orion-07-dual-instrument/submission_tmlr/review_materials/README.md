# Anonymous review supplement

This supplement exposes the complete bounded evidence used by the manuscript's three-row result without identifying the research programme during double-blind review.

It contains:

- one sanitized record for each of the three valid prospectively frozen questions;
- both retired contaminated candidates;
- the two known fail-closed instrument limitations;
- an independent verifier that reconstructs the alignment matrix and checks the finite-domain arithmetic;
- explicit data and software reuse terms.

The supplement intentionally contains no aggregate agreement, accuracy, reliability or calibration statistic. The scientific unit is one frozen question, and the three questions were not sampled from a defined population.

The verifier uses only the Python standard library. A successful run prints the three cases, confirms the agreement-with-misdiagnosis counterexample, and reports that the bounded checks passed. It does not reproduce the underlying domain-specific scientific analyzers. Those exact provenance-bearing records are withheld during blind review and will be deposited after the human authors authorize an identifying release.
