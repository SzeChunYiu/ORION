\section*{Data and Code Availability}
The valid benchmark units, contaminated-slot dispositions, pre-outcome instrument receipts,
deferred scores, scientific-result bindings and replay receipts are committed in the source
repository. The independently generated QG19 and QG20 scientific results are bound by exact
hashes and were reproduced by byte-identical double runs. The source repository is publicly
inspectable. A permanent archival identifier and explicit reuse licence will be inserted only
after an authorized release is actually deposited. This case series uses no private human dataset.
