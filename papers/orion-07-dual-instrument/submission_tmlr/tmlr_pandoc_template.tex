\section*{Data and Code Availability}
The valid benchmark units, contaminated-slot dispositions, pre-outcome instrument receipts,
deferred scores, scientific-result bindings and replay receipts are committed in the public
ORION repository at \url{https://github.com/SzeChunYiu/ORION}. The independently generated
QG19 and QG20 scientific results are bound by exact hashes and were reproduced by byte-identical
double runs. Public repository access is reported as access and reproducibility infrastructure,
not as independent scientific replication. This case series uses no private human dataset.
