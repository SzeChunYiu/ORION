# Filing checklist — ORION-05 / Quantum

The repository package is complete when `manuscript.pdf`, `arxiv-source.zip`, and `SHA256SUMS` match the validated build.

External filing actions:
- upload the source package to arXiv and obtain an identifier in or cross-listed to `quant-ph`;
- enter final author/ORCID metadata;
- enter funding and competing-interest declarations;
- use the manuscript contribution/AI-assistance statement in the submission metadata as required;
- if a separate public archive DOI is created for evidence/code, add that identifier without changing scientific claims.

A cover letter is optional for Quantum; the earlier cover letter is retained as an internal editorial summary, not a mandatory package gate.
