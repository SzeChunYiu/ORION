\section{Data and code availability}

The manuscript source, standalone finite checker, direct solver, sharpness enumeration, runtime specification, anonymized row-level observations, recorded environment, deterministic aggregation check, and adverse result are available in the accompanying anonymous review archive. The archive includes integrity and verification instructions but no author metadata or protected data. Protected data are not required for any claim in this paper.

Verification should proceed in three layers: rerun the standalone local-lemma checker; recompute the sharpness witness and support-one minimum; then regenerate the runtime summary from all 120 retained rows without changing the time limit, panel, or success rule. The twelve timeout rows are part of the result and must not be discarded. The review archive supports deterministic audit of those recorded measurements, but does not contain the full original unrestricted measurement stack for a new timing campaign.
