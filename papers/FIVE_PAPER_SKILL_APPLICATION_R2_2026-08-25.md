## Recursion contract

The portfolio was not passed once through a prose improver. Each manuscript repeated the following state machine:

`source boundary -> evidence inventory -> claim/evidence matrix -> theorem pressure -> donor search -> argument map -> main/SI allocation -> figure contract -> validity review -> positioning review -> reproducibility review -> editor synthesis -> revision`

A cycle stopped only when the next improvement required genuinely new external evidence or an unresolved theorem rather than another wording pass.
