# Q/QG submission-date literature freshness protocol V1

Purpose: apply `nature-literature-pipeline` / `nature-academic-search` as a bounded **freshness gate**, not an endless literature-collection exercise.

Current donor search date: 2026-08-21.

## Rule

For each paper, run a fresh search **within 14 days of actual submission**. Search primary scholarly sources appropriate to physics/quantum computing and AI research; use arXiv/proceedings for fast-moving CS/physics work rather than journal prestige filters.

A new paper reopens scientific content only if it:
1. directly establishes the same residual object at equal or stronger scope;
2. supplies a counterexample to a V3 headline theorem/claim;
3. materially changes the strongest donor baseline used to justify novelty;
4. reveals that a claimed bounded empirical comparison is not actually matched/novel because an omitted donor already performs the same operation under comparable information/resources.

Metadata updates, adjacent methods, citations that improve context, or a new publication venue for an already-absorbed donor trigger **citation refresh only**, not new experiments.

### Reopen trigger
A primary work proving an equal/stronger all-n support-≤2 closure for the same/shared TARE grammar/objective, or an exact counterexample requiring support ≥3 under the **same** frozen R6M/raw-support assumptions.

New TARE implementation benchmarks, hardware mappings, or Tag heuristics that do not prove/refute the same closure statement.

## Stop rule

Stop after:
- two consecutive query-expansion rounds produce no new material donor/counterexample; and
- all known direct parents plus backward/forward citations available from primary records have been checked to the level needed for the paper's headline claim.

Do not keep searching solely to increase reference count.

## Continuous monitoring (optional)

After submission, a periodic literature watch may monitor these same claim-specific queries for developments relevant to revision/rebuttal. It must never silently alter a submitted paper; any material finding opens a new revision/adjudication record.
