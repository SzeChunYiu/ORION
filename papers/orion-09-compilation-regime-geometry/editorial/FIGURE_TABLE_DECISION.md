# Figure and table decision

Backend gate: **Python**, selected for any genuinely necessary new data figure.

## Figure contract

- **Core conclusion:** a rich feature representation can determine the complete small-size domain yet fail to transfer.
- **Candidate archetype:** quantitative comparison.
- **Hero evidence:** 1,109 cells for 1,146 states, 1,072 singletons, 32/120 transfer errors, two covered states and shuffle-null p=0.51.
- **Review risk:** a plotted accuracy bar would visually promote a near-injective lookup into a general predictive result and would obscure coverage.
- **Decision:** no new plotted figure. A generated table is the more faithful representation because it keeps cell count, singleton count, coverage, errors and null calibration adjacent.

## Tables retained

1. **Cross-model authority table:** states which object is exact and which boundary remains open for each model.
2. **Feature-transfer table:** states complete-domain cell arithmetic and the frozen four-qubit transfer result.
3. **Supplementary proof-obligation table:** records exhaustive local case counts.
4. **Supplementary adverse-result table:** keeps the prospective failure, corrected negative, two-point observation and near-injective disclosure visible.

All tables are generated by a standard-library script directly from bound result records. No cosmetic figure is added.
