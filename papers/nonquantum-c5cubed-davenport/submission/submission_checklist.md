- [x] Initial submission PDF and self-contained abstract are present.
- [x] The abstract states background and principal results without citations.
- [x] The unresolved exact value is explicit; bounded support-22 evidence is not a theorem.
- [x] Critical Freeze–Schmid DOI corrected; all four references checked.
- [x] Portable PDF and retained source compile without LaTeX errors.
- [x] Insert author name and corresponding email.
- [ ] Confirm affiliation and ORCID, if applicable.
- [ ] Every author must line-check all proofs, details, attributions, and AI-assisted sentences under the E-JC AI policy.
- [ ] Obtain an independent replay/certificate before promoting any support-through-22 statement.
- [ ] Archive the verification package and insert its permanent identifier.
- [ ] Confirm all authors approve this exact version and no concurrent submission exists.
- [ ] Upload only the title-named PDF initially; use `e-jc.sty` and one self-contained TeX file after acceptance.
