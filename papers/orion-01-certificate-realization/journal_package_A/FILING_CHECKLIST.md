# Filing checklist

- [x] Canonical V3 manuscript bound byte-for-byte.
- [x] Canonical V3 claim ledger bound byte-for-byte.
- [x] Negative/forbidden claim boundaries preserved.
- [x] Reproducible review-PDF command and fail-closed verifier provided.
- [ ] Author names, affiliations, ORCIDs and corresponding-author details confirmed by humans.
- [ ] Target journal and journal-specific formatting selected.
- [ ] Conflict-of-interest and funding declarations confirmed by humans.
- [ ] Publication-licence choice confirmed.
- [ ] Immutable archive/DOI supplied if the target journal requires one.

Unchecked items are filing administration, not scientific permission to broaden claims.
