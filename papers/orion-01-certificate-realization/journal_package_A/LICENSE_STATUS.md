# Licence status

The ORION repository contains `LICENSE-PAPERS-CC-BY-4.0.txt`, the full text of the Creative Commons Attribution 4.0 International licence.

This package deliberately does **not** assert that the manuscript has been finally licensed for journal submission merely because that repository-level file exists. Final licensor/application wording is a human/legal filing-time decision.

## Current package rule

- Preserve the repository licence text and any third-party notices.
- Do not state that the journal submission is CC BY 4.0 until the authors confirm that this is the intended licence for the submitted manuscript.
- Do not infer rights for third-party figures, excerpts, or donor material from the repository licence.
- Record the confirmed licence in the final submission manifest and cover letter/package metadata.

**Status:** `HUMAN_CONFIRMATION_REQUIRED`.
