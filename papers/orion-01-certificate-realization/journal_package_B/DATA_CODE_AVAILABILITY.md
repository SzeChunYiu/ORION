# Data and code availability

No new data collection or scientific computation is introduced by this publication-closure package. All claim-bearing inputs, proofs, evidence and computational checks remain those described or cited by `SOURCE.md` and its canonical repository evidence.

The closure package does not convert repository presence into an archival claim. At filing time, repository references should be replaced or supplemented by an immutable archive identifier if required by the selected journal. No unavailable or unverified dataset is implied to be public by this statement.
