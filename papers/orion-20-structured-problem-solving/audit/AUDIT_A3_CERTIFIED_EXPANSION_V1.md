## G-5 (major) — the necessity half is proved by appeal to intended meaning

The proof of P10-T2 reads, in full:

> "three membership conditions definitionally sufficient: old closure
> excludes `t`, primitive not macro, extended closure includes `t`.
> **Necessity follows intended meaning** new behavioral reach."
> — `PAPER_THEOREM_PROOFS_V1.md:231`

Sufficiency is definitional and fine. Necessity is *asserted by appeal to
intended meaning*, which is not a proof. Remedy: either drop the necessity
direction, or present the object as a stipulative definition ("we define
genuine expansion to be...") so no necessity claim is made. As written it
is presented as a theorem with an iff, one direction of which is
unjustified.

- **Setting B:** *[recomputed]* **all five** catalogue candidates — ABS,
  SIGN, SQUARE, CUBE, FOURTH_POWER — are outside the rational-affine

  exactly one candidate (CUBE) passes.
- **Setting A:** *[recomputed]* exactly two of the sixteen truth tables
  solve the originating majority target under the frozen template — code 8

  Again the outside-closure filter eliminates nothing.

The certified-expansion gate is therefore *instantiated* by these studies
but never *stressed* by them. No case is exercised in which a candidate
solves the origin from inside the old closure and is correctly rejected.

## G-7 (major, verified) — `6/6` held-out transfer is deductively entailed

Transfer cannot fail in either setting, so the endpoint carries no
evidential weight.

- **Setting A:** the frozen composition template `g(a,b)⊕g(a,c)⊕g(b,c)` is
  equivariant under permutation of the input variables, and `majority` is a
  symmetric function. The held-out targets are the same function on the
  other three variable triples. *[recomputed]* code 8 satisfies all four
  triples, including the originating one, necessarily. A held-out set
  generated by the symmetry group the template already respects cannot
  fail.
- **Setting B:** the wrapper is `primitive(x) + a*x + b` with `a,b` free,
  and the held-out targets are `x³ + a'x + b'` — they differ from the
  origin **only in the two parameters the wrapper itself fits**. Transfer
  is arithmetic, not evidence.

This does not make the result false. It makes `6/6` uninformative, and the
manuscript must not present it as independent confirmation.

## G-8 (major, verified in code) — `false_expansion_count = 0` does not measure the decision procedure

A false expansion would be: run the OCME decision on a control target and
observe it *declare expansion necessary* when the registered basis
suffices. Neither implementation does this.

- **Primary runner.** `run_generated_ocme_v1.py:193` classifies a control
  as `KNOWN_COMPOSITION` iff `member = bool_target(case) in b_affine` —
  purely closure membership of the *control target*. The generator /
  selector is never invoked on the controls at all. Since the case file
  declares the controls affine and the membership test is exact, `0` is
  entailed by construction; it restates the case file.
- **"Independent" verifier.** `check_generated_ocme_independent_v1.py:147`
  emits the **literal** `"false_expansion_count": 0`, guarded by
  `assert all(b_controls) and all(i_controls)`. The only reachable outcomes
  are `0` or a crash. The same literal appears at
  `check_ocme_formal_independent_v1.py:115` and `:190`, and line `210` then
  tests those two constants against each other — a dead branch.

Consequence: "two structurally independent implementations agree that false
expansion is 0" is **not an agreement**. One side restates the case file;
the other side is a constant.

## G-13 (moderate) — the project's own falsifier is not discharged

`PAPER_THEOREM_PACKAGES_V1.md:466` lists as a P10 falsifier: "**candidate
grammar encodes the answer**". The generated study does not discharge it.
Its mitigation is *anonymity* — "No primitive name such as AND/OR is
supplied to the generator" (`P10_GENERATED_OCME_PROTOCOL_V1.md:39`) — but
anonymity is not non-encoding:

- Setting A's frozen composition template `g(a,b)⊕g(a,c)⊕g(b,c)` **is** the
  algebraic normal form of three-input majority when `g = AND`. The
  template supplies the solution's structure; the generator supplies one
  binary table from a set in which *[recomputed]* only two members work.
- Setting B's wrapper `primitive(x)+a*x+b` is precisely the shape of the
  target `x³+ax+b`, and the five-item catalogue contains exactly one
  exactly-fitting member.

`TOP_TIER_PROMOTION_V1.md:146` lists this attack and then scopes it to "any
claim of open-ended autonomous invention" only. That scoping is too narrow:
the encoding also bounds how much *generation* the generated study
demonstrates. It belongs as a limitation on the generated result itself,
not deferred to the successor.
