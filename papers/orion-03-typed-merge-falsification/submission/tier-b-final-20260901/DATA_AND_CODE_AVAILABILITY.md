# Data and code availability

The source archives and review-material archive in this directory bind the reader-facing manuscript to the repository evidence used for its bounded claims. A public persistent archive identifier must be inserted only after a real deposit; no DOI or submission identifier is synthesized by this package.

The journal directory also contains `artifact.zip`, the checksum-bound executable evaluator and bounded evidence archive named by the manuscript. Native-tool routes that the artifact marks `CANNOT_CHECK` remain unavailable; the archive does not convert them into reproduced outcomes.
