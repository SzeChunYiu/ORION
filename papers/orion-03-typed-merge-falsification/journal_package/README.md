# ORION-03 journal package — V3

**Title:** Typed Scientific Authority with Fail-Closed Nonpromotion

`SOURCE.md` is byte-identical to `../MANUSCRIPT_V3.md`; `CLAIM_LEDGER.md` is byte-identical to `../CLAIM_LEDGER_V3.md`. `CANONICAL_SUBMISSION_V3.md` is the current journal-science designation. The older publication-freeze addendum remains historical and is not rewritten.

This closure package adds no new science. It preserves typed authority, merge/normalization/falsification boundaries, the X.509 instantiation's stated scope, and fail-closed nonpromotion. It does not authorize a broad trust-store support matrix, sovereign PKI-governance claims, or universal asymptotic claims.

Run `python verify_package.py` before editing and `./build.sh` to generate and validate `main.pdf`. A filing build is closed only when `python verify_package.py --require-render` passes.

Human filing inputs remain deliberately unfilled: author/affiliation/ORCID metadata, target-journal style, conflict/funding declarations, publication licence choice, and immutable archive/DOI where required.
