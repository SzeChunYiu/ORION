The remaining top-tier question is whether the same responsibility logic prevents unsound reuse and needless invalidation in a public real workflow whose histories and correctness conditions were not created for ORION.

## Top-tier discriminator — one public real-workflow transfer

- [ ] Choose one independently maintained public workflow/version-history corpus with pre-existing outcomes or mechanically derivable correctness obligations.

- [ ] No unit may be selected because ORION already succeeds on it.

## Feasible public worlds

Use the strongest domain whose ground truth can be checked without private experts:

1. public software/configuration histories with tests, dependency changes, and build outcomes;
2. public scientific workflow/provenance histories using PROV/RO-Crate or workflow engines;
3. public data/schema migrations with validation suites;
4. public policy-as-code histories with deterministic validators.

The final protocol must use one concrete world and fixed revision. Do not mix worlds post hoc.

## Required comparators

- terminal/value-only reuse;
- always invalidate/recompute;
- dependency-only invalidation;
- strongest native cache/incremental/reuse mechanism available in the chosen world;
- donor-composed baseline using all responsibility information available to ORION except the proposed transport rule;
- ORION-23 responsibility-carrying reuse.

All arms receive the same history, tests/specifications, dependency information, tools, and total resource budget.

## Primary endpoints

Freeze before outcome access:

- unsound reuse rate — reused state later violates a required obligation;
- needless invalidation rate — valid reusable state is discarded;
- task/workflow success under the same stopping rule;
- recovery/recomputation cost and complete resource vector;
- abstention/CANNOT_CHECK rate;
- certificate-transport coverage and validity.

Use non-compensatory safety: a gain in reuse or cost cannot offset excess unsound reuse beyond the registered margin.

## Responsibility truth

Use, in descending preference:

1. deterministic tests/verifiers/specification obligations;
2. public dependency/provenance graph plus mechanically derived affected set;
3. pre-existing issue/change labels;
4. blinded isolated-model adjudication only for residual semantic cases, with at least two models/prompts and disagreement retained as `CANNOT_CHECK`.

ORION cannot author and certify the same responsibility label.
