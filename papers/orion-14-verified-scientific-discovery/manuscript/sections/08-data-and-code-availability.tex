\section{Data and code availability}
\label{sec:availability}

The review package contains the materials needed to audit the bounded results without exposing protected per-case gold during scoring: the prospective protocol and statistical plan, comparator and ablation definitions, safe aggregate outputs, the post-run public slice, figure/table source data, the separate reproduction path, and manifests that bind these objects to the evaluated subject and execution configuration. The same package retains the adverse evidence described in the paper, including the saturated V2 H3 result and the excluded exploratory live-model arm.

Protected per-case gold and raw execution traces are withheld from the public review bundle because they are part of the custody model under test. Their absence is explicit rather than treated as public reproduction. The released reproduction path therefore checks the published safe aggregates, headline counts, figures, and tables; it does not reconstruct hidden gold from information unavailable to the candidate or comparator lanes.

For double-blind review, identifying public-repository metadata and author-linked archive information are kept out of the manuscript-facing access path. The exact review-artifact contents are enumerated in the submission manifest and can be uploaded with the paper as anonymous supplementary material. Public repository and archival identifiers can be restored in the non-blinded release package without changing the scientific result. No persistent DOI is asserted in this review manuscript.

The naturalistic source-expansion programme is not part of the evidence supporting the present performance claims. Its outcome-free source and transport records are retained separately as prospective supplementary material so that an unexecuted successor is distinguishable from an omitted experiment.
