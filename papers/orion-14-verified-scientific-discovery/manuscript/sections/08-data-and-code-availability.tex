\section{Data and code availability}
\label{sec:availability}

The anonymous review package contains safe aggregate result objects for the protected V2 battery, the distinct V3 exact-axis battery, and the P4-X exact contracts; canonical-source checksums; a member checksum list; and a standalone verifier for the headline counts and retained interpretation boundaries. The package preserves the V2 H3 status as not supported and keeps the three empirical layers separate rather than pooling them.

Protected per-case gold, raw execution traces, secret seeds, and candidate-hidden fields are withheld from the review bundle because they are part of the custody model under test. Their absence is explicit rather than treated as public reproduction. The packaged verifier therefore checks the published safe aggregates and headline counts; it neither reruns protected scoring nor reconstructs hidden gold from information unavailable to the candidate or comparator lanes.

For double-blind review, identifying public-repository metadata and author-linked archive information are kept out of the manuscript-facing access path. The exact review-artifact members are checksum-bound and can be uploaded with the paper as anonymous supplementary material. Public repository and archival identifiers can be restored in the non-blinded release package without changing the scientific result. No persistent DOI is asserted in this review manuscript.

The naturalistic source-expansion programme is not part of the evidence supporting the present performance claims. Its outcome-free source and transport records are retained separately as prospective supplementary material so that an unexecuted successor is distinguishable from an omitted experiment.
