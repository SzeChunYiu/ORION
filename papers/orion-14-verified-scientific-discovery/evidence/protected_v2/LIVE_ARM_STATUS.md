# Status of the 39-case live-model arm

**Disposition: EXPLORATORY / NON-AUTHORIZING.**

The live arm remains in repository history because deleting a failed evaluation path would erase useful evidence. It is excluded from Paper IV's publication claims for four independent reasons discovered by recursive audit after execution:

1. live adjudication could change claim/source/support truth while the retained expected authority terminal remained the pre-adjudication value;
2. the live summary path derived clean coverage from the wrong counter and used non-eligible opportunity denominators;
3. family-based clean false-negative logic could still treat an adjudicator-invalidated clean case as a clean opportunity;
4. the live ORION/ablation path directly consumed candidate-hidden `attack_family` for several guards.

No protected V2 subject, hidden split, evaluator, comparator mechanism, threshold, or statistical rule was tuned using this arm. The final repaired-subject V2 split was generated fresh after the corrected public preflight and is the sole publication-authorizing result.
