**Status:** decision support based on the audited evidence; not an acceptance prediction.

**Core distinction:** several papers can become rigorous high-level publications by narrowing to a theorem, boundary, negative result, method or protocol. The intended broad claims of other papers cannot reach that level through prose repair alone and require new external evidence.

## Readiness codes

| Code | Meaning |
|---|---|
| `A — LOCAL-CLOSE` | A coherent bounded paper is available after claim/package/proof-surface repair using existing authoritative evidence. |
| `B — SPLIT-ROUTE` | A bounded paper can be submitted after local closure, while a broader successor claim requires a new study. The two claims must not be blended. |
| `C — EXTERNAL-GATE` | The intended central empirical or authority claim is not identified without external data, systems, implementation, evaluator or custody. |
| `D — PROTOCOL-ONLY` | The present contribution is a protocol/governance artifact because the registered campaign has not been executed. |
| `E — EXACT-OPEN` | The intended exact theorem/value remains open; either complete a proof object or publish the bounded obstruction/impossibility result explicitly. |

## Release decision

A paper moves to submission only when all of the following are true:

- its code above matches the manuscript's actual scope;
- every Wave 0 item in `11_EXECUTION_PRIORITY_BOARD.md` is closed;
- the positive and adverse terminals in `science_gap_register_v3.json` are both represented in the analysis and discussion;
- no result depends on an unbound, stale, absent or same-programme object that is described as external authority;
- source, data, analysis, figures, supplement and PDF reproduce from a clean clone;
- the expert review cell records no unresolved `RED`, and every `CANNOT_CHECK` remains visible in the released paper.

This scorecard should be revised only when a content-bound theorem, dataset, run, independent check or rendered manuscript changes the evidential state.
