# P1 saturation — venue-portable style atlas

Date: 2026-08-19

This atlas records structural lessons only. It must not copy wording from exemplar papers and it cannot change the scientific claim.

## Core manuscript architecture

1. **Problem before brand.** Open with the decision problem: when is a scientific agent justified in changing a high-level formulation/search universe? `ORION Paper I` is programme metadata, not the scientific hook.
2. **Subtract parents early.** Within the first page, state that attribution, diagnosis-conditioned scoped repair, counterfactual minimal repair, dependency rollback and recursive audit are donor-owned.
3. **State the residual in one sentence.** The protected necessity/preservation/dependency-impact gate is the tested object.
4. **Evidence order:** prospective freeze -> primary hidden-shift contrast -> evidence/execution controls -> ablations -> disjoint replication -> independent rescoring -> limitation boundary.
5. **Keep integrity chronology out of the decisive evidence chain.** Protocol amendments and receipt history remain visible in Methods/reproducibility, but the Results narrative should not read like a repository log.
6. **Put negative history where it informs interpretation.** Historical V1 remains explicitly underpowered/not supported and must never be pooled with v2.2.4.
7. **Limitations near the claim.** The synthetic/mechanical family, generator-bound perfect success, template leaks and untested model/open-science transfer are scientifically material, not boilerplate.

## NMI overlay

Use only if the bounded result survives a broad-interest editorial test.

- standalone, problem-first title;
- <=150-word broad-reader abstract;
- at most six main displays;
- explain K/W/M and `protected high-level mutation` without programme jargon;
- compress donor ledger into mechanism families;
- do **not** imply real scientific-agent efficacy, model transfer or open-ended discovery.

A reviewer request for real scientific-agent/model evidence is a request for new science, not a prose fix. In that case move to the fit-first venue rather than broaden the claim.

## AIJ overlay — recommended first submission

AIJ is the strongest current fit after saturation because the paper's contribution is a reasoning/knowledge-representation/repair **decision rule** supported by a controlled experiment.

- title should foreground epistemic mutation/problem formulation, not paper numbering;
- retain the formal K/W/M, responsibility and dependency language;
- synthesize relation to belief revision, planning reformulation, truth maintenance, causal diagnosis, agent repair and metareasoning;
- keep theorem-like boundaries and mechanistic ablations visible;
- move long per-donor disposition tables to supplementary/repository material if required for length.

## TMLR overlay

- evidence-first abstract;
- sharpen claim/evidence alignment and the exact frozen family;
- retain primary/replication/independent verification;
- minimize broad autonomous-science rhetoric;
- present the parent assimilation as baseline construction, not novelty theater.

## Invariant language

Preferred:

> In the frozen mechanical world family, protected high-level epistemic mutation outperforms every registered assimilated strong parent while withholding high-level mutation on evidence/execution controls.

Forbidden without new evidence:

- `general scientific agents learn when to reformulate`;
- `ORION solves open-ended scientific reframing`;
- `first failure-aware repair system`;
- `first recursive scientific agent`;
- `general belief-revision mechanism`.

## Submission decision

Primary: **Artificial Intelligence (AIJ)**.  
Fallback: **TMLR**.  
Aspirational alternative: **Nature Machine Intelligence** only if editors accept the bounded mechanical evidence as sufficiently broad without a new empirical campaign.
