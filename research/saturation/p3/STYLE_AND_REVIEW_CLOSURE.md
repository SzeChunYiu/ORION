# P3 saturation — SWJ/JWS style atlas and two blind-review rounds

Date: 2026-08-19

These reviewer reports are internal adversarial simulations, not external peer review.

## Core style atlas

Invariant argument:

> P3 tests a source-preserving decision rule for already-structured scientific projections: merge only when claim-relevant scientific coordinates are preserved; otherwise retain a typed, provenance-bound obstruction or plural view.

### SWJ primary overlay

- open with the semantic-interoperability failure mode, not the ORION programme;
- state `already-structured projections` in title/abstract/introduction/method/evaluation/conclusion;
- cite canonical ontology/schema/provenance/scientific-variable donors before presenting P3 coordinates;
- define each relation and coordinate once; examples must match the formal arity/type;
- benchmark construction, source spans, gold derivation, controls and error categories must be externally inspectable;
- present false merge and false split together so conservative refusal cannot masquerade as success;
- include a qualitative obstruction/error taxonomy alongside aggregate metrics;
- stable data/software URLs, README and reproduction commands are part of the submission argument.

### JWS fallback overlay

JWS can carry the same science with a more compact systems/data-integration framing. Keep formal semantics and provenance/recoverability, but compress programme-specific ownership tables. Do not broaden to raw-text knowledge extraction or universal KG integration.

## Blind review round 1

### R1 — Semantic Web novelty / benchmark realism

Attack: ontology matching, scientific-variable ontologies, KG integration and provenance already cover much of the vocabulary; the 32-case holdout may look handcrafted.

Resolution: donor ownership is explicit; I-ADOPT is added as a direct scientific-variable parent; P3's empirical object is the multi-coordinate merge/obstruction decision after structure exists. The 32-case holdout is prospectively frozen from pinned public human/expert resources and is presented as a bounded confirmatory discriminator, not a universal benchmark.

Verdict: no unresolved blocking/major concern after I-ADOPT insertion.

### R2 — formalism / statistics / validity

Attack: zero false merges could be purchased by splitting everything; the fixed coordinates could be a hand-coded ontology with no evidence of necessity.

Resolution: the confirmatory rule pairs false-merge improvement against an exact-coordinate conservative control and requires the false-split guard. The observed false-split difference is 0.000 with [0,0]. The paper explicitly does not claim universal coordinate necessity, raw-text extraction adequacy or expert-atlas completeness.

Verdict: no unresolved blocking/major concern.

### R3 — open science / SWJ editorial

Attack: a framework paper without navigable data, exact provenance and usable reproduction material is weak SWJ evidence.

Resolution: current scoped package contains source-bound public-reference artifacts, deterministic reproduction, claim ledger, journal package and independent verification. The saturation package must preserve those and rerun the PDF/reference gate after the citation insertion.

Verdict: no unresolved blocking/major concern.

## Blind review round 2

### R1b — closest-combination reviewer

Attack: `I-ADOPT + ontology matching + provenance + conservative fusion` could already implement the whole paper.

Finding: these donors supply semantic components, alignment machinery and lineage. P3's claim is not their component novelty; it is the experimentally tested decision to retain a typed scientific obstruction when a proposed cross-source mapping fails claim-relevant coordinate preservation. The paper must call this a composition/residual, not a new ontology-matching field.

Verdict: no major/blocking concern.

### R2b — error-analysis reviewer

Attack: aggregate false-merge/false-split numbers do not explain what goes wrong.

Finding: the manuscript and method/evaluation fragments distinguish referent, construct, measurement, context, modality and attribution mismatches plus GLUE/OBSTRUCTION/UNRESOLVED. A submission overlay should surface a compact qualitative error/obstruction table from existing cases, but no new scientific claim is needed.

Verdict: minor presentation task only.

### R3b — SWJ editor simulation

Attack: is this a semantic-web paper or an internal ORION architecture note?

Finding: the standalone object is semantic interoperability under scientific-meaning constraints, with public-reference data and explicit mapping semantics. Programme branding can be removed in the venue overlay without changing the paper's argument.

Verdict: no blocking/major concern.
