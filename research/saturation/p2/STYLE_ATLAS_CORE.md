# P2 saturation — core and venue style atlas

Date: 2026-08-19

## Invariant manuscript argument

> Acquisition quality and scientific-closure authority are separate layers: local relevance, utility, coverage, confidence or sufficiency may guide a route, but cannot silently discharge unresolved task-global search obligations.

Everything in a venue overlay must preserve this sentence's scientific scope.

## Core structure

1. Start with the two-control-problem distinction: acquire evidence vs certify completion.
2. Define route identity/earned independence, read-state identity, route stop and task stop before benchmark details.
3. Put the complete-denominator controlled mechanism result first.
4. Stage-separate MetaSyn, Deep and Wide external probes. No reader should need to infer which is full ORION, which is a bounded probe, and which is invalid/`CANNOT_CHECK`.
5. Treat provider failures as validity/custody evidence, not as retrieval performance.
6. Related work is organized by function: acquisition, screening, stopping, memory/read state, coverage/recall estimation, then authority consequence.
7. End with the reusable system-design contract, not an unfulfilled promise of future superiority.

## IP&M overlay — primary

- keep `Acquisition Is Not Closure` title family;
- first paragraph should be readable as an information-retrieval/system-design problem without knowledge of ORION;
- historical TAR/systematic-review stopping roots remain visible beside LLM-agent work;
- method contribution should be explicit before controlled metrics;
- external probes are stress tests of the contract, not an incomplete retrieval leaderboard;
- prepare 3–5 highlights: route/task separation, typed unavailable obligations, question-conditioned read state, donor-composable acquisition, complete-denominator mechanism test.

## JASIST overlay — conditional fallback

JASIST is not a formatting alias. A credible version must foreground information-science concepts: information need, coverage, evidence processing state, professional/systematic search, and consequences of declaring a search complete. Human/professional-search evaluation may be requested; that would be new science and must not be fabricated by rewriting the controlled study.

## Secondary IR/knowledge-systems fallback

Choose only after current venue-scope recheck. Preserve the same claim; do not relabel the paper as a retrieval-performance contribution merely to fit an IR venue.

## Abstract style

Order:

1. two control problems;
2. four system-design mechanisms;
3. bounded controlled result and its underpowered inferential status;
4. bounded external evidence;
5. invalid/`CANNOT_CHECK` external comparison state if mentioned;
6. invariant authority contribution.

Avoid detailed provider chronology in the abstract.

## Forbidden wording

- `ORION improves open-web scientific retrieval`;
- `sufficiency-aware stopping is new`;
- `coverage-aware termination is new`;
- `zero external difference shows no benefit` when the campaign failed validity;
- `provider failure demonstrates absence`;
- `the complete literature has been found` from finite search alone.

## Submission decision

Primary: **Information Processing & Management**.  
Conditional fallback: **JASIST**, with explicit information-science reframing and no invented human evidence.

Terminal: `P2_STYLE_ATLAS_FROZEN_IPM_FIRST`.
