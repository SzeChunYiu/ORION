# P2 venue ladder and portability contract

Date: 2026-08-19

The scientific core is invariant. Venue overlays may change framing, length, highlights, cover materials and section emphasis, but not promote the missing external-superiority evidence.

## 1. Primary — Information Processing & Management (IP&M)

Current official scope explicitly welcomes work at the computing/information-science intersection, including **methods manuscripts** and **critical application / system-design research**.

### P2 fit

Strong. P2's surviving object is a systems/methods contribution about evidence acquisition and closure governance rather than a new retriever.

### Overlay priorities

- title/abstract make the acquisition-vs-closure systems problem immediate;
- connect modern deep-research agents to classical IR, TAR, systematic-review stopping and information-quality/completeness concerns;
- preserve complete-gold controlled evidence as mechanism validation;
- keep external probes visibly stage-separated and bounded;
- prepare concise highlights after the argument stabilizes;
- do not imitate performance-centric IP&M RAG papers by promoting an unearned matched external win.

## 2. Fallback — JASIST

Current JASIST guidance asks manuscripts to engage explicitly with information representation/organization, human-information interaction or information-system impacts, and to make a clear contribution to information-science scholarship.

### P2 fit

Plausible but requires more than reformatting. A JASIST overlay should make the informational semantics of `coverage`, `route independence`, `question-conditioned processing state`, `open obligation`, and `closure authority` central and connect them to professional/systematic search practice.

Potential reviewer request that would be **new science** rather than overlay work: evidence involving human/professional searchers, user interaction or socio-technical use. This is not currently claimed or assumed necessary for the IP&M route.

## 3. Secondary fallback

Select a current IR/knowledge-systems venue only after the Round-B literature/style corpus. Do not assume a historical journal name/scope remains unchanged.

## 4. Portability matrix

| Element | Scientific core | IP&M overlay | JASIST overlay |
|---|---|---|---|
| claim | fail-closed acquisition/closure authority | invariant | invariant |
| title | `Acquisition Is Not Closure...` concept | systems/method emphasis | information-governance emphasis |
| abstract | controlled evidence + explicit external boundary | quantitative methods style | conceptual/information-science implication more explicit |
| nearest work | IR + systematic review + stopping + agents | method/system comparison emphasis | deeper information-science lineage |
| controlled suite | mechanism test | main evidence | main evidence but theory connection stronger |
| external probes | bounded stress evidence | stage-separated | stage-separated |
| human-use claims | NOT CLAIMED | NOT REQUIRED by current claim | NOT CLAIMED; may become reviewer-requested new science |
| unmatched external superiority | CANNOT_CHECK/future | remains excluded | remains excluded |

## 5. Current decision

Keep IP&M as first-submission target unless later corpus/reviewer evidence shows the authority-contract contribution is too conceptual for the venue or demands matched open-web superiority. Keep JASIST as a genuine intellectual fallback, not a mechanical template conversion.
