## Authority hierarchy

When commits, PR prose, workflow labels, or conversations disagree, use:

1. immutable scientific subject and exact source identity;
2. raw successful execution bytes, witnesses, counterexamples, and failure
   logs;
3. additive custody or interpretation correction;
4. this current-main convergence status;
5. per-paper science-closure disposition;
6. manuscript/PDF/reviewer-package closure;
7. external review, venue, rights, exact upload bytes, and submission receipt.

Later packaging never erases an earlier adverse/null/retracted result. A local
checker or manifest proves only its declared bounded property.
