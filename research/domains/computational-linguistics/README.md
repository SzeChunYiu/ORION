# Computational Linguistics / NLP

Status: `OPEN_RESEARCH_PROGRAM`.

Why relevant: ORION consumes scientific language but must preserve reference, event structure, predicate-argument roles, negation scope, modality, quantification, attribution, temporal/causal structure, coreference, discourse relations and pragmatic commitments before higher-level equivalence/contradiction reasoning can be trusted.

Initial subfields to study include scientific information extraction, semantic role labeling, semantic parsing, discourse semantics, pragmatics, coreference/entity/event resolution and uncertainty/stance extraction.

This program must first build known-answer/minimal-pair benchmarks for the language-to-typed-state boundary. It must not immediately turn one external representation such as AMR into ORION's canonical ontology.
