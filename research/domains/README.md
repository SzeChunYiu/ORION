# External Knowledge Domains

This subtree is recursive. Each domain should use the pattern:

```text
<domain>/
  README.md
  concepts/
  mechanisms/
  mappings-to-orion/
  evidence/
  benchmarks/
  open-residuals/
  history/
```

Only create subfolders when they hold real artifacts; empty directory placeholders are not required.

The initial domain programs below exist because the RAKL audit exposed material under-study. They are **research obligations, not promoted framework changes**.
