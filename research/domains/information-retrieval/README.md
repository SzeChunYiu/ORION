# Information Retrieval / Information Seeking

Status: `OPEN_RESEARCH_PROGRAM`.

ORION search should be a portfolio of non-equivalent retrieval families rather than a synonym-expansion routine. Study sparse lexical, dense, late-interaction, entity/event, citation/identifier, graph, mechanistic, failure-signature and exploratory retrieval together with information-foraging/search-control theory.

Track marginal root-relevant discoveries by route family so saturation is informed by what each family uniquely contributes.
