## Exact completeness theorem used

For a symmetric matrix B over `F_5` of rank r, there exists a nonsingular principal `r x r` submatrix. For `r<=3`, choose such a principal set S.

With the off-diagonal entries fixed by one affine specialization, enumerate the diagonal entries on S. If `C=B[S,S]` is nonsingular, rank(B)=r exactly iff the Schur complement outside S vanishes:

`B[i,j]=B[i,S] C^{-1} B[S,j]`

for all outside i,j, including the diagonals (which are then determined).

Thus every rank<=3 completion is generated by:

- every frozen off-diagonal specialization (5 for `942777`, 25 for `1470123`);
- every `r=1,2,3`;
- every principal set `S subset {0,...,12}`, `|S|=r`;
- every `5^r` diagonal assignment on S;
- exact Schur-complement replay.

Deduplicate by the full 13-entry diagonal vector, since off-diagonal specialization plus diagonal uniquely determines B.
