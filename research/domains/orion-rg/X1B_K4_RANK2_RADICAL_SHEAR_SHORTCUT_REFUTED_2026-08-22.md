# X1-B k=4 — universal shear-to-plane shortcut is false for the rank-2 radical family

Parent: #900.
Committed before downstream use.

## Proposed shortcut that is refuted

For the common rank-2 residual Gram witness, write the 13 residual kernel coordinates as

`(base_j, r_j) in F_5^2 direct-sum F_5`,

where the bilinear constraints see only the fixed two-dimensional base coordinates and the radical scalars `r_j` are free.

For a radical assignment r, let `F(r)` be the exact forbidden prefix set generated by every disjoint residual quotient-zero-sum pair `(Z,W)`:

- `-z_Z`;
- `-z_W`;
- `-(z_Z+z_W)`;
- and zero.

At `r=0`, this is the previously closed seven-point planar set `S_bad`.

A tempting universal argument would be: for every r, `F(r)` contains the graph of some linear functional over the seven planar base points, hence contains a `GL(3,5)` shear-image of `S_bad`.

That statement is false.

## Exact counterexample: quotient orbit `942777`

Take radical coordinates, in the fixed 13-position order used by the committed quotient orbit and rank-2 factorization,

`r = (3,0,0,1,1,1,1,2,2,4,4,3,3)`.

The resulting forbidden set has 14 points. Its fibers above the seven planar base values are:

```text
(0,0): {0}
(0,1): {0,1,2,4}
(0,3): {0,2,4}
(2,1): {2}
(2,3): {0,2,3}
(3,1): {4}
(4,0): {3}
```

Exhausting all 25 linear functionals

`ell(x,y)=a x+b y`, `a,b in F_5`,

finds **zero** whose seven-point graph is contained in `F(r)`.

## Exact counterexample: quotient orbit `1470123`

Take

`r = (1,0,3,4,4,2,2,1,1,4,1,2,2)`.

The resulting forbidden set has 18 points, with fibers:

```text
(0,0): {0}
(0,1): {0,1,3}
(0,3): {0,1,2,3}
(2,1): {1,2,4}
(2,3): {1,2,3,4}
(3,1): {2,4}
(4,0): {0}
```

Again all 25 linear functionals fail to produce a seven-point graph contained in the forbidden set.

## Consequence

The independently proved NO for the planar seven-point `S_bad` does **not** automatically eliminate every radical realization by a shear argument.

The rank-2 radical family therefore remains a real k=4 frontier and needs a stronger invariant or direct exact treatment.

## Claim boundary

This is a finite counterexample to a proof strategy, not evidence for a C15 counterexample and not novelty authority.
