# P1-X architecture-independence phase V1

Date: 2026-08-19. Parent: #529.

Question: does the P1-X escalation decision remain stable when equally informative diagnosis and recovery interfaces present the same candidates in different orders?

This is an exact interface-substitution test, not a claim about independently trained deployed diagnosis engines.

## Subject

Use 200 new identities: 5 domains x 8 archetypes x 5 replicates under namespace `P1_X_ARCH_INDEPENDENCE_V1_2026-08-19`. The scientific archetype mechanics are re-instantiations of V2; this phase tests interface substitution, not new case diversity.

## Frozen combinations

All expose identical values and budgets:

- `D_FORWARD_R_FORWARD`
- `D_FORWARD_R_REVERSE`
- `D_REVERSE_R_FORWARD`
- `D_REVERSE_R_REVERSE`

`D` changes only ordering of diagnosis/counterfactual status records. `R` changes only ordering of recovery proposals/candidate revisions. Gold, checks, candidate identities, and authority rules are unchanged.

## Pass criterion

1. P1-X ESRD = 1.000 on all 200 cases in every combination.
2. B3 decisions equal P1-X in every combination.
3. P1-X has zero false high-level reframes and invariant violations.
4. P1-X minus B1 ESRD is positive in every combination and every domain.
5. No arm exceeds the frozen intervention budget.

No new significance test is added; this is exact finite substitution evidence.

A pass supports only bounded A2 wording: invariance to these equally informative diagnosis/recovery ordering realizations. It does not support open-ended/deployed-agent generality.

Terminal: `P1_X_ARCH_INTERFACE_INDEPENDENCE_SUPPORTED` or `P1_X_ARCH_INTERFACE_INDEPENDENCE_NOT_SUPPORTED`.
