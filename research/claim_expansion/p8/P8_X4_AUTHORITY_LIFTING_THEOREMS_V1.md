## Shared scientific-discharge interface
A target scientific obligation is typed by

`(domain, kind, scope, content, epoch)`.

A donor-derived judgment may discharge that target only when:
- the donor-native verdict passes;
- the scientific type matches directly or a complete subject/epoch-bound protected coercion is registered;
- scientific authority is preserved/narrowed through the chain (`narrowing_ok`);
- blocker state is `REFUTED`; `UNDETERMINED -> CANNOT_CHECK`; `ESTABLISHED -> BLOCK`;
- at least one complete support family survives.

Two independent complete support families are used in the bounded theorem instance to make revocation nontrivial.

## Frozen X4 theorem obligations
T1. **Native-authority conservativity.** Adding the scientific-discharge layer never changes the donor-native verdict.

T2. **Cross-donor discharge separation.** For every donor family and each non-inert scientific type coordinate, native donor success can coexist with scientific-discharge failure when only that coordinate mismatches.

T3. **Monotone authority propagation.** Heterogeneous authority chains may preserve or narrow scientific-discharge type. A widening hop cannot discharge the widened target merely because every local donor step is native-valid.

T4. **Protected scientific coercion.** A complete protected bridge may transform scientific type; unregistered similarity, intent, action composability, common digest, claim fluency or generic authority context cannot.

T5. **Three-state blocker law.** Under otherwise satisfied conditions, `REFUTED -> DISCHARGE`, `UNDETERMINED -> CANNOT_CHECK`, `ESTABLISHED -> BLOCK`.

T6. **Exact support-family revocation.** One revoked complete support family does not destroy authority if another complete independent family survives; revoking every complete family removes discharge.

T7. **Heterogeneous chain composition.** Every ordered pair among the thirteen donor families composes scientifically when native verdicts pass, scientific authority does not widen, blocker is refuted, support survives and scientific type is compatible/bridged. The matched pair with a widening scientific hop fails while both local donor verdicts remain intact.

T8. **Permission/release/support non-inversion.** Native denial of one action/release route is not scientific refutation if an independent evidence family establishes the proposition; native authorization/release is not sufficient for a different or broader scientific target.

T9. **Heterogeneous-receipt insufficiency boundary.** Valid heterogeneous receipt composition and canonical action/subject binding are composition prerequisites, not proof of scientific target sufficiency. Scientific discharge still requires the target type/support/blocker relation.

T10. **Ideal decentralized-product equivalence.** A product carrying the exact same type, narrowing, support, blocker, coercion and composition rules agrees extensionally with P8; no centralized expressive advantage is claimed.

## Falsifiers
- A donor that already encodes an equivalent scientific target-discharge relation moves to the equivalence side and removes the corresponding P8 ownership claim.
- Type coordinates may be implemented differently in a domain; the theorem claims the registered product type only.
- Protected coercion must be explicit, target bound and current; no learned similarity grants it.
- Native authorization failure is never treated as scientific refutation.

## Final widened target
> A common scientific-authority lifting calculus can preserve and compose heterogeneous local authorities—from action permissions and delegation receipts to scientific claim verifiers and release gates—while governing which target scientific obligations those local judgments are actually entitled to discharge.
