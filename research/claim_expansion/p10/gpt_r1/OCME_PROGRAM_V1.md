# P10-U GPT-R1 negative-to-positive programme — Obstruction-Certified Method-Language Expansion (OCME)

Parent: #663
Related negative authorities: #586, #633
Status: `PROSPECTIVE__NO_OCME_PROTECTED_OUTCOME_CLAIMED`

## Mission

Drive P10 toward the full positive terminal:

`VERIFIED_PROBLEM_SOLVING_AND_METHOD_SPACE_EXPANSION_SUPERIORITY`

without relabeling search failure as invention or weakening the comparator.

## Negative seeds

OCME begins from preserved negative/boundary classes:

- exhaustive/donor-complete search closes the registered finite space;
- representation/access geometry is the true bottleneck;
- proof search times out despite an available registered method;
- a generated edit merely abbreviates known composition;
- a method edit improves its source instance but not held-out tasks;
- verifier/compiler feedback leaks the target action;
- native-state prediction improves without verified solve/search value;
- program synthesis or evolutionary search finds the same edit at matched resources.

These are not publication annoyances. They are causal discriminators.

## OCME stages

### O0 — freeze problem and resource model

Bind:

- target task/family;
- exact verifier;
- exact information/access model;
- total compute/search/verifier-call budget;
- pre-freeze method basis;
- closure/composition operation;
- representation family;
- implementation/environment identities.

### O1 — lower-level first right of refusal

Run/freeze evidence for:

1. more search/compute;
2. representation/interface repair (P9/AAGD);
3. implementation/environment repair;
4. premise/library retrieval;
5. action abstraction/macro mining;
6. current theorem-prover/proof-repair systems;
7. program synthesis;
8. evolutionary method/program search.

If one succeeds under the frozen model, the episode is not method-language inadequacy.

### O2 — obstruction certificate

An obstruction certificate must identify the old closure and establish one of:

- exact finite non-reachability;
- machine-checked lower bound;
- exhaustive bounded non-reachability;
- independently verified resource-bounded obstruction with every registered baseline exhausted under the same bound.

A timeout or failed candidate trace alone is invalid.

### O3 — method-language search

Only after O2 may ORION propose a language edit. Candidate edit classes:

- genuinely new semantic operator;
- new composition law unavailable in old closure;
- new grammar/primitive;
- representation-regime edit only when it changes method semantics/reach and correspondence is explicit;
- verification/selection primitive that changes reachable verified solutions.

A simple tactic macro or alias that expands to old closure is rejected as `KNOWN_COMPOSITION`.

### O4 — outside-closure verification

An independent checker determines whether the edit is outside the frozen old closure. The candidate cannot self-certify this.

### O5 — obstruction closure and transfer

Require:

- originating obstruction solved or materially moved;
- held-out tasks/families frozen before edit generation;
- positive transfer;
- no semantic/access-model widening hidden inside the edit;
- low false-expansion rate on known-method controls;
- strong search/synthesis/evolution baseline still does not recover the same result at matched cost.

### O6 — authority

P4/P8 and host/evaluator boundaries own correctness/promotion. P10 only proposes a method-language expansion result.

## Strong donor set

Mandatory families include:

- current Lean theorem-proving/proof-repair agents;
- LAMP-like agentic proof repair;
- failure-triggered learned Lean interventions;
- LeanAgent/lifelong proof-learning style systems where runnable;
- exact search and premise retrieval;
- tactic macro/library mining;
- program synthesis;
- AlphaEvolve/CodeEvolve-style evolutionary algorithm search;
- P9 structured/accessibility state;
- compute-more/search-more;
- donor-complete union.

## Primary positive gates

The OCME tranche is positive only if all are true:

1. at least one verified real problem-solving gain exists beyond representation-only metrics;
2. at least one O2 obstruction is independently established;
3. a candidate edit is independently outside the old closure;
4. the edit expands verified reach on the obstruction;
5. the gain transfers to held-out tasks/family;
6. false expansion on known-method controls stays below the frozen guard;
7. strong synthesis/evolution/search baselines do not obtain the same reach at matched budget;
8. independent reproduction passes.

Only then may the paper move from prospective method-language expansion to a protected positive.

## Jump rule

A **Jump** is allowed only when O0-O2 establish that the registered old language cannot discharge the target under the frozen scientific/resource semantics. Jump is a research action, not publication authority.

If the proposed jump is donor-owned, absorb it and reopen O3 with a stronger language. If materially distinct jump families saturate without a positive, derive the strongest lower bound/impossibility result and state the missing capability required for another jump.

## Statistics / inference

- Independent unit: protected theorem/task or predeclared obstruction family.
- Repeated generations/search seeds are technical repeats unless a hierarchy is frozen.
- Report solve rate and efficiency separately.
- Report false-expansion rate independently; it is non-compensatory.
- Freeze task/family weighting, intervals, multiplicity and catastrophic semantic-failure rules before protected outcomes.

## Completion states

- `OCME_METHOD_EXPANSION_SUPPORTED`: all positive gates pass.
- `OCME_PROBLEM_SOLVING_ONLY`: structured workspace helps but no justified expansion is earned.
- `OCME_LOWER_LEVEL_CAUSE`: apparent inadequacy resolves through search/access/implementation/library repair.
- `OCME_DONOR_SUBSUMED`: donor-complete method search obtains the same result.
- `OCME_IMPOSSIBILITY_BOUNDARY`: sharp lower bound/impossibility established.
- `CANNOT_CHECK`: verifier/provider/custody evidence unavailable.

No negative is deleted; each becomes the next responsibility-labelled research object.
