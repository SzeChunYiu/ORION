# Parent-domain search seeds V0

**Status:** candidate search seeds, not parent-domain saturation.

ORION's mechanic audit asks which mature disciplines study each operation as a canonical problem. V0 records candidate seeds recovered from RAKL and independent primary-source routes, including systems engineering, decision analysis/operations research, information retrieval/systematic review, literature-based discovery, computational linguistics, data integration/entity resolution, knowledge representation/truth maintenance, reliability/model-based diagnosis, causal inference/experimental design, measurement science/psychometrics, metareasoning/control, case-based experience learning, software reliability/reproducibility and human sensemaking/information foraging.

The purpose of the registry is to change the search vocabulary and expected variables. For example, computational linguistics asks ABSORB about predicates, arguments, reference, scope, modality, discourse and coreference; measurement science asks BENCHMARK/OBSERVE about the construct/measurand, instrument, validity and uncertainty; diagnosis asks DETECT/DIAGNOSE about expected behavior, abnormal observations, candidate causes and discriminators; truth-maintenance asks REOPEN about justifications, dependencies and minimal reconsideration.

A candidate domain list is not evidence that all relevant disciplines have been found. Every cell therefore proceeds next to an adversarial search-coverage/omission challenge. The domain registry itself must reopen whenever a newly found discipline contributes a decision-relevant coordinate absent from the current mechanic cell.
