## Proposed step-specific contract

**Mathematics — atlas entries are scoped structural objects.** A chart admitted to the atlas is \(S=(V,E,\chi,\gamma,q,\varepsilon)\): typed roles and relations with invariants, an explicit boundary/context record, the quantity of interest it serves, and its extraction evidence. Domain-facing entities stay in provenance; the transfer layer reasons over roles and relations. Explicit non-preservation (\(I^-\)) is first-class chart data: a later operator declares which preserved invariants it depends on, and an intervention touching a non-preserved property fails closed rather than leaning on an undifferentiated similarity score.

**Transition model — the evidential commitment ladder.** Atlas operations respect

```text
retrieved source  !=  witnessed target applicability  !=  verified target success
```

A retriever nominating a chart is not applicability; a passing directional witness licenses *eligible experience reuse only* (raise retrieval priority, activate a promoted tool, reorder search) and never mints a scientific claim — authority stays with the target's own verification path. Composition of partial charts (the GLUE case) requires a separate composition witness binding operation order, interfaces and incompatibility checks; component witnesses never prove pipeline coherence.

**Verification.** Witness contracts are executable and frozen: obligation-level traces with a deterministic content hash, emitted so a confirmatory benchmark can freeze the exact contract *before* outcome access; each load-bearing obligation is content-bound to its own evidence rather than inheriting authority because the witness object contains some evidence somewhere.

**Negative-transfer memory (couples to CROSS.EXPERIENCE / DIAGNOSE.ATTRIBUTION).** A failed transfer first becomes an observed-only episode; competing diagnoses (context mismatch, broken invariant, implementation defect, missing evidence, downstream failure) are separated by discriminating evidence; only fresh replay/transfer turns a supported diagnosis into a reusable boundary lesson. One near-miss never becomes a global blacklist; a future witness explicitly inherits a known non-preserved property instead of an opaque lower score.
