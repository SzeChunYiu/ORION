## 1. Research cell disposition

Four adversarial lanes were used.

- **Formal epistemology / verification:** attack any proposed unification with belief revision, dynamic epistemic logic, trace semantics, type theory, ontology evolution and conservative-extension results.
- **Scientific method / conceptual change:** attack claims of scientific novelty with prior work on evolving scientific claims, provenance, evidence registries and conceptual/schema change.
- **Meta-learning / open-ended AI:** attack recursive-evolution claims with self-modifying agents, learned languages/skills, coevolving benchmarks and meta-skill evolution.
- **Evaluation integrity:** attack apparent gains with fixed/trusted runtime, external-verifier, evaluator-tampering, regression and rollback controls.

Consensus after this round:

> No current ORION-RSE component is individually entitled to a foundational novelty claim. The only plausible residual is an interaction-level systems capability: recursive self-evolution that migrates scientific standing across semantic/framework change under independent authority and then demonstrates fresh multi-generation scientific value beyond a matched donor meta-product.

## 5. Round D — iterative belief change and path dependence

### Material parents

Classical and modern belief-change work already establishes that:

- iterated belief revision is not determined by single-step AGM alone;
- belief bases preserve distinctions lost by deductive closure;
- dependency-directed reconsideration can undo adverse effects of prior update order;
- dynamic epistemic/doxastic logics treat model-transforming belief actions;
- some revision systems are order/path dependent rather than commutative.

The strongest newly identified parent is:

**Peng Chen, `ZX-Calculus: Trace-Indexed Dependent Types and Epistemic Semantics`, arXiv:2606.03063 (2026).**

It combines:

- trace-indexed dependent types;
- presheaf/sheaf-style non-monotone semantics;
- constructive AGM revision;
- explicit Coq-checked results;
- a countermodel showing that sequential AGM revision fails the sheaf composition law `BP-comp`;
- a weaker single-step revision structure sufficient for its trace/retraction results.

This is a direct parent for any ORION claim about path-dependent scientific-state transport or failure of naive compositional revision.

### Claims struck

ORION-RSE cannot claim novelty merely for:

- trace-indexing knowledge/history;
- constructive AGM inside a typed framework;
- non-monotone semantic transport;
- discovering that sequential revision can fail a functorial/composition law;
- observing that revision order matters.

Round disposition: `MATERIAL_CHANGE`.

## 8. What remains after six material rounds

The residual is now **interaction-only**.

A candidate name for the required systems property is:

# Recursive Scientific Standing Integrity (RSSI)

This is a working research label, not a novelty claim.

Given a framework lineage

```text
F0 -> F1 -> ... -> Ft
```

and a scientific-status ledger `L_t`, every accepted framework transition must produce an explicit migration relation

```text
mu_t : L_t -> L_(t+1) x S
```

where status `S` contains at least:

```text
PRESERVED
TRANSPORTED
REOPENED
INVALIDATED
UNKNOWN
```

and where promotion/authority remains external to the actor proposing the framework change.

### RSSI obligations

1. **No silent carry-forward.** An inherited scientific status cannot simply keep its label because an object identifier survived.
2. **Semantic compatibility.** If the meaning/correspondence of the underlying object changed, old standing requires a registered transport or reopening.
3. **Dependency impact.** Changed assumptions/operators/interfaces propagate to dependent claims and obligations.
4. **Evidence-route validity.** Old evidence remains load-bearing only if its validation route is still applicable under the successor framework.
5. **Authority continuity.** A successor cannot inherit or mint authority merely because its predecessor was authorized.
6. **Negative-history applicability.** Failure knowledge and blacklists are context-scoped; a framework/operator change may reopen previously failed routes.
7. **Trace sensitivity.** Do not assume two individually valid revisions commute. If the order matters, the lineage/standing ledger must preserve that distinction.
8. **UNKNOWN preservation.** Non-identifiability is not converted into framework evolution by aspiration.
9. **Evaluator isolation.** Mutations that alter or infer protected evaluation are invalid improvement paths.
10. **Recursive closure test.** After `F1` is accepted, its migrated scientific state must be usable for a second successor experiment without laundering protected D1/D2 evidence into D3/D4.

All ten obligations have strong parents at the component level. The candidate contribution is the **recursive scientific-agent composition and causal evaluation of the complete set under matched donor power**, not first invention of any obligation.

## 9. Updated decisive discriminator

The strongest current experiment is no longer “can ORION evolve its framework?”

It is:

> When semantic representation, research policy, operators, goals or improvement machinery evolve over multiple generations, can ORION preserve the validity boundary of inherited scientific commitments and use the correctly migrated state to discover and authorize genuinely fresh science better than a donor meta-product, while avoiding unnecessary high-level evolution on cases solvable by narrower parents?

This yields three required axes:

```text
A. direct future scientific value
B. cross-generation scientific-standing integrity
C. successor-generation value
```

A result positive only on `A` is ordinary self-improvement.

A result positive on `A+B` but not `C` is governed framework adaptation.

The recursive ORION-RSE claim requires a protected positive on `A+B+C`.

## 10. Benchmark changes forced by donor discovery

The Tier-7 interaction suite in `PROGRAMME_V1.md` remains useful, but its interpretation changes.

### Parent-owned controls

The benchmark must include cases where:

- ontology-evolution/impact analysis alone is sufficient;
- iterated belief revision/reconsideration alone is sufficient;
- a fixed Lean-style verifier plus mutable workflow is sufficient;
- generic goal-drift/regression monitoring is sufficient;
- a versioned scientific claim/evidence registry is sufficient.

ORION receives no credit for those cases beyond matching the parent.

### Candidate interaction residuals

The remaining high-value families are combinations such as:

1. **semantic revision x authority** — the successor representation changes the meaning of a claim while a cached external certificate remains syntactically valid;
2. **operator invention x failure-memory applicability** — a new operator removes the cause of a historical failure, so global negative transfer is now wrong;
3. **goal evolution x scientific obligation** — a new objective improves the research score but changes which evidence is decision-relevant, requiring obligation reopening;
4. **non-commuting framework changes x preservation** — order changes the standing of inherited claims even when each edit is locally valid;
5. **benchmark coevolution x evaluator integrity x claim status** — the active curriculum may evolve, but protected scientific authority and untouched future evaluation cannot coevolve with it;
6. **multi-generation state migration** — an incorrect F0->F1 migration produces a delayed F2 error that is invisible on F1's direct task score;
7. **narrow-repair versus framework-rewrite** — broad evolution is penalized when a lower-level donor mechanism suffices.

These are not assumed novel; they are the next donor-search targets.
