# ORION-Q No-Man-Land Interface Freeze V1

**Date:** 2026-08-20  
**Tracking issue:** #659  
**First non-vacuity attack:** #660  
**Status:** `NML_INTERFACE_SPACE_FROZEN` — research-space discriminator only; **not** a novelty certificate or quantum-algorithm result.

## Frozen research territory

After repeated donor-pressure rounds, ORION-Q does **not** claim generic quantum circuit/program synthesis, scalable DSL search, reusable gate/gadget learning, automatic oracle synthesis, block-encoding construction, algorithm portfolio selection, full-stack QRE optimization, interaction-picture hybridization, deterministic/randomized Hamiltonian partitioning, or quantum formal verification. These are donor-owned structures and mandatory baselines.

The surviving territory is:

> **Proof-carrying synthesis and repair of the algorithmic interface stack itself.** Starting from the original mathematical problem and only genuinely available physical/classical data access, choose or invent the representation, access/oracle interface, algorithmic regime, and coherent/deterministic/stochastic decomposition, while independently proving that every edit preserves the original problem semantics, does not smuggle in a stronger oracle/access model, and carries an explicit end-to-end error/resource contract.

The search object is:

```text
problem semantics
-> representation
-> admissible access/oracle interface
-> algorithm family
-> deterministic/coherent/stochastic decomposition
-> implementation/resource model
-> proof/certificate
```

P10-style method-space edits may occur at the interior arrows of this chain, not merely inside the final circuit language.

## Load-bearing discriminator

A candidate system must simultaneously support:

1. original problem semantics as the root object;
2. editable/generative representation;
3. editable/generative access/oracle model;
4. editable/generative algorithm family;
5. editable coherent/deterministic/stochastic decomposition where applicable;
6. a proof that every interface edit is equivalent/admissible from original access;
7. end-to-end resource/error accounting including interface construction;
8. explicit abstention/refusal for stronger-oracle laundering;
9. method-space editing triggered by diagnosed structural obstruction rather than generic search alone;
10. external held-out correctness/novelty authority.

No weaker subset is the ORION-Q no-man-land result.

## `NO_STRONGER_ORACLE` rule

Every proposed stack must prove that each interface is either supplied in the original problem contract or constructible from supplied primitives with explicit cost/error.

Invalid hidden assumptions include, without limitation:

- free QRAM;
- free state preparation;
- an unconstructed block encoding;
- controlled Hamiltonian evolution when only uncontrolled evolution is supplied;
- stronger query oracles than the comparator;
- omitted classical preprocessing;
- changed error norm/tolerance;
- uncosted postselection/amplitude amplification.

A candidate that violates this rule is not merely suboptimal; it is epistemically invalid.

## Frozen sub-regions

1. **Representation synthesis** — construct equivalent formulations that expose different quantum interfaces.
2. **Access-model synthesis** — derive admissible oracle/data interfaces rather than assuming black boxes.
3. **Algorithm-family synthesis after interface change** — choose/generate the algorithm only after the representation/access contract is established.
4. **Coherent/deterministic/stochastic co-design** — allocate substructure across exact and randomized mechanisms under a global theorem-valid error budget.
5. **Proof-carrying end-to-end complexity** — close the complete problem→interface→algorithm→implementation chain.
6. **Interface failure epistemology** — distinguish bad tuning/search from wrong representation, expensive access, invalid assumptions, or genuine non-identifiability; retain scoped failures and reopening conditions.

## Non-vacuity ladder

- **I0:** exact access-contract worlds; stronger-oracle laundering and interface-cost accounting (#660).
- **I1:** donor-composition closure; supplied-component search gets first right of refusal.
- **I2:** hidden interface invention; required representation/interface absent from registered closure but derivable from deeper primitives.
- **I3:** current real-domain reconstruction; recover known human interface innovations without route labels.
- **I4:** prospective frontier campaign with frozen problem/access contracts and external novelty/correctness authority.

## Expected negative discipline

Fully known interface graphs should normally be closed by classical exhaustive/Pareto optimization. That outcome is expected and must be recorded rather than hidden. ORION value begins only where partial/unknown access state, scoped negative history, representation-dependent reminting, or genuine absent-interface invention leaves a residual beyond donor-complete optimization.
