# EAJ donor preflight V1 — learned schema evolution after fixed-schema closure

**Date:** 2026-08-23  
**Issue:** #963  
**Status:** donor-preflight freeze before EAJ learned outcomes.  
**Terminal:** `EAJ0_BOUNDED_RESIDUAL_SURVIVES__HIGH_RISK`.

This preflight asks whether there remains any defensible empirical research question after subtracting current work on belief-state learning, abstraction/library learning, grammar evolution, ontology construction, latent-variable discovery, M-open model discovery and verified scientific regime revision.

The answer is **yes, but only as a narrow conjunction**. None of the ingredients below is claimed as EAJ novelty by itself.

## 1. Internal owners / non-duplication

- ORION Jump #500 / J3 #512 own the conceptual definition of bounded scientific regime/concept invention.
- P10-U #663 owns end-to-end problem-solving/method-space expansion.
- P6/P7/P8/P5 own formal mechanics/transport/authority/adoption.
- ORION-Q/QG own quantum representation, state-quotient and method results.
- EAJ owns only the empirical question of **learned schema-edit proposal incremental value** under those external contracts.

## 2. Strong parent families

### P1 — abstraction and reusable program/library learning

Mandatory parents include DreamCoder, Stitch, LILO and current successors.

LILO explicitly combines LLM-guided synthesis with symbolic library compression and learns reusable abstractions grounded in language. Therefore EAJ does not own reusable abstraction/library induction.

TheoryCoder-2 (2026) goes closer: it actively learns reusable abstractions from experience and integrates them into hierarchical planning/program synthesis rather than receiving the abstractions from humans. Therefore EAJ cannot define its novelty as “the agent learns abstractions that expand planning efficiency”.

**Contraction:** learned reusable abstraction from experience is donor-owned.

### P2 — grammar / DSL evolution

Current LLM work already adapts grammar definitions across metamodel evolution and co-evolves grammar instances. Historical grammatical evolution, dynamic grammar refinement and program synthesis cover search in mutable grammars more broadly.

BINDER already identifies pieces unexpressible in an existing symbolic language and extends the executable program with LM-backed calls.

**Contraction:** mutable grammar/DSL adaptation, semantic-coverage extension and grammar-guided synthesis are donor-owned concepts.

### P3 — ontology/schema construction

LLM ontology-learning and KG work already performs term typing, taxonomy/relationship discovery, schema construction and ontology refinement. Current 2026 systems automatically construct validated ontological memory/KG schemas, while OntoKG treats schema design itself as the central reusable object.

**Contraction:** “use an LLM to create new entity/relation types or an ontology” is not EAJ novelty.

### P4 — concept discovery without a predefined concept list

Concept Bottleneck Models without predefined concepts and unsupervised concept-discovery/dictionary-learning families already extract latent concepts without human concept labels.

**Contraction:** discovering a compact concept basis from learned representations is not EAJ novelty.

### P5 — latent-variable / causal structure discovery

Causal structure learning, state abstraction, predictive-state representation and latent-variable discovery already introduce hidden variables/causal models when observed state is inadequate.

**Contraction:** introducing a latent state/object after surprising observations is not enough for an EAJ claim.

### P6 — M-open scientific model discovery

Model Discovery Agent and related Bayesian/model-criticism systems explicitly expand model/hypothesis structure after model inadequacy, with independent inference and experiment design.

**Contraction:** “detect current model family inadequacy and propose another model” is donor-owned.

### P7 — verified scientific representational regime revision

Self-Revising Discovery Systems for Science explicitly defines scientific discovery as a verified transition between typed representational regimes, transports old artifacts/provenance through the schema map, and distinguishes ordinary fixed-regime update from regime change.

This is the closest conceptual parent to ORION Jump.

**Contraction:** representation/schema revision + provenance transport + external verification is not EAJ novelty.

### P8 — ORION Jump / concept-invention formalism

ORION already owns the programme-level contract:

```text
old-regime bounded insufficiency
-> representation/concept proposal
-> executable semantics
-> correspondence/preservation
-> protected novel consequence
-> external verification
```

EAJ may only test whether a learned proposer adds value inside this formal object.

## 3. Donor-composed incumbent

The first EAJ baseline is a **composition**, not a raw LLM:

```text
model criticism / M-open expansion
+ program / CEGIS / symbolic synthesis
+ library / abstraction learning
+ grammar evolution
+ ontology / concept construction
+ latent / causal representation learning
+ verified regime-transition machinery
+ exact old-language reach/insufficiency referee
```

A learned EAJ proposer must beat or meaningfully dominate the strongest faithful applicable subset under matched information/resources.

## 4. Residual conjunction

After all contractions, the only candidate EAJ residual is:

> **Necessity-gated, generated epistemic schema invention:** after an independent exact/bounded certificate that the current epistemic schema cannot satisfy the target under the declared bound, generate an executable new primitive/relation/type/schema from a non-enumerable meta-language, preserve/transport old admitted state and obligations, and earn protected fresh-task reach/consequence beyond strong program/library/representation/regime-revision parents.

Every term is load-bearing:

### `necessity-gated`
A failed search is insufficient. The old schema must have an exact or independently verifiable bounded-insufficiency certificate.

### `generated`
The candidate cannot be selected from a fully enumerable finite menu under the available verifier budget. `EAJ_FINITE_MENU_CLASS_CLOSED` already proves that class cannot show solve-rate proposal superiority.

### `epistemic schema`
The candidate changes the state/types/relations available to the downstream reasoning interface, not merely a local solution program.

### `executable`
The proposed primitive must compile to semantics that can be independently evaluated. Natural-language novelty is not enough.

### `preservation / obligation transport`
The new schema must recover or explicitly reopen relevant old state. This is consumed from ORION/Self-Revising parents, not credited as EAJ novelty.

### `protected fresh consequence`
Origin-task fit is insufficient. The candidate must unlock a held-out consequence/task/family not available during proposal.

### `donor-complete comparison`
If program synthesis, library learning, latent representation learning or a self-revising scientific system obtains the same schema/result under matched resources, EAJ contracts to that parent.
