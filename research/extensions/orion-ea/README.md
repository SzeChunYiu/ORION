# ORION-EA — Epistemic Autoregression

**Issue:** #957  
**Status:** active research programme; no architecture/performance claim is authorized by this directory.  
**Branch packet:** EA-0A donor saturation + EA-1A exact discriminator freeze.

ORION-EA studies a narrower object than `LLM + structured workspace`: whether a learned model should predict **typed epistemic state deltas** in addition to tokens/latent states, with exact machinery retaining first right of refusal for deterministic revision operations.

The programme is constrained by completed ORION evidence:

- P9 showed that typed coordinates can be load-bearing while exact inference can remove the need for neural escalation.
- P10 A0 showed that a finite structured responsibility controller collapses to donor-composed existing control methods.
- Jump/concept-invention work already owns the long-horizon question of bounded representational regime change.
- Failure epistemology already requires negative knowledge to be scoped and reopenable rather than a permanent ban.
- ORION-Q already supplies strong obligation-transport and protected skill-admission objects.

## Current scientific residual after EA-0A

Fresh 2026 donor pressure eliminates broad novelty for all of the following:

- persistent/recurrent latent reasoning state;
- separating temporary computation from persistent committed state;
- intrinsic long-lived memory state;
- graph-native belief revision;
- exact dependency retraction;
- state-first supersession tracking;
- selective rollback that preserves benign memory;
- stale-memory revocation;
- event-sourced deterministic agent mutation;
- verified representational regime transition and provenance transport;
- M-open model-class expansion and mechanism-centric world models.

The surviving **candidate** residual is therefore the conjunction below, which remains unearned until EA-1/EA-2 execution:

> Learn arbitrary, typed `EpistemicDelta` proposals over a persistent epistemic state; bind those proposals to an exact admission/revision kernel; evaluate them by evaluator-controlled causal state interventions; preserve scoped failure/reopen and representation/obligation semantics; and compare a native state pathway against same-information serialization, recurrent latent state, external structured memory, and donor-composed exact revision under matched resources.

This is intentionally narrower than the original #957 aspiration. Native architectural superiority is **not assumed**.
