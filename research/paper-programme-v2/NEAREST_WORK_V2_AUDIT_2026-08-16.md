# V2 Nearest-Work Audit — 2026-08-16

Purpose: determine whether the PR #149 mechanisms are available as standalone novelty or only as ORION-specific compositions. This is a pre-execution audit, not the final submission audit.

## P1 — active diagnosability

**Parent work:** *Bayesian Diagnosability and Active Fault Identification* (arXiv:2509.04708) explicitly quantifies when passive fault identification is not diagnosable and designs active inputs to make faults distinguishable.

**Disposition:** `ADOPT` the parent mechanism, strike active diagnosis from standalone novelty. Test only the ORION composition: diagnosability → active discriminator → responsibility-scoped permission to alter epistemic formulation/search-universe state.

**Reopen trigger:** a scientific-agent paper that already binds diagnostic responsibility to typed epistemic mutation authority.

## P2 — conservative exploration

**Parent work:** Conservative Contextual Bandits (arXiv:2412.06165) and the earlier conservative contextual-linear bandit line (arXiv:1611.06426) formalize baseline-preserving exploration. Safe Exploration for Optimizing Contextual Bandits (arXiv:2002.00467) already applies safe exploration to information retrieval settings.

**Disposition:** `ADAPT`. Conservative bandits/safe exploration are not novel. The only candidate residual is the composition with P2's earned route identity, censored provider unavailability, question-conditioned read state, and non-authoritative route stopping.

**Reopen trigger:** adaptive scientific-literature retrieval that already combines conservative safety accounting with censoring and route/task authority separation.

## P3 — lenses, transport and obstruction

**Parent work:** Partial-State Lenses (arXiv:2601.04573) formalize bidirectional multiple-view update preservation. Partial Transportability for Domain Generalization (arXiv:2503.23605) formalizes conditional transport under structural assumptions. *Sheaf-Theoretic Transport and Obstruction for Detecting Scientific Theory Shift in AI Agents* (arXiv:2605.14033) directly applies transport/gluing/obstruction to scientific representational change.

**Disposition:** `ADOPT` only as an incremental P3 study. Strike lenses, cycle consistency, transportability and scientific obstruction from standalone novelty. Test whether **typed scientific coordinates** plus round-trip/cycle checks reduce unsafe merge/contradiction on expert gold.

**Reopen trigger:** a system already evaluating typed referent/construct/measurement/context/modality/attribution round-trip obligations against cross-domain scientific gold.

## P4 — proof carrying and defeaters

**Parent work:** Proof-Carrying Agent Actions (arXiv:2606.04104) makes certificate-bearing action governance explicit. Defeater Cards (arXiv:2606.11462) systematize assurance-case defeaters. Assurance-case work such as arXiv:2411.03291 uses explicit assurance arguments to guide required verification/evidence.

**Disposition:** `ADAPT` as an efficiency helper only. Do not claim proof-carrying authority, defeater representation, or assurance-guided verification as novelty. Test whether protected defeater-directed evidence ordering reduces cost/unresolved critical risk under an unchanged P4 authority lattice.

**Reopen trigger:** prior work that already optimizes protected evidence acquisition under the same scientific-authority custody model.

## P5 — validated self-evolution

**Parent work:** PACE: Anytime-Valid Acceptance Tests for Self-Evolving Agents (arXiv:2606.08106) directly controls false commits in self-evolution. SEA: Self-Evolving Agents with Anytime-Valid Certificates (arXiv:2607.00871) combines versioned self-modification with auditable anytime-valid acceptance. A separate PACE system (arXiv:2605.23019) validates two-timescale prompt/control evolution on held-out tasks.

**Disposition:** `ADOPT` only the non-compensatory ORION composition: STATIC → REPLAY → FRESH → PROTECTED, with known harm dominating missing stages, append-only negative history, evaluator custody, and host-only promotion recommendation. Anytime-valid acceptance is baseline/prior-work material.

**Reopen trigger:** a self-evolving system already requiring independent fresh transfer, protected custody, non-compensatory stage semantics, retained harmful variants, and no self-promotion authority.

## Saturation challenge

This audit deliberately searched parent disciplines rather than ORION terminology: fault diagnosis, safe exploration, bidirectional transformation, transportability, assurance cases/defeaters, and sequential acceptance of self-modification. A future paper must rerun these routes because the 2026 literature is moving rapidly.
