# ORION foundational scientific-discharge programme

This directory is the canonical home for the third-pass foundational research programme. It separates established bounded paper results from the proposed cross-paper theorem and from the prospective external validation required for a field-level claim.

## Canonical terminology

The programme uses one name:

> **Scientific Discharge Sufficiency Principle (SDSP)**

A locally valid scientific artifact or judgment may alter the standing of a different target obligation only through an explicit sound target-bound discharge relation. Authority-neutral computation may expose consequences already licensed by registered rules, but it cannot replace missing evidence, bridge premises, revalidation, target identity, scope, epoch, support, or blocker resolution.

Do not create parallel names for the same principle.

## Integrity rule

The publication sequence is:

`original hypothesis and terminal -> positive successor hypothesis and authority label -> prospective independent confirmation`

Retrospective compatibility with known paper outcomes is useful for theory construction but is not itself new confirmation. A universal or foundational claim requires the new hidden falsifier suite and the cross-domain Grand Challenge to be frozen and executed without outcome-conditioned changes.

## Breakthrough rule

The programme does not claim prize status, universal validity, or broad benefit by rhetoric. The strongest route is:

1. one generic calculus recovers all registered paper decisions without paper-specific algorithms;
2. the calculus makes novel predictions before outcome access;
3. an explicit discharge layer causally reduces unauthorized scientific-status transitions without clean-utility loss;
4. independent institutions and implementations reproduce the result on naturalistic artifacts and held-out domains;
5. the intervention measurably improves consequential scientific or human decisions.

Only evidence can move the programme up this ladder.
