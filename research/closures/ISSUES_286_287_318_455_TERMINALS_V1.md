# Bounded scientific terminals — #286 / #287 / #318 / #455

This closure record distinguishes **finished scientific disposition** from a positive result.  `CANNOT_CHECK` is a valid terminal when the remaining claim requires an independent authority surface that is not available.  No green unit test is promoted into cross-host, cross-model, external-benchmark, or protected-campaign evidence.

Review lenses used before terminal assignment:

- **experimental design:** asks whether held-out outcomes were genuinely independent of mechanism construction;
- **verification/authority:** asks whether the result can self-authorize or requires #283/cross-host custody;
- **transfer/continual learning:** separates known-answer baseline plumbing from scientific cross-domain transfer;
- **novelty evaluation:** separates a frozen benchmark/evaluator from actually running a certificate and strong baselines on the same inputs;
- **assimilation provenance:** checks donor source identity, assumptions, authority and composition evidence;
- **self-revision safety:** separates Stage-0 responsibility discrimination from result-bearing protected self-modification.
