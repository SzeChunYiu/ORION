# Discovery Event Normal Form V1

## Status

This document refactors ORION’s historical discovery morphology into a factorized research representation. It does **not** assert that human creativity has one universal algorithm or that the historical atlas is exhaustive.

```text
historical_morphology = BOUNDED_USEFUL_BASIS
private_cognitive_process = CANNOT_INFER
universal_pattern_completeness = NOT_CLAIMED
prospective_discovery_authority = NONE
```

## 1. What the existing atlas established

The frozen Discovery Morphology Atlas contains 51 source-grounded public-artifact episodes:

```text
mathematics/formal       16
empirical science        15
engineering/design       12
everyday/practical        8
```

Its ten stable dimensions describe **what changed in the resulting artifact**:

1. `REPRESENTATION_CHANGE`
2. `NEW_OBJECT_OR_STATE_VARIABLE`
3. `ABSTRACTION_EQUIVALENCE_STRUCTURE`
4. `NEW_LAW_CONSTRAINT_OR_INVARIANT`
5. `BRIDGE_CORRESPONDENCE`
6. `NEW_OPERATOR_PROCEDURE`
7. `SYSTEM_COMPOSITION_ARCHITECTURE`
8. `INTERFACE_MEASUREMENT_REDESIGN`
9. `FUNCTION_AFFORDANCE_INVENTION`
10. `FIXED_REGIME_SEARCH_CONTROL`

The atlas survived two fresh challenge rounds without a new public-artifact coordinate. That supports a bounded organizational claim. It does not answer:

- what triggered the search;
- where the candidate structure came from;
- which regime layer was deliberately edited;
- how it was validated;
- whether the result was instance-specific or reusable;
- whether the historical transformation is the only plausible reconstruction.

DENF adds those missing axes.

# 2. Factorized event object

For episode `E`, define

\[
DENF(E)=(T,S,\Delta,M,V,R,A),
\]

where:

- `T` — trigger/tension;
- `S` — candidate-source/synthesis mode;
- `Δ` — edited regime layer;
- `M` — public-artifact morphology;
- `V` — validation mode;
- `R` — scope/reuse rung;
- `A` — authority and evidence lineage.

An episode may have several competing DENF records when historical evidence underdetermines the interpretation. The representation is explicitly many-valued.

## 2.1 Trigger axis `T`

```text
GOAL_OR_OPEN_PROBLEM
FAILURE_OR_OBSTRUCTION
ANOMALY_OR_CONTRADICTION
UNDERDETERMINATION_OR_COMPETING_MODELS
OPPORTUNITY_OR_ZERO_ERROR_TENSION
SURPRISE_OR_SERENDIPITOUS_EXPOSURE
RESOURCE_OR_SCALE_PRESSURE
EXTERNAL_NEED_OR_DESIGN_CONSTRAINT
SOCIAL_OR_COORDINATION_CONSTRAINT
UNRESOLVED
```

Trigger is not candidate source. A surprising observation may trigger either ordinary search, donor transfer, or genuinely new completion.

## 2.2 Source/synthesis axis `S`

```text
FIXED_REGIME_SEARCH
DONOR_COMPOSITION
STRUCTURAL_TRANSFER
RESIDUAL_COMPLETION
HYBRID
UNRESOLVED
```

This is the missing axis captured by the Composition–Transfer–Completion Calculus.

## 2.3 Edited regime layer `Δ`

```text
QUESTION_OR_OBJECTIVE
FORMULATION_REPRESENTATION
METHOD_OPERATOR_LANGUAGE
INSTRUMENT_INTERVENTION_INTERFACE
VALIDATION_MEASUREMENT
AUTHORITY_ADOPTION
NO_REGIME_EDIT
UNRESOLVED
```

`AUTHORITY_ADOPTION` governs whether an earned result may be used. It cannot create scientific reach.

## 2.4 Artifact morphology `M`

Use one or more of the existing ten coordinates. Morphology remains descriptive and source-grounded.

## 2.5 Validation mode `V`

```text
FORMAL_PROOF
FORMAL_CONSTRUCTION_OR_COUNTEREXAMPLE
PREDICTION_AND_OBSERVATION
CAUSAL_INTERVENTION
MEASUREMENT_OR_INSTRUMENT_CALIBRATION
ENGINEERING_FUNCTION_OR_PERFORMANCE
REPLICATION_OR_ROBUSTNESS
SOCIAL_OR_USER_VALIDATION
PLURAL_OR_UNRESOLVED
```

Domain-specific validation semantics must not be collapsed into a generic confidence score.

## 2.6 Scope/reuse rung `R`

```text
INSTANCE
PARAMETER_NEIGHBORHOOD
FAMILY
DOMAIN
CROSS_DOMAIN
OPEN_WORLD_OR_CANNOT_CHECK
```

Historical fame does not upgrade scope. Scope follows the tested consequence family.

## 2.7 Authority/lineage `A`

Bind separately:

```text
source chronology
model chronology
proposal origin
native validity
independent verification
present-day novelty
adoption authority
```

Historical reconstruction is not present-day novelty, and present-day novelty is not adoption authority.

# 3. Crosswalk from the ten artifact dimensions

| Existing morphology | Typical edit layer | Typical source modes | Important separation |
|---|---|---|---|
| `REPRESENTATION_CHANGE` | formulation/representation | transfer, completion, hybrid | may be conservative in expressivity but decisive under bounded resources |
| `NEW_OBJECT_OR_STATE_VARIABLE` | representation or method language | completion, transfer | a new name is not a new object |
| `ABSTRACTION_EQUIVALENCE_STRUCTURE` | representation | transfer, completion, search | quotient/duality may already be donor-owned |
| `NEW_LAW_CONSTRAINT_OR_INVARIANT` | representation/validation | completion, search, transfer | fitted regularity is not automatically a law |
| `BRIDGE_CORRESPONDENCE` | representation/method | composition, transfer, hybrid | bridge may be the residual even when components are old |
| `NEW_OPERATOR_PROCEDURE` | method language or interface | composition, completion, transfer | library macro versus new semantic reach must be checked |
| `SYSTEM_COMPOSITION_ARCHITECTURE` | method/interface | composition, hybrid | known components do not settle bridge novelty |
| `INTERFACE_MEASUREMENT_REDESIGN` | instrument/intervention | completion, transfer | simulator and physical instrument authority remain separate |
| `FUNCTION_AFFORDANCE_INVENTION` | question/interface | transfer, composition, completion | engineering function is not reducible to scientific truth |
| `FIXED_REGIME_SEARCH_CONTROL` | no regime edit | search | important result does not imply a Jump |

The same public artifact morphology can arise through different source modes. For example, a new operator may be:

- found by fixed-regime search in a known DSL;
- composed from donor modules;
- transferred from another field;
- generated as a residual primitive;
- produced by a hybrid route.

That is why morphology alone cannot authorize discovery credit.

# 4. Human-history theories absorbed by DENF

## 4.1 Schema instantiation, modular subassembly, and chaining

Darden’s mechanism-discovery strategies map mainly to:

```text
Trigger: FAILURE / OPEN MECHANISM SLOT
Source: DONOR_COMPOSITION or RESIDUAL_COMPLETION
Edit: METHOD / REPRESENTATION
Morphology: NEW_OBJECT, NEW_OPERATOR, SYSTEM_COMPOSITION
```

These are strong donors for the user’s `a1 × b2 × c3` mode.

## 4.2 Relational analogy and axiomatic analogy

Structure-mapping and axiomatic approaches map to:

```text
Source: STRUCTURAL_TRANSFER
Morphology: BRIDGE_CORRESPONDENCE, REPRESENTATION_CHANGE
Validation: target proof/experiment required
```

DENF does not assume that all mathematical analogies are object-to-object maps.

## 4.3 Conceptual integration / blending

Blending can selectively project donor structure and develop emergent completion:

```text
Source: HYBRID = COMPOSE + COMPLETE
Morphology: BRIDGE, NEW_OBJECT, NEW_LAW, ARCHITECTURE
```

Generic blending remains donor-owned. ORION adds explicit closure, transfer debt, hidden consequence, and authority checks.

## 4.4 C-K concept/knowledge expansion

C-K theory maps to interaction between:

```text
QUESTION/CONCEPT SPACE
KNOWLEDGE/DONOR SPACE
RESIDUAL COMPLETION
FUNCTION/CONSTRUCTION VALIDATION
```

DENF preserves the difference between design concepts, scientific hypotheses, and mathematical conjectures.

## 4.5 Transformational creativity

Boden/Wiggins-style transformational creativity corresponds to editing the generative or conceptual space. In DENF this is an edit to `Q`, `Φ`, `L`, `I`, or `V`, not a separate source mode. The new content may still come from composition, transfer, completion, or a hybrid.

## 4.6 Abduction

Abduction is most often:

```text
Trigger: anomaly / incomplete explanation
Source: residual completion, donor transfer, or hybrid
Validation: new discriminating consequence
```

Explanation of development evidence alone is insufficient; hidden predictions or interventions are required.

## 4.7 Serendipity and exaptation

Serendipity is treated as a trigger and exposure pathway:

```text
SURPRISE_OR_SERENDIPITOUS_EXPOSURE
```

Exaptation usually appears as:

```text
Source: STRUCTURAL_TRANSFER or DONOR_COMPOSITION
Edit: QUESTION/FUNCTION or INTERFACE
Morphology: FUNCTION_AFFORDANCE_INVENTION
```

Neither creates a fourth semantic-provenance class. The resulting candidate still decomposes into local, donor-mapped, generated-residual, and unresolved structure.

# 5. Coverage and minimality

## DENF-C1 — coverage

A frozen corpus is covered when every load-bearing episode can be represented by at least one DENF tuple and every unresolved interpretation is retained explicitly.

## DENF-C2 — necessity by discriminator

A value or axis is retained only when removing or merging it causes at least one pair of episodes or prospective cases—requiring different scientific actions or claim ceilings—to become observationally identical.

Examples:

- merging search and residual completion would give invention credit to fixed-DSL results;
- merging composition and transfer would erase target-domain transfer debt;
- merging validation and novelty would let correctness self-authorize priority;
- merging trigger and source would treat serendipity as a magical generation operator.

## DENF-C3 — no universal completeness

A finite atlas cannot exclude a future load-bearing transformation outside its basis. Every schema includes:

```text
UNKNOWN_OR_NEW_COORDINATE
UNRESOLVED_SOURCE_MODE
REOPEN_BASIS
```

## DENF-C4 — plural historical interpretation

Historical records may support multiple source modes. For example, the same artifact might be reconstructed as donor composition by one historian and structural transfer plus completion by another. Unless source evidence discriminates, both remain.

# 6. Proposed reannotation protocol

The existing 51 episodes should be reannotated without rewriting the original morphology.

For each episode:

1. freeze the original source/cutoff record;
2. preserve all existing morphology tags;
3. add trigger candidates with evidence and competing interpretations;
4. add source-mode candidates;
5. identify edited regime layers;
6. identify validation mode and scope;
7. mark missing or disputed coordinates;
8. add matched no-jump/source-mode controls;
9. run two fresh source-challenge rounds;
10. compare whether DENF changes benchmark decisions.

The reannotation is successful only if at least one of the following occurs:

- it predicts a different required experiment;
- it prevents false invention credit;
- it retrieves a useful distant structural donor;
- it identifies a missing residual primitive;
- it improves failure diagnosis;
- it demonstrates that the extra axes add no incremental value and should be removed.

Historical frequency alone does not validate a discovery mechanism.
