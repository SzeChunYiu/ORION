## Why this successor exists

The completed OSTC execution wave did more than confirm finite instances. It exposed a repeatable failure class in scientific harnesses themselves:

1. **A true theorem can be tested on a non-identifying grid.** `EXEC-P9-01` confirmed two parts of T14, but its 4×4 domain made greedy and exact set cover tie everywhere, so the comparator half was never exercised.
2. **A family can omit the hard stratum.** Two P10 runs generated almost only satisfiable formulas because their clause/variable ratio was 0.8. T22 became observable only after `EXEC-P10-02` crossed the random-3-SAT transition and required UNSAT membership as a precondition.
3. **The evaluator can encode its conclusion.** An early P15 key-compromise probe incremented failure from a hard-coded compromise flag; the repaired probe derived detection from observable signals and produced both detected and undetected cases.
4. **The theorem premise can be imposed rather than tested.** The T19 structural core set two transcripts equal by construction, so it could never falsify indistinguishability.
5. **The reference relation can be defined from the candidate.** An early T13 runner defined the declared composite as coordinatewise `g∘f`; the repaired atlas enumerated independently perturbed composites and reached millions of noncommuting cases.
6. **A plausible bound can fail through an unmodelled action.** `EXEC-P12-01` found a third-action hedge that refuted the universal half-gap clause of T17 while preserving the positive-regret impossibility.

These are not isolated implementation mistakes. Together they show that scientific verification needs a theory of whether a harness can *distinguish the theorem from its registered alternatives*. A green run is not informative when every permitted world forces the same answer.

## Programme objective

Build the missing `Q-DISCOVER` layer above the completed OSTC custody/admission theory:

```text
raw scientific state
→ material tension generation
→ obstruction diagnosis
→ theorem-identifying discriminator design
→ question / representation / method / instrument / validation edit
→ proposal-origin proof
→ hidden consequence and transfer
→ donor subtraction
→ independent validity and novelty authority
```

The programme has four coupled formal objects.

### 1. Epistemic Decision Geometry

A loss-general theory of what can be decided from a scientific interface. It replaces the narrowed T17 clause with the exact fibrewise Bayes and minimax objects, explicitly accounting for hedge actions, randomized policies, responsibility changes, and partition refinement.

Canonical document: `EPISTEMIC_DECISION_GEOMETRY_V1.md`.

### 2. Theorem-Identifying Harnesses

A harness is identifying only when the outcome vector it induces separates the target theorem from every registered alternative, mutation, or omitted-premise model. Mixed outcomes, precondition attainability, mutation kills, and independent construction of the reference relation become formal obligations rather than optional test quality.

Canonical document: `THEOREM_IDENTIFYING_HARNESS_V1.md`.

### 3. Generative Reach and Discovery Credit

A selector over a supplied candidate menu cannot earn outside-closure discovery credit. A genuine discovery claim requires a content-bound proposal-origin trace, an obstruction in the frozen old closure, a non-reducible edit, protected hidden consequences, held-out transfer, donor first refusal, and independent authority.

Canonical document: `GENERATIVE_REACH_AND_DISCOVERY_CREDIT_V1.md`.

### 4. Historical–Counterfactual–Prospective Triangulation

Historical reconstruction provides ecological realism but is vulnerable to model-weight contamination. Counterfactual twins test mechanism transfer but may be synthetic. Prospective escrow tests present-day novelty but is sparse and expensive. Strong discovery authority requires these lanes to agree at the exact claimed level, with `CANNOT_CHECK` preserved.

Canonical document: `HISTORICAL_COUNTERFACTUAL_PROSPECTIVE_TRIANGULATION_V1.md`.

## Scientific state extension

Extend the OSTC state by a non-authorizing discovery layer:

\[
\Sigma_D = \Sigma \oplus (Q,\Gamma,I,\Omega,\equiv,\Pi,O_r).
\]

- `Q` — active and candidate scientific questions;
- `Γ` — mutable transformation/operator grammar;
- `I` — observation, intervention, instrument, and prototype language;
- `Ω` — counterfactual and simulated worlds;
- `≡` — responsibility-relative equivalence between candidate theories or methods;
- `Π` — exploration portfolio and resource policy;
- `O_r` — proposal-origin and derivation records.

A proposed edit is typed as one or more of:

```text
QUESTION_EDIT
FORMULATION_OR_REPRESENTATION_EDIT
METHOD_LANGUAGE_EDIT
INSTRUMENT_OR_INTERVENTION_EDIT
VALIDATION_OR_MEASUREMENT_EDIT
AUTHORITY_OR_ADOPTION_EDIT
```

The first five may expand scientific reach. The last governs adoption and may not manufacture reach or novelty.

## Exact claim boundary

This package may establish definitions, theorems for declared finite or abstract classes, executable reference implementations, countermodels, and frozen execution protocols.

It does **not** establish that ORION:

- has made a present-day scientific discovery;
- can rediscover all historical science;
- is novel relative to all prior work;
- outperforms scientific agents;
- can self-authorize validity, novelty, or adoption;
- has external evaluator custody.

## Immediate consequences of the completed execution wave

The completed jobs already justify several successor decisions:

- Replace T17's universal half-gap language by exact fibrewise regret geometry.
- Add a theorem-identifiability receipt to every result-bearing harness.
- Require every load-bearing clause to have a registered alternative capable of falsifying it.
- Treat denominator/precondition attainability as part of the theorem statement.
- Separate structural machine checking from independent authorship/review.
- Treat repeated vacuity detection as a first-class positive research result.
- Use theorem counterexamples to revise the theory under a new identity rather than silently moving a gate.

## Operating principle

> Do not ask only whether a candidate passed. Ask whether the frozen harness could have produced a materially different answer under a registered scientifically meaningful alternative.

A programme that repeatedly invalidates its own tests, narrows its own theorems, and preserves those failures is behaving more scientifically than a programme that reports only green confirmations. The next step is to make that property formal, executable, and predictive.
