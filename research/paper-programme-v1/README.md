# ORION five-paper research programme — nearest-work assimilation V1

Frozen starting point: `SzeChunYiu/ORION@c7376b952b2a33505e6fbc6644f6c9772c156190`.

This programme applies ORION to ORION's publication claims.  The object is not "write five papers"; the object is to determine which scientific contributions survive after the strongest nearby mechanisms are understood and absorbed.

## Research grammar

For each proposed paper:

1. **ATOMIZE** the candidate claim into mechanics, assumptions, observables and failure conditions.
2. **SEARCH NEAREST WORK** through independent routes: exact terminology, function-only, parent discipline, historical precursor, implementation analogue and adversarial "already solved" search.
3. **ABSORB** useful mechanisms rather than treating related work as an opponent.  Every mechanism gets an `ADOPT`, `ADAPT`, `COMPOSE`, `DEFER` or `REJECT` disposition and an ORION target.
4. **RECONSTRUCT THE CLAIM** after absorption.  Anything already provided by nearest work is removed from the novelty claim.
5. **FALSIFY** the surviving delta with a frozen discriminator/benchmark and strong simple baselines.
6. **REOPEN** the paper if a new nearest work, representation, failure class or benchmark changes the comparison.

`src/orion/knowledge/nearest_work.py` makes the nearest-work/novelty boundary executable.  `CANDIDATE_DELTA` is not publication authority.

## Cross-paper constitutional rule

Nearest work is **input to ORION's global portrait**, not a novelty obstacle to be minimized.  If another system has a better mechanism, ORION should absorb it.  The scientific claim becomes the smallest residual difference that remains after this assimilation.

The target is therefore not `ORION > every prior system`.  It is:

`all useful prior mechanisms + explicit compatibility/assumption boundaries + the smallest surviving ORION delta`.
