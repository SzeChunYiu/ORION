# ORION Discovery V2 — knowledge-web navigation and proof economy

This package is an additive successor to the Discovery V1 theory/harness lane.
It does not rewrite frozen V1 theorems, OSTC results, ORION-Q results, or any
paper claim authority.

## Exact residual

Earlier ORION work already froze:

- a descriptive discovery-morphology atlas;
- a recursive calculus for testing proposed epistemic atoms;
- theorem-identifying harnesses;
- proposal-origin and bounded generative-reach accounting;
- negative-to-atomic-successor protocols;
- self-expanding epistemic-state proposals;
- paper/framework/harness synchronization rules;
- exact ORION-Q obstruction, representation, proof, and resource methods.

The remaining object is not another universal creativity taxonomy.  It is a
**typed knowledge-web and change-impact calculus** that answers:

1. Which conjunctive ingredients are required for a target responsibility?
2. Which ingredients are already present, missing, donor-owned, or mutually
   substitutable?
3. Which navigation move should be attempted next under a vector resource
   contract?
4. What is the least adequate proof or experiment, without inventing a hidden
   scalar exchange rate?
5. Which theory/code/harness/paper/authority/manifest surfaces reopen when an
   upstream semantic object changes?
6. How may ORION study and improve ORION without self-evaluation or
   self-adoption?
7. Which exact structural methods transfer from ORION-Q, and which scientific
   authority remains domain-specific?
8. How does the system retain an explicit open-morphology terminal when the
   useful move is outside the registered basis?
