# 02 — Knowledge Absorption and Global Portrait

ORION is deliberately happy to absorb more knowledge. Absorption is not flat ingestion into a bag of facts.

For candidate external knowledge `k`, the intended pipeline is:

```text
source
 -> contextual projection
 -> semantic/scientific extraction
 -> identity resolution
 -> facet identification
 -> map against current Atlas/global portrait
 -> compatibility / contradiction / novelty tests
 -> evidence verification
 -> assimilation OR residual OR reframe
```

A typed absorption outcome should distinguish at least:

```text
ALREADY_KNOWN
EQUIVALENT_VIEW
COMPLEMENTARY_FACET
REFINES_EXISTING_FACET
NEW_CONTEXT_COORDINATE
NEW_REPRESENTATION
NEW_MECHANISM
CONTRADICTS_EXISTING
EXPOSES_ASSUMPTION
EXPOSES_SEARCH_UNIVERSE_GAP
EXPOSES_METHOD_FAILURE
UNRESOLVED
```

## Recursive effect

Absorption may change not only the global object portrait `K_t`, but the search-universe model `W_t` by revealing new disciplines, vocabularies, representations, data sources, mechanisms or falsifiers. Such a change automatically creates new search obligations.

## Domain rule

Domain knowledge belongs under `research/domains/<domain>/...`. It may contribute concepts and operators to ORION only through explicit mappings and evaluation. No domain receives special constitutional status merely because it exposed an important prior omission.
