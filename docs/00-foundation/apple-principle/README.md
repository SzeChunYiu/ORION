# Apple Principle

Different sources and disciplines may expose different projections of one latent object. ORION does not ask which paper or discipline is the single winner; it asks what each projection observes, under what context, what it cannot see, how it maps to other projections, and what global object best explains the compatible evidence.

```text
many partial projections
  -> facet normalization
  -> identity/representation mapping
  -> compatibility + contradiction analysis
  -> missing-facet discovery
  -> global portrait
  -> ORION-native synthesis/formalism when warranted
```

Two search modes remain distinct:

- **GLUE**: conservatively align more projections of the same underlying object.
- **JUMP**: adventurously seek distant systems preserving useful deep structure; mappings remain hypotheses until target-domain validation.

The principle now explicitly applies at the scale of disciplines. NLP, psychometrics, information retrieval, data integration, HCI, formal epistemology and future fields are charts over aspects of a research object, not automatically competing worldviews.
