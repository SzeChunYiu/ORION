# ORION mechanic invariants

Every mechanic inherits a universal non-compensatory invariant layer before step-specific invariants are researched.

The current Shadow baseline preserves the strongest RAKL obligations and the new mechanics-of-mechanics lessons:

- generation/model output/telemetry cannot directly mint scientific authority;
- weaker relation/measurement types cannot silently escalate to stronger claims;
- negative/null/refuted history remains addressable;
- shared evidence lineage does not create independent confirmation;
- missing mandatory evidence/measurement fails closed;
- new material residuals reopen dependent closure;
- candidates cannot weaken their protected evaluator to self-promote;
- uncertainty assumptions remain visible;
- bounded/formal closure never implies universal completeness or empirical validity;
- material state mutates only through declared transitions/receipts;
- local metrics require an explicit witness before they count as root progress;
- resource exhaustion with open obligations yields `CANNOT_CHECK`, not closure;
- repeated failure/success cannot self-promote a failure-derived guard without replay, fresh transfer and protected verification.

These are hard gates, not weighted metric terms. Every child mechanic still requires step-specific domain/correctness invariants and hostile validation.
