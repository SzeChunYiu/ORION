# Mechanic metrics

ORION separates raw observability from decision-driving metrics and separates local performance from root effectiveness.

The universal V0 metric vector contains:

- non-compensatory contract/authority/interface pass gate;
- root-relevant progress (typed/task-specific; no universal numeric scale);
- material residual change;
- coverage gain;
- failure/reliability rate;
- normalized cost;
- latency;
- remaining uncertainty/cannot-check obligations;
- blocking-invariant regressions (hard zero gate).

No universal scalar score replaces this vector. A scoped scalar utility is admissible only with explicit tradeoff/calibration semantics and cannot compensate for a failed hard gate.

## Root transport

A local score does not become root progress merely because it improved. Every metric declares what witness is required to transport it to the root problem. Examples: lower latency matters only under preserved output/invariant conditions; higher evidence count matters only when relevance/lineage improve; residual contraction matters only for root-relevant residuals.

## Construct validity

The V0 vector is a control scaffold, not a claim that it measures every mechanic's target construct. SEARCH may need recall/novelty/lineage metrics; ABSORB may need semantic/claim extraction validity; DIAGNOSE may need cause-discrimination calibration; GLUE may need compatibility/false-merge metrics. Each cell retains an empirical-open coordinate for its step-specific effectiveness/performance construct, validity, reliability, calibration, comparability and decision thresholds.
