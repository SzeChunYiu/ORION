# Mechanic search-coverage obligations

A mechanic's knowledge basis cannot be declared flat merely because repeated nearby queries stop returning new material.

The Shadow V0 contract reconstructs RAKL/OWMD's strongest route-diversity lesson and adds explicit parent-discipline/omission semantics. Depending on applicability, the mechanic research programme challenges:

- current terminology and lexical variants;
- function-only descriptions with framework/domain labels withheld;
- parent disciplines;
- historical precursors;
- mathematical equivalents;
- implementation analogues;
- methodological inspirations;
- distant/cross-domain systems;
- literature bridges;
- citation neighborhoods;
- adversarial omission probes;
- cross-language routes where relevant;
- freshness/current literature.

Different query strings do not count as conceptual independence when they preserve the same ontology. At least one route must materially change vocabulary, domain, formalism or evidence lineage.

This file defines coverage obligations, not completed search. Each route requires an execution/source ledger or a justified applicability decision. Bounded saturation remains separate and must reopen if a route discovers a new material mechanic coordinate, parent domain, contradiction, failure mode or empirical obligation.
