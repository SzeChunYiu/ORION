# Public empirical-data binding lane

This lane audits online public empirical sources for P1, P2, P3 and P5. P4 is
explicitly excluded because it has a separate owner.

Start with `EVIDENCE_REPORT.md`. Machine-readable authority is in
`PUBLIC_SOURCE_BINDINGS.json`; public-provider receipts are in
`ONLINE_EVIDENCE_RECEIPTS.json`; outcome-blind source selections are in
`MINIMAL_SAMPLING_MANIFESTS.json`.

The lane did not inspect dataset rows or protected outcomes, did not execute an
empirical campaign, and did not run pytest or CI. A downloadable public file,
licence, label schema, or runnable donor is not empirical support for any paper.
