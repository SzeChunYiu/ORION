## 1. Question

Does a frozen quantum compilation family admit an objective-independent finite primitive move set `T` such that, for every admitted linear objective and every feasible non-optimal compilation, some feasible augmentation generated by `T` strictly improves cost?

The target is a compiler-specific analogue of a universal optimization test set. Graver bases, circuit directions, Markov/Gröbner/Hilbert bases, M-convex exchange and augmentation theory are donor mathematics and receive zero novelty credit.

The first family is **R6I**, because:
- exact production semantics are additive/min-plus;
- QG-9 V6 proves the all-n unit-objective support-one normal form;
- the successful whole-system Tag relocation is a hostile control against an incorrectly local representation.

R6M/TARE is a second-family transfer only after the R6I calibration has an honest terminal.

## 2. Frozen representation attempt

Construct an exact lifted integer representation of the R6I feasible set. A candidate state vector may contain binary/integer variables for:
- local Pauli/frame choices;
- shared Tag letters/labels;
- central branch selectors;
- Restore-support indicators;
- relative block permutation;
- parity carries for symplectic/Tag XOR constraints;
- dependent-frame relations.

The representation is valid only if it is **bijectively or cost/semantics-preservingly bound** to the frozen compiler configurations needed by the theorem. It may not drop a constraint merely because the dropped model is easier to express as `A x=b`.

Required semantic bindings:
1. `R2=R0*R1` exactly;
2. rank-2/anticommutation acceptance exactly;
3. equal ordered nonzero/distinct shared Tag labels exactly;
4. frame/Tag/Restore resource vector exactly;
5. all frozen central/permutation choices exactly;
6. no target-dependent constraint omitted from a purported target-independent fiber.

If exactness requires instance-dependent constraints that invalidate a fixed kernel/test-set interpretation, terminal may be `QG19_FIXED_KERNEL_REPRESENTATION_REFUTED__CONTEXT_DEPENDENT_MOVE_REQUIRED`. Do not force the representation through a relaxation.

## 4. Primitive move extraction

For an exact semantic fiber, enumerate feasible state differences `g=y-x` with zero semantic displacement. Extract candidate primitive moves under a frozen indecomposability order:

- conformal decomposition when the lifted integer coordinates make this meaningful;
- otherwise a separately declared minimality relation preserving exact feasibility semantics.

Do not call a set a Graver basis unless the exact mathematical prerequisites and extraction definition match the donor object. Generic ORION must independently verify the minimality predicate.

For each primitive move serialize:
- canonical orbit identifier;
- support/locality footprint;
- exact semantic delta (must be zero);
- exact resource delta vector;
- preconditions for feasibility;
- inverse move if admitted;
- correspondence, if any, to an already-earned ORION-QG move.

For every exact feasible state x:

`NO_IMPROVING_T(x,theta) := no feasible positive augmentation generated by T_n has negative theta·Delta r`.

Primary bounded test:

`x globally optimal  <=>  NO_IMPROVING_T(x,theta)`.

Record false-optimal and false-nonoptimal directions separately. One false-optimal counterexample defeats the bounded universal-test-set claim for that representation/T_n.

## 7. Stabilization question

A separate all-n theorem may be attempted only if bounded calibrations pass.

Candidate statement:

> Modulo declared qubit/permitted Pauli symmetries, every primitive improving move for any n embeds an orbit representative from a finite set `T_*` supported on at most k coordinates.

Required proof ingredients must be explicit. Acceptable donor-owned routes include:
- finite-support normal-form theorem plus locality of semantic repair;

- direct compiler-specific exchange/composition lemma.

Finite equality `T_2=T_3=T_4` is evidence only, never a proof.

## 8. Objective-phase generation

For every primitive move resource delta `d`, its affine tie set is `theta·d=0`.

Compare the hyperplane arrangement induced by primitive deltas with:
- QG-16 retained certificate facets;
- QG-17 selected witness hyperplanes after QG-17 has an outcome;

Keep three notions distinct:
1. **move tie hyperplane**;

A coincidence between (1) and (2) does not prove (3). A true-boundary claim needs exact global witnesses/coverage or an independent completeness theorem.
