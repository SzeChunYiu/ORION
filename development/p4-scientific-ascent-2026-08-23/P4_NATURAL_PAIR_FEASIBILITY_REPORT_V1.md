## Required source expansion

The successor freezes provider/content families before acquisition:

1. exact arXiv version histories and abstract/full-text states for M1/M2;
2. explicitly licensed protocol/result and correction pairs from scholarly
   full-text repositories for M3/M4;
3. Zenodo/DataCite-discovered dataset and software releases with root-specific
   CC BY/CC0 or code licences and typed related identifiers for M5/M6;
4. separately licensed proceedings/full-paper and supplement/article pairs for
   M7/M8;
5. Crossref/OpenAlex only as discovery/deduplication metadata, never as content
   permission.

Every provider must populate a quarantined rights ledger before any case
adjudication.  If a frozen domain x mechanism cell remains below 48 rights-bound
candidate pairs, its successor terminal is a source-cell shortfall.  The
mechanism, domain, quota and claim margin may not be changed after case outcomes.
