## Theory insertion

We separate native method terminals from revision-responsibility decisions.
Let g map a task world to the complete terminal exposed by a comparator and let
r map the same world to its minimal revision class. An exact deterministic
adapter A satisfying r=A composed with g exists if and only if r is constant
on every fibre of g. Consequently, a single pair of admissible worlds with the
same native terminal but different minimal classes proves that no singleton
projection is valid on that terminal.

## Conclusion insertion

Interface breadth cannot be created by relabelling coarse native statuses.
Unsupported and mixed fibres are a scientific identification limit and must
remain UNRESOLVED. The next test is whether prospectively certified
single-front actions yield correct minimal revisions under matched external
evaluation, not whether a wrapper can force every method into every class.
