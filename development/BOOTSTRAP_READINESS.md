# Bootstrap readiness — minimum autonomous kernel

**Scope:** readiness to plug in a real LLM/retriever/verifier stack and execute the minimum governed recursive solve loop.

**Verdict:** `MINIMUM_KERNEL_LLM_INTEGRATION_READY`

## Evidence

- K/W/M are separate typed state coordinates.
- Core mechanics are decomposed into modules rather than one agent/prompt.
- LLM, retrieval and verification are provider ports; callable adapters exist.
- `OrionRuntime.from_providers(...)` is the composition root.
- Search/model output cannot directly mint scientific authority.
- Final solve requires verified evidence when configured.
- Final solve also requires bounded saturation over knowledge, search-universe and formulation.
- Bootstrap saturation requires heterogeneous routes including parent-discipline, literature-bridge and adversarial-omission challenges.
- A deterministic known-world benchmark demonstrates domain discovery -> residual -> diagnosis -> W reframe -> re-search -> two flat rounds -> verified solution.
- A negative benchmark refuses an otherwise supported answer when independent route coverage is incomplete.
- High-impact future ORION development has an executable atomization/saturation/basis-challenge gate.
- Paper 01 and the runtime registry share a machine-checked framework snapshot.
- CI is green at the bootstrap integration head before this readiness record.

## Explicitly not established

- high recall on live scientific literature;
- adequacy of the current route family for unknown unknowns;
- robust open-ended NLP/scientific semantic extraction;
- global-portrait quality on real multi-domain research;
- query/patch-level stopping policy;
- completeness of known-unknown/ignorance representation;
- reliable live LLM JSON/schema behavior;
- external-tool/code execution;
- empirical superiority to baseline research agents;
- Shadow/Governed Self-ORION readiness.

## New reopen fibers from the bootstrap knowledge search

1. **route-level vs task-level stopping** — information-search research distinguishes abandoning/switching a query from ending the whole information task; ORION currently formalizes the latter more strongly than the former.
2. **ignorance representation** — work on structured `known unknowns` suggests residuals may need richer scientific-ignorance categories rather than one generic gap object.
3. **live wide-research evaluation** — autonomous scientific-literature benchmarks show that wide literature discovery is a distinct and difficult capability.

These do not block provider integration, but they block any claim that the current kernel is a mature autonomous research scientist.
