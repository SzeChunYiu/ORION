# P3 public-to-protected repair design

**Identity:** `P3.EPE.PUBLIC_TO_PROTECTED.REPAIR.V1`  
**Status:** prospective repair design; no outcome  
**Relationship to frozen work:** this document does not modify
`P3.PARTIAL_IDENTIFICATION.EXCESS_HARM.V1` or inherit any public outcome.

## 1. Two lanes that must never be conflated

### Lane A — public mechanism debugging

CRAFT, SciREX and OAEI public reference labels may be used only after outputs
freeze and must always retain `protected_evidence=false`. Lane A can expose
transport failures, coverage loss and representation sensitivity. It cannot
be independent confirmation.

### Lane B — protected naturalistic execution

Public raw inputs may seed an outcome-blind frame, but P3-specific relations,
identified sets, coordinate opportunities and downstream losses must be newly
commissioned, hidden from all system builders/runners and independently
adjudicated. Public donor labels cannot be copied, translated or treated as
protected gold. Lane B is the only route that can execute the frozen protected
claim, and it remains blocked until all required strata and roles exist.

## 2. Pre-outcome gates

No case or outcome-bearing content may be released to a runner until all gates
below are signed and hashed.

| Gate | Required receipt | Blocking terminal |
|---|---|---|
| Rights | human decision naming source, version, content classes, operations, redistribution, attribution and expiry | `CANNOT_CHECK_RIGHTS` |
| Source identity | provider URL/record, immutable body digest and exact allowed archive members | `CANNOT_CHECK_SOURCE_IDENTITY` |
| Outcome separation | input-only member manifest; evaluator-only members under separate custody | `INVALID_OUTCOME_SEPARATION` |
| Case universe | deterministic source-native candidate-generation and blocking rule, frozen on development only | `INVALID_CANDIDATE_UNIVERSE` |
| Actions | one common four-terminal contract and complete loss matrix | `INVALID_ACTION_SET` |
| Comparators | exact revision, licence, environment, input adapter and terminal map for every arm | `CANNOT_CHECK_COMPARATOR` |
| Opportunity | blinded counts for every claimed coordinate and truth class, without system identities | `ZERO_OR_UNKNOWN_OPPORTUNITY` |
| Coverage | numeric envelope-coverage threshold and missing-case policy | `CANNOT_CHECK_COVERAGE_GATE` |
| Custody | distinct builders, runners, gold joiner/adjudicator and verifier, with actual independence stated | `CANNOT_CHECK_CUSTODY` |
| Analysis | cluster-level estimand, uncertainty, multiplicity and all terminals hashed before outcomes | `INVALID_ANALYSIS_FREEZE` |

A Boolean command-line acknowledgement is not a rights receipt or custody
receipt.

## 3. Lane A executable closure

### 3.1 Start with OAEI only

OAEI is the sole donor with a locally acquired, provider-MD5-verified archive
and a byte-reproducible input census. It is nevertheless one seed family and
therefore only a descriptive mechanism falsifier.

Required implementation sequence:

1. Extract only allow-listed `onto.rdf` members into an input-only quarantine;
   never extract `refalign.rdf` for builders/runners.
2. Freeze an ontology-pair manifest with member SHA-256 hashes and one common
   correspondence candidate universe. Candidate generation may use only raw
   ontology labels, identifiers and local structure.
3. Implement the P3 envelope candidate and every comparator against exactly
   that universe.
4. Bind one maintained OAEI-capable source-native matcher at an exact revision,
   with offline external-resource policy and a terminal-preserving adapter.
5. Freeze unique, complete prediction rows and input digests.
6. Transfer outputs to the public-gold joiner. The joiner alone opens
   `refalign.rdf`, supplies authority-owned cluster/source identities and
   computes the frozen endpoints.
7. Publish all 21 perturbation trajectories descriptively under one cluster;
   do not compute an interval pretending that tests are independent.

### 3.2 Four-terminal semantics

Before step 3, decide explicitly whether `PLURAL` is:

- a world/query state;
- an admissible set containing multiple scientific views;
- a downstream action to preserve plurality; or
- some combination with distinct encodings.

Then freeze a complete loss matrix for
`{GLUE, OBSTRUCTION, PLURAL, UNRESOLVED}` actions against every licensed state.
No default `else -> OBSTRUCTION` mapping is permitted. The minimax floor,
coverage, over-resolution and exactness must all consume the same state model.
An information-equivalent ideal product must tie under this matrix.

### 3.3 Statistical output

For the current OAEI family, report:

- exact case and candidate-universe coverage;
- envelope coverage and size;
- all four terminal confusions;
- floor-adjusted harm by perturbation type and loss regime; and
- paired candidate-minus-comparator differences as descriptive trajectories.

Do not report a population p-value, bootstrap confidence interval or broad
ontology-family claim from this single seed.

## 4. Donor-native comparator binding

A single generic comparator family cannot fairly cover ontology alignment,
biomedical concept/coreference mapping and document-level scientific IE.
Every donor therefore needs its own strongest runnable external arm plus one
common information-equivalent boundary arm.

- **OAEI:** bind a maintained OAEI-capable matcher (AgreementMakerLight and
  LogMap are candidates to verify, not bound facts) with exact revision,
  licence, resources and threshold policy. Reject a KG entity-alignment system
  as the primary arm unless its ontology-terminal adequacy is demonstrated.
- **CRAFT:** bind task-specific official or strongest reproducible shared-task
  systems separately for concept normalization and coreference. A lexical
  matcher is not a strong biomedical comparator, and results from distinct
  tasks may not be silently pooled.
- **SciREX:** reproduce the official model at `7daad660…` and preserve its
  native Method/Metric/Task/Material/Score and n-ary-relation terminals before
  projecting to P3. Missing table mentions must remain an adverse stratum.
- **Temporal donor:** bind both a source-native version/history comparator and
  a time-agnostic ablation; both receive the same source snapshots.

Any comparator whose environment, model artifacts, external knowledge or
terminal adapter cannot be replayed receives `CANNOT_CHECK`, not a substitute
weaker baseline.

## 5. Temporal opportunity acquisition

The current three donors contain no natural temporal scientific-identity
opportunity. Do not manufacture one from publication dates, provider splits or
OAEI test numbers.

Potential public frames for rights and suitability screening are:

1. ClinicalTrials.gov historical study versions for biomedical constructs,
   outcome measures and eligibility/context changes;
2. openly licensed arXiv version chains for physics claims and measurement
   revisions;
3. explicitly versioned, openly licensed climate data/model records; and
4. versioned public preregistrations or survey instruments for social-science
   construct/measurement changes.

These are candidates, not bound sources. Each must pass exact licence/content
rights, immutable history retrieval, independent-unit, nonzero-opportunity and
new-gold feasibility checks. A source qualifies only when two versions can
share a visible coarse projection while a source-grounded temporal/context
fact changes the licensed identity/action. Mere textual change is not a P3
opportunity.

For the frozen 16-stratum protected execution, temporal material must be
source-disjoint from development and provide the prespecified independent
source-artifact-family clusters. If any temporal stratum has zero or unknown
opportunity, the four-coordinate intersection claim is `CANNOT_CHECK`.

## 6. Lane B protected execution packet

### Units

Retain the frozen plan: 16 strata, 48 independent source-artifact-family
clusters per stratum, 768 planned units across four scientific domains.
Annotations, mentions, pairs, versions and technical repeats inside a cluster
are not independent units.

### Fresh protected gold

For each frozen cluster, two independent domain annotators plus adjudication
must supply:

- all four coordinate-opportunity flags and reasons;
- source-grounded relation state and admissible identified set;
- gold authority and evidence pointers;
- exclusions and `CANNOT_CHECK` reasons;
- downstream action loss or a stakeholder-approved loss range; and
- raw-text-to-structure stage labels.

Gold custody must be external to case builders and runners. Hash commitments
may be public before execution; content remains sealed until every system
output and environment receipt is frozen. Same-model or same-session review is
not independent custody.

### Primary comparative family

Fill, but do not mutate, the frozen four-comparator slots with exact named
systems before any protected outcome access. Every system receives the same
raw input, permissible donor artifacts, candidate universe, action set and
abstention/coverage contract. Include:

1. strongest donor-native external system;
2. strongest semantic/typed pairwise product;
3. complete-case conservative/blanket-deferral control; and
4. information-equivalent ideal product required to tie.

The P3 candidate must improve floor-adjusted harm against every primary
comparator at the frozen margin while passing coverage and clean-loss gates.
A failure of any intersection member preserves a negative terminal; no
post-outcome baseline substitution or subset promotion is allowed.

### Raw-text and temporal attacks

Run input-preserving redactions, table/mention loss, coordinate deletion and
version-context removal as prespecified attacks. Measure stage-attributed
failure and compare coarse versus truthful refined observations. A positive
mechanistic result requires identified-set shrinkage and lower floor-adjusted
harm after a source-grounded refinement, not merely higher point accuracy.

## 7. Required scorer redesign

The repaired scorer must consume immutable cases, predictions, gold, rights,
comparator and gate manifests together. It must reject:

- any forbidden outcome field anywhere in an input object;
- any unknown field outside a versioned closed schema;
- any prediction relation outside the four-terminal contract;
- duplicate or missing `(system_id, case_id)` rows;
- any prediction digest, source, panel or cluster mismatch;
- any missing rights/comparator/custody receipt;
- any absent or zero claimed opportunity;
- any missing coverage threshold or failed coverage gate; and
- any attempt to pool donor PASS terminals.

Cluster/source/panel identity comes from the frozen case/gold authority only.
Predictions contain no statistical-weight fields. Results must expose donor-
specific terminals, all adverse outcomes and a machine-readable reason for
every `CANNOT_CHECK`.

## 8. Promotion logic

1. A repaired OAEI execution can authorize only a public one-seed-family
   descriptive mechanism result.
2. Adding CRAFT or SciREX does not create a pooled PASS; each donor retains its
   own terminal and rights boundary.
3. A public temporal donor can show a public mechanism, not protected
   confirmation.
4. Only Lane B, with all 768 frozen clusters, fresh concealed independent gold,
   nonzero four-coordinate opportunities, exact comparator bindings and
   external custody, can evaluate the frozen protected claim.
5. Every null, harmful, invalid-coverage, rights-blocked, zero-opportunity and
   comparator-cannot-check terminal is preserved as a named scientific result
   or research blocker. Thresholds are never weakened after outcomes.
