search and not a relaxed interpretation of V7:

1. Make the strong u4 learner/balancer the mandatory base rather than an arm the

2. Learn only a residual representation/query correction using leave-one-review-
   out development and a frozen fallback to the u4 score when the residual is
   unsupported.
3. Optimize a continuous early-recall objective with explicit worst-review
   harm regularization; do not tune the V7 thresholds.
4. Freeze the resulting controller and test it on a source-disjoint public
   review family. V7 KIFMS becomes development evidence and cannot be reused as
   confirmatory data.

This directly implements the programme's upward requirement: absorb the
strongest neighbouring method and test whether ORION adds a safe residual,
rather than demanding that a weaker standalone candidate beat it.
