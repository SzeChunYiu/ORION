## Bounded saturation assessment

The repository search covered the complete P6–P8 paper directories, their
shared candidate checkers, P9 protocol/evidence/study modules, P10 manuscript
and authority artifacts, the root dependency lock, and all scoped tests. This
is sufficient for repository-local reproducibility mechanics because every
candidate target named by the V2 checker was traced to its concrete probe.

It is not saturation over empirical generality. No local search can establish
independent custody, produce a missing external model checkpoint, create a
fresh protected split after outcomes, or substitute a reference-policy trace
for a deployed-system result.

## Challenge to the saturation basis

- A generator can be cosmetically present while copying its output. Hostile
  tests must delete or corrupt the source and reject a generator that reads the
  target dataset.
- A lockfile can be present but unused. The reproduction route must invoke
  `uv sync --frozen` and run through the synchronized environment.
- A replay receipt can be self-authored. Local receipts must say
  `LOCAL_REPLAY_ONLY` and must never satisfy the independent-replay probe.
- A trace can replay an oracle rather than an agent. Its authority scope must
  remain `REFERENCE_POLICY_PREFLIGHT_ONLY`.
- A protocol can be frozen but infeasible. Validators must test attainability
  and required-input presence separately from execution and results.

## Why prior diagnostics were falsely flat

The V1 table copied one `CANNOT_CHECK` label across unlike targets. The V2
checker improved typing, but it still found missing local packaging alongside
genuine external authority gaps. The same word therefore mixed absent schemas,
unused dependency locks, unavailable third-party custody, and nonexistent
provider/checkpoint execution.

## Frozen implementation hypothesis

Add only successor artifacts:

- versioned schemas and deterministic generators for the existing P6–P8
  instruments;
- a P7 local reference trace and P8 local attack-replay receipt;
- paper-local one-command Makefiles and `REPRODUCE_V3.md` frozen-install routes;
- typed append-only negative/null registries and hostile validators;
- a V2 content-binding successor after the implementation commit;
- outcome-free P9 D1v1.3 and P10 H1–H6 protocol freezes with fail-closed input
  inventories;
- scoped tests proving that local evidence never grants independent or
  empirical authority.

No V1 receipt, historical result, endpoint, threshold, independent-unit
definition, or multiplicity rule may change. P10 execution is forbidden unless
every frozen input exists before outcomes.

## Acceptance and hostile checks

- generators reproduce committed bytes from distinct inputs and reject schema
  violations, duplicate IDs, wrong controls, or reading the target as source;
- the clean replay runs from `uv sync --frozen` and all expected sentinels and
  content digests match;
- P7 trace rows bind all eight cases; P8 attack replay binds all five laundering
  cases and labels itself locally authored;
- history source digests match and entries cannot claim positive authority;
- P9/P10 protocol validators reject missing protected inputs, post-outcome
  threshold changes, unit inflation, and uncorrected multiplicity;
- the diagnostic checker reduces only the targets actually supported by these
  artifacts; independent replay/custody remains unresolved.

## Reopen triggers

Reopen if any generator needs the target output as input, any committed digest
drifts, a local receipt satisfies an independent-custody gate, a protocol is
treated as a result, a P9/P10 run starts without all protected inputs, or a
historical adverse result disappears from the active evidence graph.
