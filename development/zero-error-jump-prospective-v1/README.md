## 1. Frozen scientific question

Can a candidate correctly identify and execute a **representational regime transition** on contamination-safe invented worlds where the incumbent model has exactly zero error on all public observations, while:

- an exact finite old-language check proves the protected explanatory/counterfactual contract is not expressible under the registered old-regime bound;
- the proposed new regime has a structurally valid representation move;
- old-domain behavior is preserved by an explicit correspondence witness;
- a protected consequence is derived before evaluator access;
- an informative thought experiment/intervention is selected;
- no Jump occurs on matched controls where the old regime is already sufficient;
- primary and disjoint replication splits agree;
- scoring is reconstructed by a separate verifier path;
- the strongest verified representation-revision parent receives exactly the same public information, move library, experiment budget and validation interfaces as ORION.

The pre-outcome candidate terminal is deliberately **negative with respect to ORION incremental value**:

`REPRESENTATION_INVENTION_NO_INCREMENTAL_VALUE`

The hypothesis is:

1. the positive worlds genuinely require a representational move relative to the **registered old regime**;
2. a strong verified representation-revision parent solves the registered task;
3. the full ORION Jump composition ties that parent exactly on primary and replication;
4. therefore this benchmark supports bounded regime-transition competence of the common parent structure, but not a distinct ORION Jump mechanic.

If ORION beats the strong parent, if the old DSL can express a positive target, if the replication diverges, or if contamination/preservation/authority checks fail, the frozen terminal is not earned.

## 2. Expert-panel roles

The study is challenged from four independent perspectives.

### Formal expressivity

Owns exact old-language enumeration and the distinction:

`SEARCH_HARD` vs `UNREPRESENTABLE_IN_REGISTERED_OLD_REGIME`.

A positive case is invalid if any old-language candidate under the frozen bound satisfies the full public + protected contract.

### Abduction / representation revision

Owns the strongest parent comparator. Recent mechanistic-world-model, M-open discovery and verified regime-revision work are treated as real parents, not weakened baselines. In particular, a verified representation-revision parent is allowed the same representation move library as ORION and can use the same thought-experiment outcome.

### Benchmark security / contamination

Owns opaque generated symbols, split seeds, candidate/public projection, outcome-access flags, banned historical names, outcome-permutation tests and structural scoring. This is **process protection against historical-answer retrieval**, not a cryptographic claim that a public repository can hide source code from a malicious reader.

### Scientific verification

Owns correspondence/preservation, protected consequence scoring and no self-authorization. A representation proposal without a correspondence witness or protected consequence is not a successful Jump.

## 4. Six positive families

Every positive family has `incumbent_observed_regime_error = 0`.

### A — zero-error unification / correspondence

Two local descriptions fit their visible domains exactly. No registered old-language candidate can state the protected cross-domain relation. A bridge/correspondence representation predicts a protected cross-domain consequence.

Required move class: `BRIDGE_CORRESPONDENCE`.

### B — counterfactual frame change

Ordinary trajectories are exactly predicted. A registered observer/reference-frame thought experiment exposes a relation that cannot be represented by the old coordinates under the bound.

Required move: `FRAME_COORDINATE`.

### C — hidden symmetry / invariant

Visible states are exactly fitted, but a transformation experiment reveals an equivalence orbit/invariant required for protected transfer.

Required move: `INVARIANT_ORBIT`.

### D — relational / higher-order lift

Local transitions are exactly predicted, but the protected composed-path contract depends on a relation/path object absent from the old variable language.

Required move: `RELATIONAL_LIFT`.

### E — causal object / contextual split

Passive observations are exactly fitted. A protected intervention distinguishes contexts that the old variable treats as one autonomous object.

Required move: `CAUSAL_SPLIT`.

### F — bridge law between exact local theories

Two local descriptions are independently exact. A cross-description calibration thought experiment reveals a typed relation needed for a protected composed prediction.

Required move: `BRIDGE_LAW`.

The labels are benchmark move classes, not claims that these are universal atomic invention operators.

## 5. Six no-Jump control families

A false Jump on any control counts against the candidate.

1. `PARAMETER_UPDATE_SUFFICIENT` — existing old-language model class contains a full-contract solution after parameter choice.
2. `FIXED_LANGUAGE_STRUCTURE_SUFFICIENT` — a new structure in the same registered language is enough.
3. `ADDITIONAL_EVIDENCE_SUFFICIENT` — the regime is adequate; another observation identifies the old-language candidate.
4. `NO_CHANGE_NEEDED` — incumbent already satisfies the full contract.
5. `MEASUREMENT_REPAIR_SUFFICIENT` — an apparent tension is an interface/measurement defect; the scientific representation must not mutate.
6. `SEARCH_HARD_BUT_EXPRESSIBLE` — the full solution exists in the old DSL but is placed late in the finite enumeration; this is the mandatory hard-search/non-Jump control.

## 6. Exact old-regime insufficiency gate

Every world carries an evaluator-side finite list of old-language hypotheses and their public/protected contract signatures.

The checker exhaustively enumerates the registered old language:

- positive world: **zero** candidates satisfy the full contract;
- no-Jump control: **at least one** old-language candidate satisfies the full contract.

The proof object records candidate count, matching-public count, full-contract solution count and a digest. It is not inferred from the candidate's failure to search.

## 7. Candidate-visible contract

A policy receives only a `PublicJumpCase.v1` projection containing:

- opaque case/object/relation IDs;
- public observations and incumbent predictions (which match exactly on positive worlds);
- the registered old-language public signatures;
- available thought-experiment IDs and costs;
- the outcome of the one selected registered thought experiment;
- the finite **meta-level representation move library**;
- correspondence obligations;
- public validation interfaces.

It does **not** receive:

- family name;
- gold representation move;
- protected consequence token;
- protected full-contract signatures;
- control/positive label;
- evaluator terminal.

The move library is intentionally shared with the strongest parent. This benchmark therefore does not claim open-ended invention beyond the frozen representation meta-language.

## 8. Output / success contract

A candidate output is successful on a positive case only if all non-compensatory gates pass:

- requests a regime change;
- chooses a representation move structurally equivalent to gold;
- chooses an informative registered thought experiment;
- emits a complete correspondence/preservation witness;
- predicts the protected novel consequence before evaluator access;
- does not claim scientific/adoption authority.

A no-Jump control is correct only if no representation change is requested and the registered old-regime solution/repair is used.

No weighted scalar may compensate for a missing preservation or protected-consequence gate.

## 9. Comparator ladder and fairness

Executable primary arms:

1. `OLD_DSL_EXHAUSTIVE` — exact search of the frozen old language;
2. `M_OPEN_SAME_REPRESENTATION` — may add one same-language structure but cannot change representation type;
3. `FIXED_REP_WORLD_MODEL` — mechanistic latent search constrained to old representation types;
4. `VERIFIED_REGIME_REVISION_PARENT` — strongest parent; may use the exact same move library, thought experiment and verification/correspondence interface as ORION;
5. `ORION_JUMP` — typed composition using the same public resources;
6. `ORION_NO_CORRESPONDENCE` — ablation;
7. `OVERJUMP_ALWAYS` — false-Jump control;
8. `ORACLE` — evaluator-only ceiling, excluded from superiority claims.

Literature-only/mechanism comparators remain in the baseline registry with `MECHANISM_COMPARATOR_ONLY` when no credential/model-stable executable binding exists. The terminal depends on the strongest executable parent, not on weak LLM strawmen.

## 10. Pre-frozen expected terminal pattern

The exact numeric expectations are stored separately before the runner. The load-bearing scientific pattern is:

- old-DSL / same-representation / fixed-representation arms cannot solve a positive full contract;
- they can correctly avoid Jump on all controls;
- verified regime revision parent solves every positive and every control;
- full ORION solves the identical set with identical proposal decisions;
- ORION-minus-correspondence fails every positive preservation gate;
- always-Jump produces false Jumps on every control;
- oracle equals the parent/ORION ceiling;
- primary and replication metrics are identical at the registered finite-family level;
- strong-parent incremental gap for ORION is exactly zero.

## 11. Independent reconstruction

A separate verifier module must reconstruct split identities, old-language insufficiency counts and protected metrics from serialized candidate decisions without importing the main scoring function.

This is implementation-path independence, not a claim of an external human replication. Scientific authority remains separate.

## 12. Reopen / falsifier conditions

Reopen the protocol if:

- a positive full contract is expressible in the frozen old language;
- public projection contains family/gold/protected leakage;
- opaque renaming changes structural score;
- historical names appear in gold or public symbols;
- a representation proposal succeeds without correspondence/preservation;
- a protected consequence is derived only after outcome access;
- thought-experiment outcome permutation leaves an evidence-responsive proposal unchanged when the outcome is load-bearing;
- the strong parent has a smaller move/action/validation budget than ORION;
- primary and replication produce materially different parent-vs-ORION disposition;
- the independent verifier disagrees with the primary scorer;
- a post-freeze donor provides a stronger parent requiring a changed comparator;
- repository CI or exact-head integration fails.

## 13. Scientific nonclaims

Even a perfect finite-family result does not establish:

- open-ended autonomous scientific creativity;
- human-like imagination;
- ability to invent representation operators outside the frozen meta-language;
- historical scientific rediscovery competence;
- contamination security against a malicious reader of a public repository;
- novelty of representation revision, correspondence, mechanistic world models or analogy;
- superiority over the verified representation-revision parent if the frozen tie is reproduced.

The intended result is narrower: **the benchmark can demonstrate old-regime representational insufficiency and validated regime transition, but the full ORION composition has no incremental value over a strong verified representation-revision parent on this registered family.**
