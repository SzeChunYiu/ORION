# P2 SYNERGY bounded-screening successor

## Purpose

The public-data audit bound SYNERGY V1 as the strongest licensed naturalistic
substrate for P2: 26 systematic-review pools, 169,288 OpenAlex work records,
public inclusion labels, and a CC0-1.0 dataset release.  It is not an open-web
route world and cannot decide P2's wide acquisition/closure claim.  It can,
however, replace constructed examples with a real-data acquisition component
test and quantify the gain from active screening over static and random
selection under a matched screening budget.

## Scientific boundary

The study is a public-label development benchmark. Labels are used only as the
simulated reviewer's response after a record is selected, except for the two
predeclared initial seed labels shared by every arm. Public labels are neither
protected outcomes nor independent custody. A positive result supports the
utility of an active-acquisition donor component on bounded pools; it does not
support ORION-specific novelty, open-world route invention, or valid scientific
closure.
