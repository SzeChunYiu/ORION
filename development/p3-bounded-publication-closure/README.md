# P3 bounded-publication closure development packet

## Development question

Can ORION-P3 close its current publication lane on the already replicated public-reference mapping/obstruction result without silently broadening that result into the larger expert-atlas programme?

## Review roles

This decision is pressure-tested through three independent roles:

1. **Scientific evidence auditor** — traces the proposed headline to the disjoint confirmatory result and independent verification boundary; rejects any move from mapping-only evidence to broader end-to-end scientific integration authority.
2. **Methodology / novelty reviewer** — separates the surviving typed mapping/obstruction claim from generic schema matching, ontology alignment, provenance, and other donor mechanisms; treats the full expert atlas as a separate generalization question.
3. **Reproducibility / editorial engineer** — requires one frozen paper subject, deterministic regeneration, claim-ledger consistency, and a submission package that cannot reinterpret a follow-up objective as already completed evidence.

The three roles agree only on the bounded decision recorded below; none of them grants new empirical or novelty authority.

## Atomic fibres

1. identify the exact P3 result that is already independently reproducible;
2. freeze one publication-level claim no broader than that result;
3. enumerate explicit nonclaims that prevent atlas/generalization laundering;
4. separate the expert-atlas programme into a follow-up lane instead of deleting it;
5. add a machine-readable claim-boundary record and fail-closed checker;
6. leave any external/submission-time obligations open until they are actually satisfied;
7. reopen the bounded lane if evidence, verification, nearest work, or the selected claim changes.

## Incumbent evidence and negative history

The current bounded evidence is the disjoint public-reference confirmatory mapping result already carried by the P3 programme and #283 verification surface:

- confirmatory `n = 32`;
- ORION false merges `0/32`;
- flat comparator false merges `6/32 = 0.1875`;
- paired absolute difference `-0.1875` with reported 95% interval `[-0.34375, -0.0625]`;
- false-split difference `0`, with the reported non-inferiority interval `[0, 0]`;
- scope: already-structured public-reference mapping, not unrestricted raw-to-ontology reconstruction.

Earlier ambitions for a broad expert-annotated multi-domain atlas are preserved as follow-up work. They are not re-labelled as completed and are not used as evidence for the bounded claim.

## Saturation assessment

The programme-level publication decision already distinguishes two scientific questions:

- whether the current public-reference mapping/obstruction result is a defensible bounded paper result; and
- whether a substantially larger expert atlas supports broader generalization.

Waiting for the second question before publishing the first creates a false dependency. Removing the second question entirely would hide an unresolved generalization objective. The bounded-track solution preserves both facts.

## Challenge to the saturation basis

This closure is invalid if any of the following is true:

- the confirmatory set overlaps the development set materially;
- the independent verifier cannot reproduce the denominator/result;
- the manuscript claims raw extraction, universal cross-domain mapping, or expert-atlas generality;
- current nearest work absorbs the exact residual claim;
- the final paper changes its claim after this freeze without reopening the record.

## Frozen implementation hypothesis

A versioned P3 publication-track record plus a deterministic checker can make the scope decision mechanically inspectable: the current paper may use only the public-reference confirmatory mapping/obstruction claim; expert-atlas generalization remains follow-up and becomes a blocker again only if the manuscript deliberately broadens to that claim.

## Reopen triggers

Reopen this packet on any raw-evidence or #283 discrepancy, claim-ledger/manuscript broadening, changed result identity, new nearest work that changes the residual, a failed exact-subject reproduction, or a decision to make expert-atlas generalization part of the current headline.
