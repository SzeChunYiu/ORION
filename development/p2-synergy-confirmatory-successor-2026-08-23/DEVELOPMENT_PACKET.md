# P2 SYNERGY eight-world relative-acquisition confirmation

## Scientific decision

The four-world predecessor found a large relative benefit but missed its
absolute gate.  At 10% screened, active logistic acquisition reached macro
recall 0.687516 versus 0.475777 for the stronger aggregate comparator, won or
tied three of four worlds, and produced positive WSS@95 in every world.  The
absolute 0.80 gate nevertheless failed, driven by Moran_2021 recall 0.180180.
That failure and terminal remain immutable.

This successor does not lower the predecessor gate on the same outcomes.  It
changes the estimand to the cross-world **relative acquisition effect** and
carries the unchanged V2 model, features, seeds, batch rule, budgets and
comparators into eight previously unopened review worlds.

## Outcome-blind panel

The source frame is the frozen Dataverse metadata receipt for all 26 SYNERGY V1
worlds.  The four burned worlds are excluded.  Each remaining world is ranked by
`sha256("P2-SYNERGY-CONFIRM-V1:" + world_id + ":" + labels_sha1)`, and the eight
smallest keys are selected.  `PROTOCOL_FREEZE.json` records every file identity,
byte count and checksum before any selected body is downloaded.

## Positive authority if every gate passes

A positive terminal supports a donor-derived active-screening component on
heterogeneous, bounded public systematic-review pools.  It does not repair the
predecessor absolute gate, establish ORION-specific superiority, decide open-web
route invention or closure, create protected freshness/custody, or license a
claim outside this task family.

## Alternatives rejected before outcome access

1. Tuning Moran_2021 until it passes is allowed only as burned-world
   development; it cannot create confirmation.
2. Selecting worlds after opening labels would be outcome-dependent sampling.
3. Rewording the four-world gate after observing it would overwrite adverse
   history rather than solve a successor problem.

## Verification boundary

In scope: source hashes, exact label/work joins, deterministic execution,
machine-readable result validation, and scientific interpretation.  Pytest and
repository CI remain excluded by the user's current instruction.
