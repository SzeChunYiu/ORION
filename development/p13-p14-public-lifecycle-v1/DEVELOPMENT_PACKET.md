# P13+P14 public lifecycle acquisition-pilot freeze

## Atomic question

Can the consolidated lifecycle-contract paper freeze a lawful, objective,
AI-retrievable acquisition pilot over the required repository/organization
breadth without confusing candidate public Git metadata with verified external
gold or human governance authority?

## Retrieval and license audit

Thirty public repositories from 26 organizations were queried through the
GitHub connector on 2026-08-24. The selected head commit and its reported
parent/merge base were resolved with connector search and compare operations.
Each license file was fetched at the reported head and recorded by Git blob
SHA-1 plus SHA-256; only metadata is committed and
`full_text_redistributed=false` for every record. These are frozen acquisition
targets, not independent live-Git verification receipts.

Three initially selected repositories (`encode/starlette`, `encode/uvicorn`,
`facebook/react`) returned no commit through the available connector search and
were excluded rather than guessed. `nodejs/node` was replaced because its
composite third-party license register exceeded the bounded local command
argument used for SHA-256 calculation. No partial Node license hash was retained.

## Saturation challenge

The 30 repositories exceed the issue minimum and cover 26 organizations, but
they are predominantly open-source software repositories hosted on GitHub. This
does not saturate other forges, private CI, signed-release practices, social
governance decisions or hardware/site independence.

## Hostile-review correction

Hostile review rejected treating manifest equality as objective gold and
rejected repository-block inference from identical repeated templates. It also
found that URLs, retrieval metadata, license sizes and runner/source identity
were insufficiently bound. The increment was therefore downgraded from a
campaign protocol to an acquisition pilot; no result generator remains.

The validator now fail-closes relational URL/path/date/operation bindings,
zero identities, runner-byte drift and authority drift. It freezes 210 fixtures,
including forged commit URLs, and requires a later live-Git acquisition with
retained receipt digests. This increment must not contain a result receipt or
check an execution box in issue #1086.

Scientific-authority delta: **NONE**. Semantic governance quality, independent
expert adjudication and protected custody remain **CANNOT_CHECK**. Objective
gold is **CANNOT_CHECK_UNTIL_LIVE_GIT_ACQUISITION**, and no repository-bootstrap
inference is authorized.
