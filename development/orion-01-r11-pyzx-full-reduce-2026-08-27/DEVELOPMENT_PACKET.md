## Bounded saturation assessment

### Knowledge

The frozen knowledge set is the current ORION-01 convergence record, issues
#1513/#1520, the R9 adverse terminal, the R12 non-identifiability theorem, the
PyZX source at the registered commit, and current equality-saturation / exact
rewrite donors already named by the programme.

### Search universe

The scientific subject is only the automatic macro-operation language reached
by public `pyzx.simplify.full_reduce`; it is not the set of all PyZX public
rewrites and not the ZX calculus. The input universe is every word of length
zero through four over a fixed eight-gate alphabet on two qubits. Exact search
explores every state reachable by reordering the twelve registered automatic
macro operations. No trace-derived rule, learned rule, heuristic branch
pruning, sampled input, or protected Task-3/P9 material is admitted.

### Formulation

For a source graph `G`, let `F(G)` be the result of the pinned `full_reduce`
schedule. Let `Reach_M(G)` be the complete finite state graph generated by the
registered macro language `M`. Resource is the lexicographic tuple
`(non_Clifford_vertices, non_boundary_vertices, edges)`. The realized schedule
gap is strict exactly when

```text
min { resource(H) : H in Reach_M(G) } < resource(F(G)).
```

This is a bounded source-relative statement. It is not an unrestricted
compiler optimum or a lower bound for all sound PyZX/ZX transformations.

## Challenge to the saturation basis

The R9 gate inspected an exact optimizer whose source had no transition
interface. PyZX exposes a named public simplifier whose finite transitive call
closure can be read from source. That changes the authority problem: the move
language can now be bound extensionally at the automatic-operation level
before outcomes are observed.
