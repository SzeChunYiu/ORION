## Bounded saturation assessment

The repository is sufficient to bind each predecessor, implement local design
validators, calculate source-cluster-level power, and construct hostile
attainability fixtures. It does not contain the new source/task/project frames,
the strongest live comparators, or independent evaluator custody. Local closure
therefore stops at `READY_FOR_EXTERNAL_BINDING` with an explicit
`CANNOT_CHECK_EXTERNAL_*` execution terminal.

## Challenge to the saturation basis

False closure could arise by counting cells, pair members, retries, retrieved
records, tests, or annotations as independent units; shrinking the comparator
family; calibrating from protected predecessor outcomes; accepting a gate that
cannot fail; hashing a missing artifact; or calling internal scorer ownership
independent custody. Hostile tests mutate each of these boundaries.

## Frozen implementation hypothesis

A common fail-closed preflight can validate historical immutability, independent
unit arithmetic, simultaneous-family power, local content bindings, paper-level
attainability conditions, and the external-evidence boundary without reading an
outcome. If any field is weakened, the preflight must refuse local readiness.

## Prospective designs

- **P1 R7A:** 32 family/domain strata x 12 independent source-pair clusters =
  384 per wave, plus 64 unresolved safety clusters. The multiplicity family is
  all nine comparators. Seeded 50,000-draw max-T planning at delta 0.20,
  margin 0.05, discordance 0.40 and FWER 0.05 gives projected joint power 0.920
  and conditional minimum 384. Sensitivity explicitly shows that delta 0.15 or
  discordance 0.50 requires a larger frame.
- **P2 V2:** 768 source-disjoint task-world clusters across four arenas; three
  fixed comparator contrasts; equal admissible route exposure and baseline
  identity reproduction are mandatory.
- **P3 V1:** 768 source-family clusters across four domains x four formerly
  inert coordinates; four comparator contrasts; opportunities exist only when
  the protected distinction remains separable under visible observations.
- **P4 V1:** 768 naturalistic source-case clusters across four domains x eight
  unidentifiability mechanisms; four comparator contrasts; each unidentifiable
  member has an identifiable same-source control.
- **P5 V1:** 768 source-disjoint project/issue clusters across eight domains x
  eight bounded revision classes; six comparator contrasts; visible-symptom
  blocks contain different protected causes.

All effect sizes and discordance values are prospective planning assumptions,
not estimates from protected predecessor outcomes. Each protocol states its
multiplicity family and retains a valid adverse terminal after execution.

## Reopen triggers

Reopen before outcome access if any source stratum cannot be populated, task or
project identities overlap, a stronger comparator cannot be run fairly, a
measurement is at zero resolution, an external evaluator cannot be separated
from candidate authorship, or sensitivity shows the attained design is below
the registered target. After outcome access, the design is immutable; failure
does not authorize gate relaxation or outcome-dependent replacement.
