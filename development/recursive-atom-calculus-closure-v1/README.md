## 6. Factorial / synergy protocol

For proposed children `a` and `b`, freeze candidate-visible information/resources and evaluate at least:

```text
Reach(R)
Reach(R+a)
Reach(R+b)
Reach(R+a+b)
```

Define:

```text
Unique(a) = Reach(R+a) - Reach(R)
Unique(b) = Reach(R+b) - Reach(R)
Syn(a,b) = Reach(R+a+b) - (Reach(R+a) union Reach(R+b))
```

Interpretation must remain non-compensatory:

- if only `Syn(a,b)` is nonempty and the children have no independent semantics, report `INTERACTION_ONLY`;
- if `Reach(R+a) == Reach(R+b)` and the pair adds nothing, a registered equivalent-family case may report `REDUNDANT_EQUIVALENT`;
- if an existing donor reproduces the candidate delta under the same bound, report `SUBSUMED`;
- if observables cannot separate proposed children, report `NON_IDENTIFIABLE` rather than inventing a decomposition;
- if one child is independently load-bearing, that is evidence for a separate bounded child study, not universal atomicity.

The executable closure checker includes frozen synthetic witnesses for standalone, interaction-only, redundant-equivalent and non-identifiable cases.

## 7. Recursion stop rules

The seven #507 stop reasons are frozen as first-class protocol outcomes:

1. donor/existing formalism supplies the same object at the registered resolution;
2. no protected discriminator separates children;
3. proposed children are implementation details with no bounded epistemic effect;
4. non-unique decompositions are observationally equivalent for the target contract;
5. only an interaction term has independent semantics;
6. further decomposition requires inaccessible/private cognitive variables;
7. further splitting would create anecdote-specific operators rather than reusable structure.

`IRREDUCIBLE_AT_CURRENT_RESOLUTION` means only that none of the registered stop/decomposition discriminators justifies another split under the current information/resource/validation resolution.
