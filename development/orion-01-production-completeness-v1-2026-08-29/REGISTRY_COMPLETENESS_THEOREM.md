# Relative production-registry completeness theorem

**Status:** analytic protocol theorem proved below; pinned-source instance obligations open  
**Current terminal:** `PROTOCOL_FROZEN__NO_OUTCOME`

## 1. Objects

Fix a uniquely resolved source commit and frozen execution environment. Let:

- `B` be the frozen byte corpus;
- `E` be the finite set of production entry roots;
- `C(E)` be the least call-graph closure generated by the edge rules in `CORPUS_MANIFEST.json`;
- `S` be the set of graph-mutation sinks in `SOURCE_COMPLETE_MOVE_GRAMMAR.json`;
- `R` be the set of mutation roots extracted from `C(E)` by the grammar's root rule;
- `D_r` be the complete admissible receiver, parameter, match, and side-condition domain of root `r`;
- `M = {(r,d): r in R, d in D_r}` be the set of move instances;
- `N(m,x)` be the deterministic normalized effect of move instance `m` on admissible canonical input `x`;
- `X` be a complete separating basis for the functions `N(m,.)` over the frozen admissible domain.

Define

`m ~ext n` iff `N(m,x)=N(n,x)` for every `x in X` and every jointly admissible parameter/side-condition partition represented by `m` and `n`.

Let `Q=M/~ext`. The generated registry contains one stable class identifier for every member of `Q` and maps every `m in M` to its unique class.

## 2. Instance obligations

The theorem is conditional on six independently checkable obligations.

**O1 — unique source identity.** The frozen prefix resolves to exactly one 40-character commit object before source import or semantic testing.

**O2 — source-boundary closure.** Every production execution beginning at a root in `E` remains within the evidenced call-graph closure, and every dynamic, native, reflective, callback, registration, re-export, and returned-delta edge has a finite resolved target set.

**O3 — mutation-root completeness.** Every path from `E` to a mutation sink in `S` crosses a recorded root in `R`, and every separately selectable production mutation is represented by a root even when it wraps another root.

**O4 — domain completeness.** For each `r`, `D_r` is a finite disjoint partition of all admissible receiver states, matches, parameters, and side conditions reachable in production. Every member of a partition has the same control-flow and normalized-effect function, or the partition has been refined.

**O5 — canonical-effect soundness.** The canonical graph/state encoding preserves every observation available to any later production operation or frozen ORION caller; repeated evaluation from byte-identical canonical inputs is deterministic.

**O6 — separation.** `X` separates all nonequivalent normalized-effect functions: whenever two move instances differ on any admissible input, some represented witness in `X` exposes the difference. Equality proofs may replace explicit witnesses only when they cover the complete admissible domain.

The production-source instance is not complete until receipts discharge O1–O6.

## 3. Theorem

### Theorem 1 (relative source-complete extensional registry)

If O1–O6 hold, then:

1. `M` is exactly the set of production move instances in the frozen boundary;
2. `~ext` is an equivalence relation on `M`;
3. each production move instance maps to exactly one class in `Q`;
4. no two distinct classes in `Q` have the same production-observable normalized effect;
5. the generated registry is complete and nonredundant relative to the frozen source, environment, entry roots, grammar, and admissible domain.

### Proof

By O1, all source and semantic objects are interpreted against one immutable commit. By O2, every production execution path from `E` has all callable targets represented in `C(E)`; there is no unresolved edge through which a production mutation can escape the boundary.

Consider any production mutation instance `p`. Its execution follows a path from some entry root to a sink in `S`. By O2 that path lies in `C(E)`. By O3 it crosses a recorded mutation root `r`, with wrappers retained whenever they are separately selectable. The concrete receiver, match, parameter, and side-condition assignment of `p` belongs to exactly one disjoint member of `D_r` by O4. Thus `p` corresponds to one member of `M`. Conversely, every member of `M` consists of a reachable root and an admissible domain member, so it is a production move instance. Hence statement 1 holds.

By O5, `N(m,x)` is a well-defined deterministic function. Equality of such functions on the complete domain is reflexive, symmetric, and transitive. O6 makes equality on the declared basis equivalent to equality on the complete admissible domain. Therefore `~ext` is an equivalence relation, proving statement 2.

Equivalence classes partition a set. Every `m in M` therefore belongs to exactly one member of `Q`; the ledger's total single-valued mapping realizes that partition, proving statement 3.

Assume two distinct classes had the same production-observable normalized effect. Their representatives would agree over the complete admissible domain. By O6 they would agree on `X`, and therefore be `~ext`-equivalent, contradicting that they are distinct classes. This proves statement 4.

Statement 1 gives source-relative completeness; statements 3 and 4 give totality, unambiguity, and absence of extensionally duplicate classes. Together they prove statement 5. QED.

## 4. Counterexample corollary

### Corollary 2 (fail-closed alternative)

If an execution conforming to the frozen protocol finds any of the following, it cannot emit `REGISTRY_COMPLETE`:

- a second or missing source-prefix match;
- an unresolved reachable call edge;
- a mutation path avoiding all recorded roots;
- an admissible input outside the frozen domain partition;
- an observable state component omitted by canonical encoding;
- nondeterministic normalized effects;
- a pair merged by the registry with a separating witness;
- a move instance with zero or multiple class assignments.

When replayable, the finding is a `REGISTRY_INCOMPLETE_COUNTEREXAMPLE`; otherwise the corresponding `CANNOT_*` or boundary terminal in `EXPECTED_TERMINALS.json` applies.

### Proof

Each listed finding negates at least one of O1–O6 or the total single-valued quotient map. Theorem 1 is therefore unavailable, and a completeness receipt would be unsound. QED.

## 5. Materiality lemma

### Lemma 3 (quotient preservation for class-congruent drivers)

Suppose a frozen production driver observes moves only through normalized effects and its scheduling/termination behavior is congruent under `~ext`. Replacing the syntactic move multiset by one representative per canonical class preserves every reachable canonical graph/state and every driver-observable terminal.

### Proof

At each driver step, replacing a selected move by an extensionally equivalent representative produces the same normalized effect. Congruence preserves the next driver state and the set of later admissible selections. Induction on finite executions, and coinduction on repeated-driver traces with the same frozen scheduling semantics, gives equal reachable canonical states and terminals. QED.

The lemma makes the registry scientifically consequential: it can remove aliases without changing the frozen production semantics. It does not prove that the quotient is smaller, that exact search terminates, or that a compiler metric improves. Those are outcome-dependent questions for a fresh Phase-4 protocol.
