# ORION-Q QC-2D — target-specific repair development packet

Tracking issue: #641
Parent programme: #633
Donor saturation: #638

## Development question

Can ORION gain anything beyond exact classical graph/control repair once the state includes partial/unknown edit feasibility, scoped negative history, representation-dependent applicability and false-obstruction cases?

The first phase deliberately predicts that the clean fully-known graph problem is donor/classically closed. Any positive ORION residual must appear only after matched-information epistemic structure is introduced.

## Atomic fibres

1. Freeze a small weighted component-graph repair world with existing and candidate couplings.
2. Compute exact target-specific repair cost independently.
3. Compute exact universal-repair cost independently.
4. Include `NO_EDIT` worlds and cases where universal repair strictly over-repairs.
5. Add explicit candidate feasibility states `VERIFIED`, `REFUTED`, `UNKNOWN` only after clean P0 is frozen.
6. Add scoped failure records with `required_same` and `reopen_on_change` semantics only after P0.
7. Add false-obstruction cases where search stopped but no language inadequacy certificate exists.
8. Preserve evaluator gold, component identities and optimal edge set outside model-visible weak views.

## Donor ownership / mandatory baselines

- Graph connectivity, shortest path, Steiner-tree-style repair, spanning-tree/universal repair and weighted graph optimization are donor/classical structure.
- Lie-algebraic invariant-subspace/graph universality criteria and constructive generator repair are quantum-control donor structure.
- Minimum-time/energy control with a fixed control set is donor structure.
- A clean fully observed target-repair graph is expected to be solved exactly by a non-ORION oracle. This is a required negative result, not a failure of the programme.

## Saturation assessment

Search so far found strong universal controllability repair, minimum-control-resource and state-transfer optimization parents, but no exact parent for the full ORION combination of target-specific method-set repair + explicit unknown edit feasibility + scoped negative history + representation-dependent reopening + false-obstruction discipline. This is provisional and must remain under S0 pressure.

## Challenge to saturation basis

The residual collapses if a close quantum/control system already performs all of:

1. diagnoses target-specific method/control-set insufficiency rather than only optimizing a fixed set;
2. represents candidate control additions with unknown/refuted/verified feasibility;
3. uses context-scoped failed-control history with explicit reopen conditions;
4. chooses between verify/query, repair, search-more and abstain under matched resource budget;
5. preserves representation/access-model provenance across changes.

If such a parent is found, absorb it and narrow again.

## Miss hypotheses

1. Apparent ORION value may come from giving the ORION arm feasibility/history information unavailable to baselines.
2. A graph solver plus Bayes/value-of-information layer may close P1 without P9/P10.
3. Raw negative history may help only because benchmark failures are unrealistically deterministic.
4. Representation changes may simply remint graph labels instead of changing applicability/cost.
5. Universal repair may appear worse only because costs were constructed to make it so; include equal-cost and universal-required controls.
6. `UNKNOWN` may be treated optimistically or pessimistically instead of as a queryable epistemic state.

## Frozen implementation hypotheses

### H0 — clean graph closure (expected negative ORION result)

> With complete correct knowledge of candidate-edge feasibility and costs, exact graph optimization reaches the target-specific optimum and ORION-specific state adds no legitimate value.

### H1 — scoped-failure/unknown residual (candidate positive)

> Under matched visible candidate/cost information and a frozen verification budget, explicit typed `UNKNOWN` plus context-scoped failure/reopen state reduces harmful pruning and false repair relative to raw-failure memory and no-history baselines, while approaching a clairvoyant graph oracle more closely.

H1 may be rejected. No architecture escalation is allowed if a simple Bayesian/search policy closes it.

## Frozen P0 hostile tests

- already-connected required support => `NO_EDIT` and cost 0;
- two-terminal shortest target repair computed exactly;
- multi-terminal target repair compared with exact enumeration on tiny graphs;
- universal repair cost >= target repair cost;
- at least one world has strict universal over-repair;
- at least one world genuinely requires universal connection of all components, so target-specific policy cannot always prefer a subset;
- candidate edge ordering permutation invariance;
- component identity remint invariance;
- negative/zero/non-finite costs rejected;
- duplicate/self-loop malformed candidates rejected if not explicitly allowed;
- evaluator optimal edge identities absent from model-visible weak view.

## Frozen P1 hostile tests

- cheapest candidate `UNKNOWN`, verified alternative available;
- cheapest candidate `REFUTED`;
- stale failure reopens only after a materially named representation/access change;
- irrelevant representation label remint does not reopen;
- raw failure-memory baseline prunes a route that should reopen;
- no-history baseline repeats a route whose failure remains applicable;
- no certified obstruction => `SEARCH_MORE/UNRESOLVED`, not repair;
- query result unavailable => `CANNOT_CHECK`, never imputed;
- evaluator outcomes cannot update protected policy/model.

## Matched-information rule

Any ORION-vs-baseline comparison must expose the same candidate states, costs, history records and verifier/query interface. A baseline may ignore a field by design but cannot be denied it.

## Reopen triggers

Reopen before result interpretation if:

- the P0 oracle is not exact on tiny enumerated worlds;
- identity/order changes alter optimal repair;
- H1 depends on unequal information;
- simple value-of-information/Bayesian search fully closes H1;
- S0 finds a direct close parent for scoped target-specific method-set repair.

## Authority

Benchmark/evaluator research only. Even a positive H1 would be a bounded decision-state result, not a new quantum algorithm or new quantum-control theorem.
