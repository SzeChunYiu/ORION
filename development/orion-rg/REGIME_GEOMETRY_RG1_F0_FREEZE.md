## RG-A — trivial semantics, dense optimum

For each `n`, let the feasible objects be all binary words `x in {0,1}^n`.

- semantic contract: trivial; every word is semantically admissible;
- conserved semantic quotient: the one-element group/state, so `d_sem=0`;
- designated support: `supp(x)={i:x_i=1}`;
- nonnegative additive objective: `C(x)=sum_i (1-x_i)`.

The unique optimum is `1^n`, with support exactly `n`. Therefore no all-instance constant `kappa` exists despite `d_sem=0`.

**Boundary learned:** a support theorem needs more than a low-dimensional semantic quotient. It needs a legal semantics-preserving support-reducing edit plus an objective certificate making the edit non-increasing (the substantive premises in QG-6/R6S-style arguments).

## RG-B — bounded support, unbounded continuation value state

Use the one-symbol alphabet `Sigma={a}`. There is no optimization choice and no auxiliary support, so `kappa=0` identically. Define exact value on a word of length `n` by

`V(a^n)=n^2`.

For two prefixes of lengths `m != m'` and a continuation of length `k`,

`V(a^(m+k))-V(a^(m'+k)) = (m^2-m'^2)+2k(m-m')`.

The difference depends on the continuation length `k`; hence the two prefix states cannot be merged under value-equivalence that permits only one fixed additive offset. There are infinitely many continuation-distinct value states.

**Boundary learned:** bounded optimal support plus a finite local alphabet is insufficient. A finite exact optimizer theorem needs a finite lifted state for all load-bearing accumulated cost/semantic context, or a compositional/additive law that eliminates it.

## RG-C — one regime, no uniform bounded-support improvement basis

For each `n`, feasible configurations are only `0^n` and `1^n`. Let

`C(0^n)=0`, `C(1^n)=1`.

There is one global optimum/regime family for every instance size. Any feasibility-preserving improvement from `1^n` to `0^n` changes all `n` coordinates at once. Therefore no fixed bound `b` can support a complete basis of moves that each touches at most `b` coordinates for all `n`.

This refutes only the **bounded-support primitive move** interpretation. If a move language admits the parametric schema `flip every coordinate`, a one-schema basis exists. RG must therefore make move-language complexity part of every `T_*` statement instead of counting schemas alone.

## RG-D — donor strike on test bases and objective fans

A central apparent RG theorem is already classical for fixed-matrix integer programming.

Bernd Sturmfels and Rekha Thomas, *Variation of Cost Functions in Integer Programming* (1990s), study

`min c·x  subject to A x=b, x>=0, x integral`

for fixed `A`. Cost functions are equivalent when they induce the same optimal solutions for every right-hand side. Their theory identifies objective-equivalence regions with Gröbner cones/state-polytope geometry; reduced Gröbner bases give local cost inequalities; the universal Gröbner basis is a finite universal structure related to fiber edge directions; the Graver arrangement refines the Gröbner fan.

Current accessible donor pointer used in F0:
`https://www.researchgate.net/publication/2277674_Variation_of_Cost_Functions_in_Integer_Programming`

**RG consequence:** `finite move/test basis -> objective hyperplane/fan geometry` cannot be sold as a general ORION discovery. A distinct result would need, for example, compiler/science semantics outside a fixed lifted integer matrix, a theorem deriving the correct finite lift automatically, a stabilization theorem across growing representations, or a recognition/forecast theorem not already implied by the donor correspondence.

## RG-E — weighted-state asymptotics donor boundary

If an exact optimizer is already represented by a finite min-plus weighted automaton and a fixed motif induces one finite min-plus transfer matrix `M`, then repeated motifs reduce to observables of `M^k`. Ultimate/critical-cycle behaviour is established tropical spectral theory.

Recent donor frontier also includes:
- Almagor, Arbel, Sheinvald, *Determinization of Min-Plus Weighted Automata is Decidable*, SODA 2026;
- Almagor, Arbel, Sheinvald, *A Complexity Bound for Determinisation of Min-Plus Weighted Automata*, LICS 2026;
- Almagor, Arbel, Sheinvald, *Unambiguisability and Register Minimisation of Min-Plus Models*, ICALP 2026, including undecidability of tropical CRA register minimisation from a fixed register count.

**RG consequence:** the high-value object is not generic automata determinization/minimization or periodicity. It is a structural theorem that tells us when a scientific optimization family *admits the exact finite weighted-state lift in the first place*, with measurable scope and counterexamples.

## RG-F — local certificate arity does not imply a complexity win

Input is `x in {0,1}^n`. Regime label is

`ZERO` iff all bits are zero, otherwise `NONZERO`.

A positive `NONZERO` certificate has support arity 1: one index with `x_i=1` suffices. Nevertheless any deterministic exact recognizer has worst-case query complexity `n`, because on the all-zero input it must rule out a one at every unread position. An exact baseline that simply scans the input is also `Theta(n)`.

Therefore bounded certificate arity does not by itself imply `recognition << optimization` or even sublinear recognition.

**Boundary learned:** a genuine recognition-vs-optimization separation needs a complete two-sided certificate/access model, explicit query/computation costs, and a lower bound for the optimization task or an upper bound for recognition that is strictly smaller under matched access.

## First surviving high-value theorem candidates

After F0, the council keeps only these as serious RG-core candidates:

### T-A — automatic finite-lift theorem

Find checkable structural premises on a family expressed in its *native semantics* that imply existence of a finite exact weighted-state representation, and quantify the state bound. The theorem must not simply assume a finite sufficient state as a premise.

Promising premise ingredients:
- all-instance compactness/normal-form theorem for auxiliary objects;
- finite local alphabet/type system;
- finite set of load-bearing global parity/syndrome/count coordinates;
- additive/local resource law after a finite lift;
- spectator/environment equivalence theorem proving omitted coordinates inert.

### T-B — recognition-compression theorem

Prove for a nontrivial growing family that the exact regime-label quotient is strictly smaller than the exact value quotient *and* that this yields a provable matched-access complexity reduction, not merely fewer named states.

### T-C — stabilization theorem across size

Show that a family of native semantic fibers/transition systems has finitely many primitive obstruction or improving-move orbit types beyond some proved locality/support radius. This is potentially distinct only if it is not an immediate n-fold IP/Graver/finite-model theorem after faithful encoding.
