## Skills under calibration

### S3 — theorem-gated bounded-support localization
If an all-n theorem certifies a smaller exact support cap, restrict exact candidate search to that cap. Never infer the cap from a finite panel alone.

### S4 — question-conditioned coarse representation
If a simple predicate is exactly sufficient for the requested label on the frozen domain, stop at that representation. If exactness is impossible for the frozen vocabulary, do not continue treating vocabulary widening/search depth as if it could solve the same representation.

### S7 — information-barrier-first
Before expensive predicate search, check whether identical visible feature vectors carry both labels. A mixed cell is a complete zero-error impossibility certificate for every predicate over that vocabulary and should stop zero-error search immediately.
