# MAX-R6 P10 frame optimizer erratum 1

Date: 2026-08-20
Applies before any optimizer outcome.

The candidate-generation protocol's G1 wording could be read as requiring exhaustive arbitrary rank-3 frame optimization for every open-subject triple. That is stronger than the frozen candidate-generation gate, computationally unnecessary, and overlaps the generic Clifford/symplectic compilation problem already owned in part by Treespilation/Symphony-style donors.

For the **candidate-generation stage only**:

- exhaust the full rank-2 `F2^2` three-label frame grammar on every eligible H4/equilibrium-N2 triple;
- compare against the strengthened canonical rank-3 TARE donor after all 24 ordered distinct two-bit label triples, all target permutations and all Uanti central axes;
- implement arbitrary rank-3 frame search only on reminted 2/3-qubit hostile cases to validate grammar/solver semantics.

This stage may establish only `MAX_R6_P10_FRAME_CANDIDATE_GENERATED`.

Before any R6 resource-superiority claim, arbitrary noncanonical rank-3 frame optimization must receive first right of refusal through either (a) an exact bounded solver on the selected blocks, or (b) a donor-composed compiler binding demonstrating that a stronger Clifford/symplectic optimizer was applied. Thus this erratum narrows computation, not donor strength or R6 obligations.
