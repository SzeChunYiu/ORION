## Frozen implementation hypothesis

> If every execution job is represented by a content-addressed protocol with exact source identities, dependency and resource contracts, registered terminals, a scheduler deduplication key, and a fail-closed result schema, then ORION can execute dependency-ready studies quickly without duplicate submission or authority laundering; queue conflicts and missing scientific inputs will terminate as explicit blockers rather than guessed mappings.

This is an engineering/governance hypothesis only. It creates no scientific, novelty, or paper authority.

## Frozen hostile tests

- reject two canonical jobs sharing one identity;
- reject aliases that map to scientifically different questions;
- reject a job with missing dependencies or donor-product definition;
- reject outcome-bearing protocol inputs;
- reject stale source SHA and unpriced resource scalarization;
- reject duplicate submission when an identical protocol is live or terminal in scheduler history;
- reject incomplete result bundles;
- preserve adverse and `CANNOT_CHECK` terminals;
- prevent paper-authority delta from changing during execution ingestion;
- accept an engineering reference check only with an explicit non-scientific authority ceiling.
