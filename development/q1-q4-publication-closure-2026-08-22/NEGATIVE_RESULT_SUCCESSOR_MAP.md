# Negative-result and successor map

evidence into a more favorable outcome. Each existing result keeps its original
status. A replacement method receives a new identifier and a new prospective
test.

## Rules for absorbing threats into useful structure

1. A falsified subfamily yields an exact counterexample and may motivate a
   boundary theorem; theorem status requires a separate proof.
2. A donor tie becomes an ownership boundary: determine whether value lies in
   state, inference, policy, or not at all.
3. A null becomes evidence about the tested domain and a constraint on the next
   forecast; it is not evidence that the test was useless.
4. A contaminated or invalid run becomes an instrument-quality observation; it
   never enters the scientific denominator as a valid positive.
5. A harness repair produces a versioned successor. Historical receipts and
   claims remain fixed.
6. A new method may address the limitation only in a versioned prospective
   successor, and only if it is compared with the strongest relevant donor at
   matched information, compute, and outcome custody. The predecessor result is
   never replaced.
