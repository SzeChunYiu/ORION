## Goal

Attack the remaining P1 negative/tied boundary without rewriting any old result.

Historical evidence is immutable:

- broad `failure => reformulate` failed;
- decision-complete objective-basis cases tie and establish a no-reformulation regime;

The new research object is not static revision semantics. It is **acquisition of the missing responsibility/regime information under a matched resource budget**.

## Prospective object

`ActiveResponsibilityDiscrimination.v1` is a research object only. It is **not** added to the canonical registry before scientific value is shown.

The candidate observes a cause-confusable episode and an admissible set of discriminator actions:

- `SEARCH_MORE`
- `COMPILE_OR_REPRESENT`
- `REPAIR_ENV_OR_HARNESS`
- `REMEASURE`
- `TEST_OBJECTIVE_BASIS`
- `TEST_PROBLEM_BOUNDARY`
- `ABSTAIN`

Each action has a frozen cost and a case-specific observation contract. The candidate must select an action, consume its observation, then issue a revision decision. High-level reformulation is invalid unless the acquired evidence rules out registered lower-level explanations within the budget.

## Atomic questions

1. Can the current static P1-X rule remain correct when the responsibility coordinate is hidden and must be acquired?
2. Which discriminator observations are necessary/sufficient to separate representation, implementation, measurement, objective and problem-boundary causes?
3. Can a donor-complete controller with the same action set route as well as ORION without an explicit responsibility-acquisition state?
4. Does an explicit epistemic value-of-discrimination policy improve fresh protected scientific success after discriminator cost is charged?
5. Does the learned routing rule transfer to held-out domains and reminted surface forms?
6. Can at least one historical negative/tie family become a positive regime result without weakening the ideal-product ceiling?
7. When no affordable discriminator identifies the cause, does ORION correctly remain `UNRESOLVED/CANNOT_CHECK` rather than escalate?

## Competing mechanism hypotheses

- **H-A:** no new mechanism is needed; donor-complete dynamic routing matches ORION.
- **H-B:** explicit responsibility-acquisition state improves action choice but not final scientific outcomes.
- **H-C:** active responsibility discrimination improves final protected outcomes and reduces false reformulation under matched cost.
- **H-D:** benefit exists only in authored exact worlds and disappears under held-out domain/remint transfer.
- **H-E:** a new discriminator/operator is required in at least one held-out regime and transfers after being learned from failure.

Every runnable comparator receives the same candidate-visible information and exact discriminator action/cost set.

## Red-first hostile requirements

Before any positive result is admissible, tests must reject:

1. protected responsibility/gold leakage through action names, IDs, path names, ordering or metadata;
2. free discriminator observations or uncharged state compilation;
3. action set that uniquely identifies the label by availability alone;
4. always-reformulate policy;
5. always-abstain policy;
6. timeout interpreted as objective/problem inadequacy;
7. donor-complete baseline missing an applicable donor mechanism;
8. protected result counted when evaluator/subject/split identity is stale or mismatched;
9. result denominator dropping failed/harmful/unresolved cases;
10. post-outcome margin or action-cost changes.

## Statistics freeze target

Independent unit: unique protected episode, never repeat/model sample.

Primary endpoint proposal: **Generalized Reformulation Success (GRS)** is 1 only when:

- protected final scientific task succeeds;
- revision responsibility/level is correct;
- no frozen harmful-regression/protected-invariant violation occurs;
- required authority/evaluator integrity holds.

Primary contrast: ORION ARD minus strongest runnable donor-complete comparator on paired GRS.

Non-compensatory guards:

- false/unnecessary reformulation;
- missed necessary high-level reformulation;
- worst-family harmful regression;
- false resolution of `UNRESOLVED/CANNOT_CHECK`;
- evaluator/authority compromise = automatic block.

Exact margins and CI method are frozen in the protocol before generated protected outcomes.

## Stop / recurse rule

Aim for `P1_U_GENERALIZED_REFORMULATION_SUPERIORITY_SUPPORTED`.

If a run is negative, preserve it and classify the failing responsibility. The next successor must change a materially different causal ingredient. No margin relaxation, hard-family deletion, label mutation, baseline weakening, endpoint switching, or outcome suppression.

A negative may terminate only through a rigorous lower bound/impossibility for the registered object or saturation across materially different successor families.
