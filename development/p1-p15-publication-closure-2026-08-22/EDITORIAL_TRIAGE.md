# P1-P15 editorial triage

This triage precedes the three blind referee reports. It uses only the frozen
candidate packet identified in `PACKET.md`; it does not anticipate or summarize
reviewer concerns.

## Decision

- **P1-P9 and P11-P14:** technically reviewable. Presence of a manuscript does
  not imply acceptance or submission readiness.
- **P10:** technically reviewable but editorial promotion is deferred because
  the active programme description itself says the verdict may be decided by
  construction. The technical review must resolve that issue before prose work.
- **P15:** rejected at editorial intake as an incomplete submission. The fixed
  candidate contains a planning README but no manuscript, chapter TeX tree,
  claim ledger, donor matrix, frozen protocol or protected result.

## Target criteria card

Exact target journal: `UNRESOLVED`.

The first pass therefore evaluates correctness, claim/evidence alignment,
independent contribution, reproducibility, reporting integrity, literature
support, scope boundaries and readable/buildable submission files. Page limits,
article type, house citation style, data-policy forms and venue-specific priority
criteria cannot be certified until a target is fixed.
