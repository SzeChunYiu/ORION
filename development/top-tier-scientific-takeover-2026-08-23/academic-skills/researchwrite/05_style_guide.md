# P1-P5 style guide

- Language: English.
- Stance: scientific-question-driven and evidence-first.
- Repeat canonical terms when the referent is unchanged. Do not rotate `authority`, `custody`, `identified set`, `terminal` or `exact contract` into vague synonyms.
- Prefer one proposition chain per paragraph: claim, evidence, alternative, boundary, implication.
- Put the strongest valid result early, then state the information-equivalent tie or authority boundary in the same local argument.
- Avoid prestige adjectives, unsupported intensifiers, generic future-work lists and repository-path leakage in the scientific narrative.
- Preserve exact terminal names and all adverse results.
- Never call another AI context an external reviewer, custodian or provider.
- Avoid dash punctuation when a sentence boundary is clearer; preserve mathematical hyphens and machine identifiers.
