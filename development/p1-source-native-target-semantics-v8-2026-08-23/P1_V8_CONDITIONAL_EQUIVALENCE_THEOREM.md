# P1 V8 public-target semantic underdetermination theorem

## Scope

Let (S) be the six frozen source-native postpublication terminals, (T) the
seven R7 scientific-decision identifiers, and (F=S\to T). The certification
gates G1--G7 and all R7 source profiles are unchanged. The evidence added in V8
is limited to the seven-file target-semantic corpus in the public ORION
repository at commit
`390267dfa9c6669e506ba67b5dde5dddd8f96232`, its remote byte identity, and its
rights/provenance metadata.

## Theorem 1: diagnostic probes are not terminal-decision denotations

Within the frozen public ARD protocol, scientific decisions and diagnostic
actions are different types and there is no inherited one-to-one pairing.

**Proof.** `ARD_PROTOCOL_V1.md` declares the seven scientific decisions and
seven diagnostic actions in separate vocabularies. The executable protocol
then supplies direct non-functionality witnesses: `SEARCH_MORE` can distinguish
`KEEP_SEARCH` from `KEEP_COMPILE`; `TEST_PROBLEM_BOUNDARY` can distinguish
`REFORMULATE_OBJECTIVE` from `REFORMULATE_BOUNDARY`; and representation or
harness probes can distinguish lower- from higher-level decisions. A probe
returns evidence used to choose a decision; it is not that decision's
denotation. QED.

## Theorem 2: public target evidence does not identify actionable equivalence

Under G2--G4, the V8 public corpus identifies neither equality nor inequality
for any of the 30 actionable source-target cells.

**Proof.** The corpus binds each target's scientific-process intent and proves
the probe/decision type separation. It does not provide an exhaustive
postpublication coordinate, licensed operation set, forbidden operation set,
owner-ratified postpublication bridge, or target-specific
error/timeout/malformed/unsupported rule for any actionable target. G2--G4
require those fields for extensional equality. An authoritative contradiction
or forbidden-operation witness is required for inequality. The unchanged
protocol forbids turning absence, lexical resemblance, or causal-anchor
difference into either result. Each actionable cell therefore remains
`CANNOT_CHECK_TARGET_DENOTATION`. QED.

This is a result about the sufficiency of the frozen evidence registry, not a
claim that the real target semantics are unknowable.

## Corollary: the 720-map partition is invariant

Direct enumeration of all (7^6=117{,}649) functions reproduces:

- fully certified: **0**;
- rejected by an existing cell or collision witness: **116,929**;
- not disproved but uncertified: **720**.

Every survivor fixes `UNRESOLVED -> UNRESOLVED` and injectively maps five
actionable sources into six actionable targets. Thus every survivor has exactly
five still-unbound actionable images. V8 certifies 0 and newly rejects 0 of the
720. This preserves the R7 negative; it does not infer impossibility.

## Conditional owner-algebra equivalence

For any surviving total function (f), (f) is certifiable exactly when a
prospectively frozen, closed-world, owner-ratified target algebra supplies
profiles and terminal behavior that make every image pass unchanged G2--G7.
Conversely, if that algebra authoritatively forbids at every target an
operation required by some source terminal—for example full-artifact
withdrawal—then no total adapter exists **under that algebra**.

The antecedent is currently unbound. The conditional implication is neither
owner ratification nor an unconditional impossibility result.

## Rights boundary

The repository and pinned source bytes are publicly fetchable, but GitHub
reports a null repository-license field, its license endpoint returns 404, and
the pinned tree contains no repository-level or target-corpus-applicable
`LICENSE`, `COPYING`, `NOTICE`, or `COPYRIGHT` file. Six scoped licence files
exist in unrelated journal-package/benchmark subtrees and are not generalized
to the frozen target corpus. V8 therefore retains no remote source body. Public
visibility supports provenance and bounded inspection, not a claimed reuse
licence.
