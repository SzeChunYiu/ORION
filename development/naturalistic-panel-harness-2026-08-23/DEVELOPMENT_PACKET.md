## What was and was not accessed

The fetcher requested only:

1. official repository identity metadata;
2. the first commit returned at or before `2025-12-31T23:59:59Z`;
3. the repository licence object at that exact commit; and

It deliberately did **not** request issues, pull requests, discussions,
scientific case text, pair roles, causal families, revision classes, protected

## Licence boundary discovered

The exact repository licence is evidence about the repository content at the
pinned commit. It does **not** automatically license third-party issue text,
pull-request prose, linked papers, uploaded datasets, screenshots, or
attachments. Therefore this tranche does not authorize redistribution of
issue bodies or use of linked artifacts. A provider-diverse acquisition plan
must bind the legal status and permitted processing of each selected content
class before raw case capture. This is now an explicit acquisition gate rather
than an implicit assumption.
