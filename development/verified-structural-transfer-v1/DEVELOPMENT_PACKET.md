# Verified Structural Transfer V1 — development packet

**Development question:** Can ORION convert far-domain structural analogies into useful solver mechanics without granting authority to analogy-by-similarity, and can those mechanics survive deterministic hostile toy worlds before any paper adopts them?

**Base subject for this packet:** `46977ea104162c4cf64da8138a4c4759065fe6d4`.

## Atomic development fibres

1. Define a domain-independent problem signature that can retrieve structurally similar problems while explicitly treating the score as non-authoritative.
2. Define an `AlgorithmCell` with explicit assumptions, invariants, stopping rule, failure modes and falsifiers.
3. Make transfer fail closed: false assumption -> `BLOCKED_ASSUMPTION`; failed falsifier -> `OBSTRUCTED`; unknown requirement -> `CANNOT_CHECK`.
4. Add optional independent-domain cross-confirmation so a single attractive analogy cannot masquerade as a necessary structural mechanism.
5. P1 prototype: detect responsibility *diagnosability* before failure attribution and actively select a discriminating probe; only a sufficiently supported responsibility may license a corresponding epistemic mutation.
6. P2 prototype: preserve a declared baseline-performance floor while exploring alternative discovery routes; provider unavailability is censored feedback, not zero reward.
7. P3 prototype: make source/global mappings bidirectional and test round-trip/cycle consistency; inconsistent cycles emit an obstruction rather than a forced merge.
8. P4 prototype: plan the next protected evidence action from unresolved authority defeaters; evidence acquisition never itself grants authority.
9. P5 prototype: require non-compensatory STATIC -> REPLAY -> FRESH -> PROTECTED stages; replay gain cannot compensate fresh harm or protected `CANNOT_CHECK`.
10. Construct known-answer toy worlds where each mechanism has a falsifiable local advantage over a deliberately weaker baseline.

## Incumbent mechanics / negative history recovered

- ORION already separates local implementation semantics from external scientific authority; this packet keeps every new local result below publication authority.
- P1's current pilot exposed a non-discriminating mechanical arm. That makes diagnosability of the *instrument* a concrete development requirement rather than an aesthetic addition.
- P2 already distinguishes route stop from task closure and unavailability from evidence of absence. The allocator must preserve those semantics rather than replacing them with generic reward learning.
- P3 already has typed semantic projections and obstruction states. Lens/cycle checks are candidates for stronger consistency machinery, not replacements for semantic coordinates.
- P4 already has protected evaluator/holdout custody. Evidence planning must stay outside the authority terminal and cannot substitute self-checks for protected evidence.
- P5 already forbids self-promotion and requires fresh/protected evidence. The multi-stage gate must remain non-compensatory and host-recommendation-only.

## Same-domain and parent-domain research

The research pass deliberately challenged the paper vocabulary and searched distant fields.

### Cross-domain structural transfer

- Analogical cross-domain reasoning is already active research (`Reason Analogically via Cross-domain Prior Knowledge`, arXiv:2604.05396).
- `Analogical Deep Research` (Forecast@ICML 2026) treats analogy retrieval as a causal/structural problem and argues that cross-confirming analogies can distinguish mechanism from coincidence.
- `IsoSci` (arXiv:2607.01431) is a direct warning: isomorphic problem structure does **not** imply knowledge-independent transfer; most measured reasoning-mode gains in its study were knowledge-dependent.

**Consequence:** generic structural analogy retrieval is not a novelty claim. ORION's candidate contribution is a *verified transfer gate* between retrieval and executable solver adoption.

### P1 — diagnosis / active sensing

- Bayesian active fault identification (arXiv:2509.04708) formalizes diagnosability and designs inputs when passive observations cannot distinguish faults.
- CausalFlow (arXiv:2605.25338) already performs causal attribution and counterfactual repair for agent failures.
- AgentDebugX (arXiv:2607.18754) already closes detect -> attribute -> recover -> rerun.
- Active clinical diagnosis such as MedAction (arXiv:2605.07305) treats test ordering under partial evidence as part of the task.

**Consequence:** active diagnosis and causal repair are absorbed. The candidate residual is applying diagnosability to *epistemic responsibility classes* and using supported responsibility as a license for formulation/search-universe mutation.

### P2 — safe exploration / censored feedback

- Conservative bandits and Conservative Linear UCB already provide baseline-preserving exploration (arXiv:1602.04282; 1611.06426; 2002.03221).
- Safe exploration has already been applied to information retrieval/ranking (arXiv:2002.00467).
- Missing/censored-feedback bandits are established.

**Consequence:** route allocation by bandit is not novel. The candidate residual is the composition with ORION's fail-closed route/task authority, earned route identity, and censored-unavailability semantics.

### P3 — bidirectional views / multi-view consistency

- Partial-state lenses (arXiv:2601.04573) formalize bidirectional transformations and well-behaved round-trip properties for multiple partially specified views.
- Bundle adjustment and cycle-consistent synchronization are established multi-view reconstruction tools.
- Causal transportability research explicitly asks when information may be transferred between populations/domains.
- Current semantic-atlas/obstruction work means "use cycle consistency / local-to-global gluing" is not safely novel by itself.

**Consequence:** lenses and cycle consistency are absorbed. The candidate residual is typed scientific round-trip validation over referent/construct/measurement/context mappings, with failure routed to ORION obstruction/pluralism rather than forced canonicalization.

### P4 — assurance / certificates / defeaters

- Proof-Carrying Agent Actions (arXiv:2606.04104) already binds actions to portable evidence/approval certificates.
- Semantic Quorum Assurance (arXiv:2606.08021) and the Honest Quorum Problem (arXiv:2607.16109) already study diverse validators and correlated epistemic failure.
- Defeater Cards (arXiv:2606.11462) structures safety-case defeaters.

**Consequence:** proof-carrying actions, validator quorum and defeater representation are absorbed. The candidate prototype is narrower: *which protected scientific evidence action should be acquired next*, scored by unresolved authority-risk reduction per cost, while authority remains fail closed.

### P5 — sequential acceptance / multi-stage trials

- PACE (arXiv:2606.08106) already brings anytime-valid paired e-process acceptance tests directly to self-evolving agents.
- Adaptive clinical-trial e-values and multi-stage trial designs are established.
- Multi-stage/multi-fidelity optimization is used in self-driving laboratories.
- Recent self-evolving-agent evaluation shows validation and transfer can disagree and evolution is sparse (arXiv:2608.02636).

**Consequence:** e-process acceptance is absorbed and must not be claimed by P5. The candidate residual is a non-compensatory sequence in which independent fresh transfer and protected evaluation are mandatory promotion stages, not optional audit metrics.

## Saturation challenge

Why might this still be falsely flat?

- Search terms could overfit agent/LLM literature and miss older control, diagnosis, experimental-design, IR, database, measurement, safety-case, clinical-trial or reliability theory.
- Structural analogy can be a seductive false friend: two domains can share a graph while differing in ground-truth access, intervention legality, dependence or authority cost.
- A toy world can prove a mechanic's semantics but cannot establish paper-level empirical value.
- A mechanism can be useful without being novel; every paper must separately decide whether to use it as method, baseline, ablation, or future work.

## Miss hypotheses

1. There may be stronger problem-signature / algorithm-selection frameworks outside LLM research; generic solver retrieval remains explicitly non-novel until searched again before publication adoption.
2. P1 responsibility diagnosability may have a direct analogue in software fault localization or requirements diagnosis not yet found.
3. P2's exact composition may appear in federated search/reliability allocation even if not named as a bandit.
4. P3's typed lens idea may be absorbed by ontology alignment or measurement-harmonization literature once the scientific coordinates are searched directly.
5. P4 evidence-action planning may already exist in assurance-case confidence/Bayesian safety-case tooling.
6. P5 mandatory fresh/protected stages may be absorbed by a new self-evolution paper after this packet; PACE already absorbs the anytime-valid part.

## Frozen implementation hypothesis

> If structural retrieval is separated from transfer authority, and every imported mechanism is gated by explicit assumptions/falsifiers, then far-domain analogies can be used safely as solver candidates. On deterministic counterexamples, paper-specific ORION compositions should outperform deliberately weaker baselines on their intended invariant without creating new scientific authority.

This is a **local engineering hypothesis**, not a publication claim.

## Frozen known-answer / hostile tests

- high structural score + false assumption must never become admissible;
- unknown assumption/falsifier must become `CANNOT_CHECK`;
- cross-confirmation must require distinct source domains;
- P1 identical probe likelihoods must have zero information gain and refuse diagnosis;
- P1 evidence/execution diagnosis must not license formulation rewrite;
- P2 unsafe exploration must be blocked transactionally and leave allocator state unchanged;
- P2 censored provider failure must not update mean reward as zero;
- P3 consistent affine views must round-trip/cycle consistently; corrupted mapping must produce `OBSTRUCTION`;
- P4 unprotected self-check cannot resolve a critical defeater; evidence action availability means BLOCKED/gather-evidence, not authorized;
- P5 replay improvement cannot compensate fresh harm; protected `CANNOT_CHECK` blocks; failed/harmful candidate remains in archive.

## Reopen triggers

Reopen research rather than extending code if:

- a local falsifier can be passed by a trivial/no-op strategy;
- a mechanism can escalate authority without the intended protected gate;
- a stronger direct nearest-work system is found for the ORION-specific residual;
- a paper's existing V1 protocol would need outcome-informed mutation to include the mechanism;
- an imported algorithm requires assumptions ORION cannot observe or defend.
