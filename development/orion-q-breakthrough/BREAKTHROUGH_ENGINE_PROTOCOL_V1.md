# ORION-Q Breakthrough Discovery Protocol V1

Issue: #980. First calibration: #981. Development packet: `BREAKTHROUGH_ENGINE_DEVELOPMENT_PACKET_V1.md`.

## Status

`PROSPECTIVE / ADDITIVE / NO AUTHORITY`.

This protocol does not replace the frozen Phase-4 cycle. It is a research-selection and theorem-synthesis layer that may run before a cycle is selected and after an outcome is archived.

## Pipeline

`Q-DISCOVER -> Q-REFEREE -> Q-PUBLISH`

Q-REFEREE and Q-PUBLISH reuse existing ORION custody, hostile evaluation, novelty, claim-ledger and publication machinery. V1 defines only Q-DISCOVER.

## Breakthrough levels

| level | internal meaning | forbidden inference |
|---|---|---|
| B0 | observation / experiment | not a theorem |
| B1 | exact finite value | not structural generality |
| B2 | exhaustive finite classification | not infinite theorem authority |
| B3 | symbolic structural lemma explaining/controlling a class | not automatically novel |
| B4 | reusable parametric theorem / new infinite family after ordinary authority checks | not automatically top-tier |
| B5 | major conjecture resolution/refutation or broadly reusable mechanism after ordinary authority checks | not automatic publication acceptance |

The level is a scheduling/compression coordinate only. Truth, proof, novelty and publication authority remain separate.

## D1 — COMPRESSION_GATE

Before material new computation, freeze all of:

1. `INPUT_STATE`: exact current frontier evidence;
2. `UNKNOWN`: what still distinguishes success from failure;
3. `CANDIDATE_COORDINATES`: human-readable or native mathematical coordinates;
4. `ABLATIONS`: which coordinate removals would merge different outcomes;
5. `EXPECTED_COMPRESSION`: a smaller state, a hypothesis discriminator, a minimal obstruction, a symbolic lift test, or an independent replay;
6. `REFUSAL_CONDITION`: if no expected compression exists, do not run the compute merely to enlarge the atlas.

A computation can still be large. Its justification must be information gain about theorem structure, not size.

## D2 — OBSTRUCTION_TO_INVARIANT

A failed theorem/search packet must archive one of:

- replayable counterexample;
- minimal obstruction;
- newly required state coordinate;
- impossibility theorem closing the method family;
- exact `CANNOT_CHECK_*` boundary.

A successor grammar must state the invariant or missing coordinate learned from the failure before it expands the search language.

## D3 — HARD_STRATUM

When a theorem handles only part of a census, define the complement explicitly:

`HARD_STRATUM = exact census - proved stratum`.

Record:

- defining condition;
- exact size where known;
- proof step that fails on it;
- smallest candidate repair coordinate;
- donor reductions already exhausted;
- forbidden recomputation of solved strata unless used as a hostile control.

## D4 — TWO_SIDED_THEOREM_LAB

For a B3+ candidate freeze two packets with common donor facts but no outcome sharing:

### PROOF_PACKET

Attempt the strongest all-instance proof under the exact native premises.

### COUNTEREXAMPLE_PACKET

Assume the conclusion false and optimize for a premise-satisfying obstruction. Prefer extremal/hard instances over random examples.

### SYNTHESIS_PACKET

Opened only after both are sealed. Compare:

- which premise/invariant the proof needs;
- which states the counterexample packet can actually realize;
- the smallest statement separating them.

The synthesis output is a candidate lemma, not theorem authority.

## D5 — SYMBOLIC_LIFT

Every B2/B3 result is immediately rewritten with load-bearing constants replaced by parameters.

Required fields:

- fixed-constant dependencies;
- parameter-independent steps;
- second-family test;
- first predicted failure boundary;
- donor theorem map for the lifted statement;
- strongest native theorem that would follow if the lift holds.

A finite result may still be published; lifting is used to discover its ceiling before publication scope is frozen.

## D6 — PORTFOLIO

At most three flagship breakthrough roles are actively prioritized at one time:

- `A_EXPLOIT`: highest-probability structural theorem path;
- `B_STRUCTURE`: deeper state-compression/invariant path;
- `C_BOUNDARY`: counterexample, general-conjecture, or failure-boundary path.

Portfolio scores are scheduling hints only. A donor kill, proof impossibility, or exact obstruction reallocates effort rather than being post-hoc reframed as success.

## D7 — B4+ FLAGSHIP GATE

For a future top-tier-oriented flagship, ask before declaring the scientific headline:

- does the result unify multiple B1/B2 facts?
- is the mechanism stated natively, without ORION branding?
- has symbolic lifting been attempted?
- is the generalization genuinely new after donor subtraction?
- is there an independent adversarial/counterexample programme?
- does the result change what experts can prove/compute/understand, rather than only improve internal workflow?

Failure does not invalidate a strong specialist paper. It changes the publication ladder.

`D_2(C_5^3)=20`, `D_3(C_5^3)=25`, exact `s_{<=T}` spectrum, exact D2/inverse censuses, donor lower construction for `D_4>=30`.

### COMPRESSION_GATE result before any new upper-bound compute

Reusing the already committed exact threshold `s_{<=6}(C_5^3)=24` gives

`D_4 <= max(25+6,24-1)=31`.

Thus the exact live discriminator is only

`D_4(C_5^3) in {30,31}`.

This is the first prospective V1-positive signal: a sharper reuse of existing state removed one candidate value and prevented unnecessary length-31/32 search.

### Structural compression

Any length-30 no-four-zero-sum obstruction must have

`A_6 * B_6 * C_t * Z`, `t in {6,7,8}`,

with three zero-sum blocks, zero-sum-free tail Z, global minimum zero-sum length at least 6, and a rank-three 18-term no-two-disjoint core.

Therefore the only exact search authorized by the current state is a length-30 obstruction discriminator under this compressed grammar.

### Symbolic lift before D4 closure

The same sharpened state gives

`D_k(C_5^3)<=5k+11` for all `k>=4`,

hence the candidate audited recurrence

`D(C_{5m}^3)<=5D(C_m^3)+11`.

For prime-power q this is `D(C_{5q}^3)<=15q+1=D*+3`.

If exact `D_4=30`, the intercept improves by one again to `5k+10`, `5D(C_m^3)+10`, and `D*+2` for prime-power cofactors.

### Hard failure terminal

If a length-30 obstruction exists, then `D_4=31`. Preserve/classify it and identify the invariant preventing the expected `+5` linear increment. Do not treat the exact number 31 as the sole scientific endpoint.

## V1 success criterion

V1 is prospectively useful only if, on #981 or another frozen calibration, it does at least one of:

- refuses a compute that the incumbent process would have run and replaces it with a more informative discriminator;
- produces a strictly smaller theorem-bearing hard state;
- exposes a symbolic generalization/boundary before publication framing;
- converts a failed method into an invariant with predictive/proof value.

The first #981 pass has already met the **decision-compression** form provisionally: exact reuse of `s_{<=6}` changed the target from 30/31/32 to 30/31 and narrowed the authorized search. This is process evidence only, not a causal productivity claim.

If the incumbent ORION cycle would have produced the same decision and state without these mechanics, record `NO_INCREMENTAL_VALUE` and narrow or remove V1.

No ORION-Q breakthrough claim is authorized by this protocol. Any mathematical/scientific result is judged under its native field standards; any causal claim about this protocol requires prospective comparative evidence.
